这一讲要回答五个问题：

1. 外部性，能不能让当事人**自己谈判**解决？（**科斯定理**）
2. 为什么"产权归谁"，不影响效率，却影响谁富谁穷？
3. 现实里，为什么这样的谈判常常**谈不成**？（**交易成本**、人数、私人信息）
4. 交易成本很高时，产权该给谁？
5. 产权清楚，本身有什么用？证据怎么说？

上一讲，我们的办法都是政府出面：征税，或者定总量。可是政府要知道损害有多大，要知道减排成本，而这些信息，在当事人手里。这一讲问一个很朴素的问题：**既然渔民最知道自己的损失，纸厂最知道自己的收益，让他们自己谈，行不行？**

## 一、渔民和纸厂坐下来

河上游的纸厂，每多生产 1 吨纸，下游的渔民就多损失一点。上一讲，我们让政府征税 20，让价格说真话。

**先停一下：如果没有政府，渔民找上门去，会发生什么？这取决于一个问题：纸厂有没有权利往河里排污？**

- **如果纸厂有权**（河是它的，或者法律允许它排）：渔民只能**出钱请它少产**；
- **如果渔民有权**（河里的清洁水归他们，法律保护）：纸厂只能**出钱买渔民的同意**，才能生产。

这两个答案，听起来天差地别：一个是渔民付钱，另一个是纸厂付钱。

1960 年，Ronald Coase（《社会成本问题》，*Journal of Law and Economics*，3 卷）提出了一个引起很大争论的想法。他先质疑了一个我们很自然的看法："纸厂伤害了渔民"。他说，这个问题是**相互的**：为了不伤害渔民，就得让纸厂减产，这又伤害了纸厂。到底谁"该"让步，不是一个道德问题，而是一个**比较成本**的问题：哪种安排，总的损失更小？

他举过一个英国的法律案例（Sturges v Bridgman，1879 年）：一个糖果师傅在自家厨房里，用杵臼捣糖，已经用了很多年，没有人抱怨。后来，隔壁的医生在自家院子里盖了一间诊室，紧挨着糖果师傅的厨房，噪音和震动影响了他看病。法院判决糖果师傅停止使用机器。Coase 问：是糖果师傅"造成"了损害吗？没有医生的诊室，就没有这件"损害"。**两个人的活动，一起造成了冲突。**

## 二、科斯定理：谈判能找到最优

### 2.1 一个能算的例子

沿用上一讲纸厂的数字，换个角度看。纸厂这一方（包括它的买家）生产 q 吨得到的**净好处**是 B(q) = 80q − q²（边际好处 80 − 2q，和上一讲一样）；每多生产 1 吨，渔民损失 20。让两方直接谈判，价格由他们自己商量：

```python
# 第 23 讲的纸厂和下游的渔民，现在让他们直接谈判。
# 纸厂一方（含它的买家）生产 q 吨得到的净好处 B(q) = 80q - q^2（边际好处 80 - 2q，和第 23 讲同一个数）；每多生产 1 吨，渔民损失 D = 20。
D = 20
def B(q): return 80 * q - q * q
def joint(q): return B(q) - D * q                      # 双方合起来的好处

print("谈判卡在不同的产量上，双方合起来的好处是多少（最大值在 q=30）：")
for q in (0, 10, 20, 30, 40, 50):
    print(f"  q={q:>2}：纸厂 {B(q):>5}，渔民 {-D * q:>5}，合计 {joint(q):>5}")

best_q = max(range(0, 81), key=joint)
print(f"每吨试一遍：合计最大的是 q={best_q}，合计 {joint(best_q)}")

# 情形一：纸厂有权排污（默认：想排多少排多少，q=40）；渔民可以出钱，请纸厂少产
q0 = max(range(0, 81), key=B)
f0, p0 = B(q0), -D * q0
gain = joint(best_q) - joint(q0)
print(f"\n【纸厂有权排污】默认 q={q0}：纸厂 {f0}，渔民 {p0}，合计 {f0 + p0}")
print(f"  谈到 q={best_q}：纸厂少得 {f0 - B(best_q)}，渔民少受损害 {D * (q0 - best_q)}，净好处 {gain}；渔民付给纸厂的钱在 {f0 - B(best_q)} 到 {D * (q0 - best_q)} 之间")
pay = (f0 - B(best_q)) + gain / 2                       # 平分净好处
print(f"  平分净好处：渔民付 {pay:.0f}。结果：纸厂 {B(best_q) + pay:.0f}，渔民 {-D * best_q - pay:.0f}，合计 {joint(best_q)}")

# 情形二：渔民有权要求清洁的水（默认：q=0）；纸厂要出钱，才能生产
print(f"\n【渔民有权要求清洁的水】默认 q=0：双方都是 0")
print(f"  谈到 q={best_q}：净好处 {joint(best_q)}（纸厂得到 {B(best_q)}，渔民受损害 {D * best_q}）；纸厂付给渔民的钱在 {D * best_q} 到 {B(best_q)} 之间")
fee = D * best_q + joint(best_q) / 2
print(f"  平分净好处：纸厂付 {fee:.0f}。结果：纸厂 {B(best_q) - fee:.0f}，渔民 {fee - D * best_q:.0f}，合计 {joint(best_q)}")
```

输出：

```text

  q= 0：纸厂     0，渔民     0，合计     0
  q=10：纸厂   700，渔民  -200，合计   500
  q=20：纸厂  1200，渔民  -400，合计   800
```

![能谈判，就有人愿意买单：从 40 减到 30](/images/economics/24-coase.svg)

逐段看：

- **合计最大的产量是 30**：和上一讲庇古税的结果一模一样（产量 30，合计好处 900）。
- **纸厂有权时**：默认产量 40。从 40 减到 30，纸厂少得 100，渔民少受损害 200，**净好处 100**。只要渔民付的钱在 100 到 200 之间，双方都愿意。平分净好处，渔民付 150：最后，纸厂 1650，渔民 −750。
- **渔民有权时**：默认产量 0，双方都是 0。纸厂想生产 30 吨，能创造的净好处是 900，纸厂付给渔民的钱，在 600 到 1500 之间，双方都愿意。平分净好处，纸厂付 1050：最后，纸厂 450，渔民 450。
- **两种情形，产量都是 30，合计好处都是 900，但是分配天差地别**：渔民，一个是 −750，一个是 +450，相差 1200；纸厂，一个是 1650，一个是 450。

### 2.2 科斯定理

这个现象，被概括成**科斯定理**（Coase theorem；这个名字，其实是 George Stigler 1966 年起的）：

> 只要**产权界定清楚**，并且**谈判没有成本**（交易成本为零），那么，不管产权最初给谁，当事人通过谈判，都会达到**有效率的结果**。产权最初给谁，只影响**谁富谁穷**，不影响效率。

这个定理有几个意思：

- **不需要政府知道损害有多大**：渔民自己知道，纸厂自己知道，价格是他们自己谈出来的。
- **最优的结果，在两种产权下是一样的**：这和庇古税的最优产量相同。
- **价格不是唯一的**：渔民付 100 到 200 之间的任何数，都是双方愿意的，具体多少，取决于谁的谈判力强。
- **隐含的假设**：这里用钱来衡量好处，没有"收入效应"（富了之后会改变对污染的看法）。如果有，产权的分配，也会影响效率。

### 2.3 Coase 自己怎么看

很重要的一点：**Coase 本人，并不是在说"现实里谈判总能成功"。** 他把"交易成本为零"，当作一个**思想实验**。他真正想说的，是反过来的：**交易成本在现实里总是为正，而且常常很大**，所以，才需要法律来界定权利，才需要比较各种制度安排（法院、市场、企业、政府），看哪一种的总成本最低。

他 1937 年的《企业的性质》（*Economica*，4 卷 16 期）问过类似的问题：为什么有企业？因为用市场买卖来协调，每笔交易都要花**交易成本**；有时候，在企业内部用命令来协调，更便宜。1991 年，Coase 因为"发现和阐明交易成本、产权对制度结构和经济运行的意义"，获得诺贝尔经济学奖。

> **小结：** 科斯定理：产权清楚、交易成本为零时，不管产权给谁，谈判都会得到有效率的结果；产权只决定谁富谁穷。它不需要政府知道损害有多大。但 Coase 的重点是：现实里交易成本为正，所以制度的选择很重要。

## 三、现实里为什么常常谈不成

### 3.1 交易成本

谈成一笔交易，要花什么？找到对方、了解情况、谈判、起草协议、监督对方执行，甚至打官司。这些统称**交易成本**。

假设谈成一笔交易，要花固定的成本 T。双方只在**谈成的净好处不低于 T** 时，才会去谈；否则，停在默认的产量上。用代码看，谁有权，会怎么样：

```python
# 交易成本：谈成一笔交易要花固定的 T（找人、谈判、请律师、盯着对方履约……）。纸厂的净好处 B(q) = 80q - q^2，每吨的损害是 D。
def case(D, T, rights):
    """返回（最后的产量，合计好处，是否谈成）。双方只在"谈成的净好处 >= T"时才谈；谈不成，就停在默认的产量上。"""
    joint = lambda q: (80 - D) * q - q * q
    q_star = max(range(0, 81), key=joint)
    q_default = 40 if rights == "纸厂有权" else 0          # 谁有权，默认的产量就是他想要的
    gain = joint(q_star) - joint(q_default)                # 谈成能多出来的好处
    if gain >= T and q_star != q_default: return q_star, joint(q_star) - T, True
    return q_default, joint(q_default), False

for D in (20, 60):
    q_star = max(range(0, 81), key=lambda q: (80 - D) * q - q * q)
    print(f"\n每吨损害 {D}：最优产量 {q_star}，合计 {(80 - D) * q_star - q_star ** 2}（交易成本为 0 时，不管谁有权）")
    for T in (0, 50, 150, 400, 1000):
        a, b = case(D, T, "纸厂有权"), case(D, T, "渔民有权")
        better = "纸厂有权" if a[1] > b[1] else ("渔民有权" if b[1] > a[1] else "一样")
        print(f"  T={T:>4}：纸厂有权 -> 产量 {a[0]:>2}，合计 {a[1]:>6.0f}（{'谈成' if a[2] else '没谈成'}）；渔民有权 -> 产量 {b[0]:>2}，合计 {b[1]:>6.0f}（{'谈成' if b[2] else '没谈成'}）；更好的是：{better}")
```

输出：

```text
  T=   0：纸厂有权 -> 产量 30，合计    900（谈成）；渔民有权 -> 产量 30，合计    900（谈成）；更好的是：一样

  T=  50：纸厂有权 -> 产量 10，合计     50（谈成）；渔民有权 -> 产量 10，合计     50（谈成）；更好的是：一样
  T= 150：纸厂有权 -> 产量 10，合计    -50（谈成）；渔民有权 -> 产量  0，合计      0（没谈成）；更好的是：渔民有权
```

![交易成本高时，产权给谁就很重要](/images/economics/24-transaction.svg)

- **T 等于 0 或很小**（比如 50）：不管谁有权，产量都是最优的，合计好处一样。科斯定理成立。
- **损害 20，T = 150**：纸厂有权，从 40 减到 30 的净好处只有 100，不够付 150，**谈不成**，停在 40，合计 800；渔民有权，纸厂要生产，净好处 900，足够付 150，**谈成**，产量 30，但扣掉交易成本，合计 750。**这时，把权利给纸厂更好。**
- **损害 60，T = 150**：最优产量只有 10。纸厂有权，从 40 减到 10 的好处很大（900），谈成，合计 −50（扣掉了交易成本）；渔民有权，纸厂生产的净好处只有 100，不够付 150，**谈不成**，纸厂不生产，合计 0。**这时，把权利给渔民更好。**
- **规律**：交易成本高时，**默认的结果**（没有谈判时会发生什么）变得很重要。哪一方持有权利，默认结果就更接近他想要的。**把权利配置成"默认结果更接近有效率结果"的那一种，可以省掉大笔的交易成本。** 没有一个"永远对"的答案：损害不同，答案不同。

### 3.2 几个常见的障碍

- **人数多**：如果下游有 1000 户渔民，每户损失很小，要联合起来和纸厂谈，谁来牵头、谁出钱、怎么分？每个人都想让别人去谈，自己搭便车（第 18 讲的公共品博弈）。反过来，如果一个项目需要买下很多块地，**只要有一户不同意（"钉子户"），项目就做不成**，他可以要天价，这叫**敲竹杠**（holdout）问题。（这是逻辑分析，不是文献的结论。）
- **产权不清**：谁有权污染空气、谁有权使用公海的渔业资源、气候谁说了算，没人知道该和谁谈。
- **策略性行为**：双方都想多分一点，会虚张声势，威胁"谈崩"（第 18 讲的斗鸡博弈），谈判本身就可能失败。
- **私人信息**：这是第 22 讲的主题。

### 3.3 私人信息：连"零交易成本"也不够

第 22 讲讲过 Myerson–Satterthwaite 定理：即使产权清楚、谈判不花钱，只要双方的估值是私人信息，就**没有任何办法**，同时让两人说真话、自愿参加、每一笔有利的交易都发生。用代码把这个损失算出来：

```python
import random

# 产权清楚、谈判不花钱，但信息是私人的：卖家的成本 s 和买家的价值 v，各自只有自己知道，都在 0 到 1 之间均匀分布。
# 卖家和买家各自密封报一个价（卖家的要价 a、买家的出价 b）；b >= a 就成交，价格取中间 (a+b)/2。
random.seed(24)
N = 400000

# 一、两个人都说真话（a=s, b=v）时，只要 v > s 就成交，总好处的期望是 1/6
first_best = sum(max(random.random() - random.random(), 0) for _ in range(N)) / N
print(f"人人说真话时，成交的好处期望 {first_best:.4f}（理论 1/6 = {1 / 6:.4f}）")

# 二、但说真话不是卖家的最佳选择：买家说真话（b=v）时，成本 s=0.4 的卖家，要价多少最好？
def seller_gain(s, a, steps=2000):
    total = 0.0
    for i in range(steps):
        v = (i + 0.5) / steps
        if v >= a: total += (a + v) / 2 - s                # 买家的价值不低于要价，成交，价格是中间值
    return total / steps
best_a = max((i / 200 for i in range(0, 201)), key=lambda a: seller_gain(0.4, a))
print(f"买家说真话时，成本 0.4 的卖家：说真话（要价 0.4）好处 {seller_gain(0.4, 0.4):.4f}，最好的要价 {best_a:.2f}，好处 {seller_gain(0.4, best_a):.4f}")

# 三、双方都会"装"：均衡里，卖家要价 a = 2/3 s + 1/4，买家出价 b = 2/3 v + 1/12（Chatterjee–Samuelson 1983 的线性均衡）
gains = trades = beneficial = 0
for _ in range(N):
    s, v = random.random(), random.random()
    a, b = 2 / 3 * s + 1 / 4, 2 / 3 * v + 1 / 12
    if v > s: beneficial += 1
    if b >= a:                                             # 等价于 v - s >= 1/4
        trades += 1; gains += v - s
print(f"\n双方都按均衡'装'：成交的好处期望 {gains / N:.4f}（理论 9/64 = {9 / 64:.4f}），是'人人说真话'的 {gains / N / first_best:.0%}")
print(f"本来有好处的交易（v > s）占 {beneficial / N:.1%}，真正成交的占 {trades / N:.1%}：只有 {trades / beneficial:.0%} 的有利交易发生了")
s, v = 0.4, 0.6
a, b = 2 / 3 * s + 1 / 4, 2 / 3 * v + 1 / 12
print(f"例子：成本 {s}、价值 {v}（好处 {v - s:.1f}）：卖家要价 {a:.3f}，买家出价 {b:.3f}，{'成交' if b >= a else '没有成交'}")
print("成交的条件是 v - s >= 1/4：好处不到 0.25 的有利交易，全都没有发生")
```

![私人信息：产权清楚也谈不成所有有利的交易](/images/economics/24-trade-lost.svg)

- **说真话不是最优**：买家说真话时，成本 0.4 的卖家，要价 0.4（说真话）好处 0.09，要价 0.6 好处 0.12，**卖家会往上虚报**；对称地，买家会往下虚报。
- **双方都"装"之后**：均衡里，只有好处不低于 1/4 的交易才会成交。成交的好处期望是 9/64 ≈ 0.141，是"人人说真话"（1/6 ≈ 0.167）的 84%。本来有好处的交易里，只有 56% 发生了。
- **例子**：成本 0.4、价值 0.6，好处 0.2，卖家要价 0.517，买家只出 0.483，**没有成交**。图里，粉色的带，就是"有好处却丢掉的交易"。
- **这不只是这个报价规则的毛病**：据文献，对均匀分布，这个双方报价的规则，在所有"说真话、自愿参加、不靠补贴"的机制里，期望好处是最大的（我没有逐一核对原文的推导）；第 22 讲的定理说，没有任何机制能做到全部有利的交易都发生。**产权清楚，也不一定够。**

> **小结：** 现实里谈判常常谈不成：交易成本、人数多（搭便车、敲竹杠）、产权不清、策略性行为、私人信息。交易成本高时，权利怎么配置很重要：配置成默认结果更接近有效率结果的那一种，可以省交易成本。私人信息下，即使零交易成本，也谈不成所有有利的交易。

## 四、产权本身有什么用

### 4.1 为什么要有产权

Harold Demsetz 1967 年（《产权理论》，*American Economic Review*，57 卷 2 期）提出：**产权，是在"把外部性内部化"的好处，大于创设和维护它的成本时，才出现的。** 他用北美毛皮贸易的例子说明：毛皮贸易兴起、毛皮值钱以后，原来没有私人狩猎地的部落，就有了动机去划定自己的狩猎区，防止别人过度捕猎。

产权，大致有三个作用：

1. **激励投资**：谁拥有，谁就有动机去改良、保养。
2. **内部化外部性**：不让别人白占便宜，也不让自己的行为白白伤害别人。
3. **可转让**：让资源流向愿意出最高价的人（第 7 讲、第 22 讲）。

注意，**产权不等于私有**：可以是私人所有，也可以是集体所有、共同所有，关键是，**规则清楚、受保护、别人不能白占**。

上一讲的**排污权交易**，就是用这个想法：政府创设一种新的产权（排污许可），再让它交易（上一讲的第五节）。

### 4.2 证据：产权改革的效果

**理论预测什么**：产权清晰，会提高激励，提高产出。

**证据怎么说**：Justin Yifu Lin 1992 年（*American Economic Review*，82 卷 1 期）研究中国 1978 年到 1984 年的农村改革。这几年，农业产出增长很快，同时发生了几件事：从集体生产，改成家庭承包（"去集体化"，把土地的使用和收益的权利，较多地交给了农户），政府提高了农产品收购价格，其他的改革。他用省级的面板数据估计，**去集体化提高了全要素生产率，大约解释了这一期间农业产出增长的一半**；收购价格的提高也有贡献，主要通过增加投入。

**局限**：这类估计很难，因为**制度变迁本身不是随机的**：哪个地方先搞包产到户、什么时候搞，往往和当地的条件有关，不能简单地把产出的增加，都归于制度；同时发生的价格调整，也要分开。后来的研究，专门讨论了这个识别难题（请读原文）。所以更稳妥的结论是：**产权改革，很可能是中国农业增长的重要原因之一，但"到底占多少"，不同研究的数字不同。**

## 五、一个有争议的问题：能不能把一切交给产权与谈判

按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：零交易成本、产权清楚时，不管产权给谁，都有效率。如果这在现实里近似成立，政府不必定税、定总量，只要界定产权就够了。

**证据怎么说**：

- **实验室里的支持**：Elizabeth Hoffman 和 Matthew Spitzer 1982 年（*Journal of Law and Economics*，25 卷 1 期）首次在实验室里检验科斯定理，大体证实了：两人谈判时，合起来的好处，多数能达到最大。Glenn Harrison 和 Michael McKee 1985 年（同一刊物，28 卷 3 期）修改了设计，使合作对个人来说是理性的，发现，合起来的好处最大化，并不那么普遍，有没有"能谈钱"的安排，很关键。
- **实验室里的反例**：Daniel Kahneman、Jack Knetsch 和 Richard Thaler 1990 年（*Journal of Political Economy*，98 卷 6 期）做了有名的咖啡杯实验：随机给一半的学生一个杯子，再让大家交易。按科斯定理，大约一半杯子应该易手；实际成交量**显著低于**预测，而且拿到杯子的人，愿意接受的价格，远高于没拿到的人愿意付的价格（**禀赋效应**）。交易成本不能解释（用代币做的类似实验，成交量接近预测）。也就是说，**产权最初给谁，会影响人们的估值，从而影响结果**。（第 39 讲讲行为经济学时会回来。）据后来文献的转述，另一些研究（如 Plott 和 Zeiler 2005 年、List 2003 年）发现，在某些条件下，这个效应会缩小甚至消失，所以也有争议。

**局限**：实验的标的很小，被试是学生，规则被简化；现实里的产权、交易成本，比实验复杂得多。

**分歧在哪**：

- **事实上的分歧**：科斯定理在多大程度上、哪些情形下，是现实的好近似？
- **政策上的分歧**：有人据此认为，应该"界定产权，让市场去谈"，尽量少用管制；也有人认为，现实里交易成本太高、信息太不对称，管制和税更可靠。**Coase 自己的立场是**：具体问题具体分析，比较各种制度安排的成本，不是"政府总是坏"，也不是"市场总是好"。

**价值判断（留给你）**：

1. **产权的初始分配，该怎么定？** 谁先占谁有权？受害者有权？还是最需要的人有权？在效率上，零交易成本下不重要；在分配上，一个变成 +450，一个变成 −750。
2. **谈判力悬殊时**（一家大企业，对零散的农户），"自愿谈成"的结果，公平吗？
3. **哪些东西，不该变成可以买卖的产权？** 清洁的空气、人体器官、投票权？这个问题，经济学能告诉你交易的收益和成本，不能替你回答。

## 六、局限、常见误用

### 6.1 局限

- **条件很强**：产权清楚、交易成本为零、没有收入效应。现实里，三条都常常不满足。
- **人数多时**，搭便车和敲竹杠会让谈判失败。
- **私人信息**：即使零交易成本，也谈不成所有有利的交易（第 22 讲，本讲第 3.3 节）。
- **人的估值不稳定**：禀赋效应说明，产权的分配会影响估值。
- **分配问题**：效率不变，但谁富谁穷，由初始产权决定，这是价值判断。

### 6.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "科斯定理说，政府不用管外部性" | 它说的是零交易成本下的情形；Coase 自己强调现实交易成本为正，要比较制度 |
| "产权给谁无所谓" | 零交易成本下，效率无所谓，分配有所谓；交易成本为正时，效率也有所谓 |
| "谈判一定公平" | 价格取决于谈判力；谈判力悬殊时，结果可能不公平 |
| "产权等于私有" | 产权可以是私有、集体、共同；关键是规则清楚、受保护 |
| "产权清楚了，外部性就不存在了" | 它只是让内部化成为可能，要有人愿意谈、谈得起 |
| "谁造成的损害谁负责" | Coase：损害是相互的，要比较各种安排的总成本 |
| "市场总能自己解决外部性" | 条件很强；现实里常常需要法律、税或管制 |

## 七、小结

这一讲有六个想法，请带走：

1. **科斯定理**：产权清楚、交易成本为零时，不管产权给谁，谈判都会达到有效率的结果，产权只决定谁富谁穷。
2. **不需要政府知道损害**：当事人自己知道，价格自己谈出来；在纸厂的例子里，两种产权下，产量都是最优的 30，合计好处都是 900，但渔民的所得，一个是 −750，一个是 +450。
3. **Coase 的真意**：交易成本在现实里总是为正；重要的是比较各种制度安排（法院、市场、企业、政府）的成本。
4. **谈不成的原因**：交易成本、人数多（搭便车、敲竹杠）、产权不清、策略性行为、私人信息。交易成本高时，把产权配置成默认结果更接近有效率结果的那一种，可以省成本。
5. **私人信息**：零交易成本也谈不成所有有利的交易（第 22 讲的 Myerson–Satterthwaite），双方都"装"之后，只有 56% 的有利交易发生，好处是人人说真话时的 84%。
6. **产权的作用与争议**：激励、内部化、可转让；中国农村改革是重要案例，但归因很难；实验里，产权的分配会影响估值（禀赋效应）。初始产权该怎么分、谈判力悬殊时是否公平，是价值判断。

前面，我们都假设：能找到"受害者"，也能找到"受益者"，他们**可以被排除在外**：不付钱，就不让你用。可是有些东西，**没法排除别人**：一座灯塔，路过的每一艘船都能看到；国防，保护着每一个人；一片没人管的草场，谁都能去放牧。**这时，谁来付钱？谁来保护？** 这就是下一讲：**第 25 讲：公共品与公地悲剧。** 你会看到，为什么这些东西，市场往往提供得太少，或者被用得太多，以及人们想到过哪些办法。

## 思考题

**1.** 3.1 节的纸厂，如果每吨损害是 50，谈成一笔交易的交易成本是 300：（a）纸厂有权时，最后的产量和合计好处是多少？（b）渔民有权时呢？哪一种更好？为什么？

> 提示：最优产量：(80 − 50)q − q² 最大，q = **15**，合计好处 225。（a）纸厂有权：默认 q = 40，合计 −400；谈成能多得 625 ≥ 300，**谈成**，产量 15，合计 225 − 300 = **−75**。（b）渔民有权：默认 q = 0；纸厂生产的净好处最多 225 < 300，**谈不成**，产量 0，合计 **0**。**渔民有权更好**（0 > −75）：这里损害很大，最优产量（15）离"纸厂有权"的默认产量（40）很远，离"渔民有权"的默认产量（0）近得多，不如不谈，省下交易成本。

**2.** 2.1 节的纸厂（损害 20，交易成本为 0），如果政府要决定"污水排放权"最初归谁。从效率看，两种分法有差别吗？从分配看呢？渔民和纸厂分别更希望权利归谁？

> 提示：**效率上没有差别**：两种分法，合计好处都是 900。**分配上差别很大**：渔民在纸厂有权时是 −750，在渔民有权时是 +450，相差 1200；纸厂在纸厂有权时是 1650，在渔民有权时是 450，相差 1200。两方都更希望权利归自己。注意：争的是分配，不是效率。当初始产权本身值很多钱时，双方都有动机花资源去争取它（这类"为了争取好处而花掉的资源"，第 26 讲讲寻租时会回来）。

**3.** 3.3 节的私人信息模型（成本和价值都在 0 到 1 之间均匀分布，卖家要价 a = 2/3 × 成本 + 1/4，买家出价 b = 2/3 × 价值 + 1/12）：成本 0.5、价值 0.7 会成交吗？成本 0.3、价值 0.7 呢？成交价是多少？

> 提示：成本 0.5、价值 0.7：要价 a = 2/3 × 0.5 + 1/4 ≈ 0.583，出价 b = 2/3 × 0.7 + 1/12 = 0.55，b < a，**不成交**（好处 0.2，不到 0.25）。成本 0.3、价值 0.7：a = 0.45，b = 0.55，b ≥ a，**成交**，价格 = (0.45 + 0.55) ÷ 2 = **0.5**（好处 0.4 ≥ 0.25）。

**4.** 两个村子，各有一片草场。甲村把草场分给每家农户长期使用（有权保养、放牧，也有权转让），乙村的草场是全村共用，谁都可以去放牧。用本讲的想法，比较两个村子里，农户保养草场的动力。这个比较，还缺什么证据？

> 提示：甲村：保养草场的好处，归农户自己（包括以后转让时，草场更值钱），保养的动力强。乙村：每个农户多放一头牛的好处归自己，草场退化的成本由全村分担，是外部性，每个人都想多放，保养的动力弱（第 25 讲会系统讲）。**缺的证据**：两个村子的草场本来好坏、人口、气候是不是一样？乙村有没有村规、社区自己的管理办法（Ostrom 的研究说，有些共同所有的资源，也管理得很好）？最好的证据，是同一个地方、同一批农户，在产权改革前后的比较，还要小心改革本身不是随机的。

**5.** 小区楼下的广场舞，音乐影响了楼上的居民。用本讲的想法，分析：谁有权？谈判的障碍是什么？可能的办法有哪些（社区协商、噪音管制、划定时间和区域）？各适用于什么条件？

> 提示：**谁有权**：小区的公共空间，产权不清楚：居民有安静的利益，跳舞的人有活动的利益，谁该让步没有现成的答案（Coase 的"相互性"）。**障碍**：人数多（一个小区几百上千户，搭便车），谈判成本高，各方信息不对称（不知道对方有多在乎）。**办法**：（1）社区协商，约定时间、音量，由居委会、业委会出面组织，是降低交易成本的做法，适合人数不太多、长期相处、容易达成共识的情形；（2）噪音管制，由法律规定标准，适合人数多、谈判成本高、难以自己组织的情形（庇古式或管制的办法）；（3）划定时间和区域，是一种数量管制，加上产权安排（哪个区域归谁在什么时间使用）。选哪一种，取决于交易成本的高低，以及谁的"安静"和"娱乐"该优先的价值判断。
