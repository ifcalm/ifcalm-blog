## 一、再等等，就更便宜

你想买一台 5000 元的洗衣机。你知道，物价，每年，下降 2%，明年，它只要 4900 元，后年，4802 元。

**先停一下：你，是现在买，还是，再等等？如果，所有的人，都这么想，会怎样？**

想一想：再等等，更便宜；所以，**每一个人，都有理由，推迟消费**。可是，如果，所有的人，都推迟，企业，卖不出去，只好，**降价、裁员、减少投资**；工资，下降，收入，下降，人们，更不愿意花钱；物价，更低……这是一个，**自我强化的螺旋**（第 17 讲：预期的自我实现；第 32 讲：总需求）。

更糟的是，**你的债务，不会，跟着，降价**：你借了 100 万，每月还款，是固定的**名义**金额；你的工资，和物价，一起，在降；**同样的还款，占你收入的比例，越来越高**。这就是 Irving Fisher，1933 年说的**债务通缩**（第 44 讲）。

**但是，物价下降，不一定是坏事**（第 33 讲）：如果，是因为**技术进步**，成本下降（比如，电子产品，一直，在降价），那是**好的通缩**：产出，在增加，工资，没有下降；Atkeson 和 Kehoe 2004 年，Borio 等人 2015 年，发现，历史上，物价下降，和萧条，只有，很弱的联系（大萧条除外）；**更坏的是，伴随着，资产价格下跌、债务问题的通缩**。日本，就是后一种的例子。

## 三、通缩，为什么难办

### 3.1 两个算术

```python
# 通缩，为什么，是坏事：两个算术。
# 一、债务通缩（Fisher，第 44 讲提到过）：债务，是名义的（固定的货币金额）；物价，每年下降 d，你的名义收入，也下降 d。
#    你借了 300 万，贷款，每年的还款，是固定的名义金额 P。n 年之后，P 占你的收入的比例，变成多少？
debt_service, income = 20.0, 80.0                 # 万元：每年还 20，收入 80（还款，占收入的 25%）
print("一、每年，还款的名义金额，不变（20 万）；收入，随物价，每年变化：还款，占收入的比例")
for infl in (0.02, 0.0, -0.01, -0.02, -0.03):
    row = []
    for n in (0, 5, 10, 20):
        inc = income * (1 + infl) ** n
        row.append(f"{n:2d} 年后 {debt_service / inc:5.1%}")
    print(f"   物价和收入，每年 {infl:+.0%}：" + "，".join(row))
# 二、零利率下限（第 31 讲）：名义利率，不能（明显）低于 0。实际利率 = 名义利率 - 通胀。
#    设：经济，需要的实际利率，是 r* = 1%（这样，才能让总需求，等于潜在产出；r* 是示意的）。央行，需要的名义利率 = r* + 通胀预期；但是，名义利率 >= 0。
rstar = 0.01
print("二、需要的名义利率，和，能做到的名义利率（r* = 1%，示意）：")
for infl in (0.03, 0.02, 0.0, -0.01, -0.02, -0.03):
    need = rstar + infl
    can = max(need, 0.0)
    real = can - infl
    gap = max(real - rstar, 0.0)
    print(f"   通胀 {infl:+.0%}：需要的名义利率 {need:+.0%}，能做到的 {can:+.0%}，此时的实际利率 {real:+.0%}，比需要的，高 {100 * gap:.0f} 个百分点" + ("   <- 达不到" if need < 0 else ""))
# 三、利率，回升的时候（第 34 讲）：债务，是 GDP 的 2 倍（200%）；如果，所有的债务，都按更高的利率，重新定价（上限，不考虑期限结构）：
debt = 2.0
print("三、（示意，上限）债务 = GDP 的 200%，全部，按新利率，重新定价：利息，占 GDP 的比例")
for r in (0.005, 0.01, 0.02, 0.03):
    print(f"   平均利率 {r:5.1%}：利息 = {debt * r:.1%} 的 GDP")
```

- **第一部分：债务通缩**。每年还 20 万，收入 80 万（占 25%）。**物价和收入，每年上涨 2%**：20 年后，还款，只占 16.8%（负担，变轻了：通胀，在帮债务人）；**不变**：25%；**每年下降 2%**：20 年后，**37.4%**；下降 3%：**46%**。**同样的债务，名义上，一分没变，实际上，越来越重。** 所以，通缩的时候，债务人，被迫，减少消费、变卖资产，来还债，这又压低价格和需求（第 35 讲：杠杆的螺旋）。
- **第二部分：零利率下限**。设，经济，需要的实际利率，是 1%（示意）。通胀，是 +2%，央行，把名义利率，定在 3%，就行；通胀，是 −1%，要 0%，**刚好**；通胀，是 **−2%**，要 **−1%**：**做不到**（名义利率，不能，明显，低于 0，因为，人们，可以，持有现金，而现金，利率是 0），实际的利率，被迫，是 +2%：**比经济，需要的，高 1 个百分点**；−3% 时，高 2 个百分点。**物价，越是下降，央行，越是，没有办法，把实际利率，压下去。**（第 31 讲，7.1 节。）**这就是，为什么，大家，都害怕，从温和的通缩，滑进，通缩的陷阱。**
- **第三部分**（先放在这里，第六节会用）：如果，债务，是 GDP 的 200%，所有的债务，按新的利率，重新定价（上限，不考虑期限结构），平均利率，从 1% 到 2%，利息，从 2% 到 4% 的 GDP。

### 3.2 僵尸企业

通缩，常常，和**银行问题**，一起出现。银行，借给企业的钱，企业，还不上了，银行，如果，承认，就要，核销，自己的资本，可能，不够（第 35 讲）：于是，银行，选择，**展期**：让企业，继续，借新还旧，把损失，往后拖。这种企业，叫**僵尸企业**。Caballero、Hoshi 和 Kashyap 2008 年（*American Economic Review*，98 卷 5 期，1943–1977 页）：据摘要，在日本，银行，通过虚假的重组，让资不抵债的企业，继续存活；**僵尸企业的增加，压低了健康企业的投资和就业的增长**，也拉大了两类企业的生产率的差距。

```python
# "僵尸企业"的玩具（Caballero、Hoshi 和 Kashyap 2008 的想法，我做了最简化）：
# 市场的需求：P = 100 - Q。健康的企业：每单位产量，真实的成本，是 40；可以自由进入（长期里，价格，会压到 40）。
# 僵尸企业：每单位产量，真实的成本，是 60（效率低）；但是，银行，一直，借给它钱、不要求还（"展期"），所以，它，只要价格不是负的，就继续生产；它的产能，是 Z。
def market(Z, cost_h=40, cost_z=60):
    if Z <= 100 - cost_h:                       # 僵尸的产能，没有大到，把价格，压到低于健康企业的成本
        P, Qh = cost_h, (100 - cost_h) - Z
    else:                                       # 太大：价格，被压到 100 - Z < 40，健康企业，全部，没法活
        P, Qh = 100 - Z, 0
    Q = Qh + Z
    real_cost = cost_h * Qh + cost_z * Z        # 生产这些，用掉的真实资源
    return P, Qh, Q, real_cost

print("僵尸企业的产能 Z：市场价格、健康企业的产量、总产量、用掉的真实资源、每单位产出的资源成本")
base_cost = None
for Z in (0, 10, 20, 30, 40, 50, 60, 75):
    P, Qh, Q, rc = market(Z)
    unit = rc / Q
    if base_cost is None: base_cost = unit
    print(f"   Z = {Z:2d}：价格 {P:4.1f}，健康企业的产量 {Qh:4.1f}，总产量 {Q:4.1f}，真实资源 {rc:6.1f}，每单位 {unit:5.2f}（比 Z=0 时，高 {unit / base_cost - 1:5.1%}）")
print("   解释：Z <= 60 时，价格，被健康企业的成本，钉在 40：每有一个单位的僵尸产能，健康企业，就少生产一个单位（被'挤出'）；总产量不变，但是，为了这些产量，用掉的资源，更多：效率下降。")
print("   Z > 60 时，价格，被压到低于 40：健康企业，全部退出；价格，对消费者，更低了，但是，整个行业，是低效率企业，用更多资源，生产出来的。")
```

   Z =  0：价格 40.0，健康企业的产量 60.0，总产量 60.0，真实资源 2400.0，每单位 40.00（比 Z=0 时，高  0.0%）

## 四、一个有争议的问题："失去的三十年"，是什么造成的

按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：有几套解释，不互相排斥：

- **货币政策，太晚、太紧、不够**（Krugman 1998 年，*Brookings Papers on Economic Activity*；Bernanke 2000 年）：日本央行，在 1989–1990 年，加息，太猛；泡沫破裂后，反应，太慢；到了零利率，又没有，足够有力地，用"非常规"的办法（比如，承诺，更高的通胀）。Bernanke 的说法，是，日本的货币政策，"自我造成的瘫痪"。
- **资产负债表衰退**（Richard Koo，2003 年）：泡沫破裂，让企业的资产，缩水，债务，还在；企业的目标，从"赚钱"，变成"还债"：**即使，利率是零，也不借钱、不投资**；这时，货币政策，没用，**只有政府，当"借款人"**（财政政策），才能，填补缺口。
- **僵尸银行、僵尸企业**（Caballero 等人 2008 年）：见上一节。
- **生产率和人口**（Hayashi 和 Prescott 2002 年，*Review of Economic Dynamics*，5 卷 1 期，206–235 页）：据摘要，他们认为，1990 年代，日本的问题，**不是**，金融系统的崩溃（企业，能借到钱），而是，**生产率增长，太低**；还有，劳动时间的减少。

## 五、一个有争议的问题：日本央行的实验，有没有用

**理论预测什么**：零利率之后，央行，还可以：**量化宽松**（买债券，增加准备金）、**承诺**（让人们，相信，会长期，保持低利率，或者，容忍，更高的通胀）、**负利率**、**收益率曲线控制**（压住长期利率）（第 31 讲，第七节）。如果，这些，能改变预期，通胀，会回到 2%。

**证据怎么说**：

- **事实**（第二节，代码 1）：2013 年，QQE，目标，2 年内，2%；2014 年，通胀，到了 2.76%（CPI），但是，**那一年 4 月，消费税，从 5% 提高到 8%**，把物价，**机械地**，推高了；2015 年，0.8%；2016–2021 年，大部分时间，在 0 到 1% 之间。**直到 2022 年，才持续，高于 2%**，而那一次，是**全球的**供给冲击和能源价格（第 32、33 讲），**不是**，日本自己的需求。
- **实际利率**：1999–2005 年，实际隔夜利率，是**正的**（0.49%）：**名义的零，没有，转化成，足够低的实际利率**（零利率下限）；2016–2023 年，实际利率，−0.95%，但是，通胀，仍然，只有 0.9%。
- **央行的资产负债表**：据报道，日本央行，持有，约 **48%** 的日本国债（2026 年）；2026 年 6 月，据报道，它，决定，到 2027 年 4 月起，停止，削减购买的步伐，每月，维持约 2 万亿日元的购买。

**怎么读**：（1）**很难，把"政策的效果"，和"别的因素"，分开**：QQE 之后的几年，物价，只涨一点；2022 年之后，涨了：是 QQE 的"迟到的"效果，还是，外部的冲击？**数据，分不开**；（2）**"没有，立刻，达到 2%"，不等于，"没用"**：没有，政策，会怎样？（反事实）；（3）**负的实际利率，持续了很多年，通胀，仍然很低**，说明，**不是，只靠，利率，就够**。

**局限**：每一种政策，都，叠加，在别的政策（财政、税收）上（比如，2014 年的消费税）；**样本，只有一个国家**。

**分歧在哪**：事实上：QQE，对通胀预期，有多大的作用；2022 年的通胀，有多少，是，货币政策的遗产。目标上：央行，**是该**，把通胀，推到 2%，**还是，该**，更关注，金融稳定和财政成本？

**价值判断（留给你）**：

1. **央行，持有近一半的国债，意味着什么**：它，帮助政府，以低利率，借钱；**这是，货币政策，还是，财政政策**？（第 31 讲：央行的独立性）
2. **长期的低利率，谁受益，谁受损**：借款人和政府，受益；储蓄的人，受损；资产的持有人，受益（股价，在上涨）。
3. **要不要，容忍，更高的通胀**，来换取，更低的实际债务负担？

## 六、今天的日本：走出来了吗

下面是**事实**（据官方的数据和报道，请以原文为准）：

- **物价**：2022 到 2025 年，CPI，2.5%、3.3%、2.7%、3.2%（世界银行）。2026 年 8 月：全体，**1.9%**，**核心**（不含生鲜食品，日本央行，偏好的指标），**1.7%**，不含生鲜食品和能源，**1.9%**（用 2025 年做基期的新数据；能源价格，在 8 月，因为电费调整，下降）。
- **工资**：2026 年的春季劳资谈判（"春斗"），工会联合会（连合）的最终结果，加薪 **5.01%**（5368 家公司），是**连续第三年**，超过 5%（1989–1991 年之后，第一次）；基本工资，3.5%。**实际工资**，2026 年 8 月，同比，+1.5%，连续第 8 个月，上涨；但是，据一项分析，2022 到 2025 年，实际工资，**每年，都在下降**，累计，比 2021 年，约低 5%。
- **央行**：2026 年 6 月，加息到 **1.0%**；9 月 18 日，再加 0.25 个百分点，到 **1.25%**，**7 比 2** 的投票（两位委员，反对：理由，是，核心 CPI，最近，低于 2%，物价，还没有，加速到，足以，支持，加息）；央行的声明，说，**潜在的通胀，在接近 2%**。
- **国债**：10 年期国债收益率，2026 年 9 月下旬，约 **3.07%**，据报道，是 1996 年以来的最高；10 月中旬，约 2.9% 到 3.1%（各来源，不同）。（FRED：2026 年 8 月，2.94%。）国际货币基金组织，2026 年 9 月的文章：日本的政府总债务，超过 GDP 的 **200%**，**净债务，要低得多**（各个版本的 IMF 数据，口径，不同，总债务，约 206% 到 230%）。

**理论预测什么**：

- **"好的"退出**：工资，涨了，物价，涨了，通胀，稳定在 2% 附近：通缩，被**需求和工资**，推出去了。
- **"风险"**：（1）**外部冲击**：2022 年以来，物价，来自，进口的成本（能源、日元贬值，第 41 讲）；如果，是**一次性的**冲击，**消退**之后，物价，可能，又回去；（2）**债务**：第三节代码 2 的第三部分：如果，利率，持续，上升，政府的利息负担，会增加；（3）**加息，会不会，压垮脆弱的部分**（住房贷款，还在浮动利率的家庭、依赖低利率的企业）。

**证据怎么说**：现在，**还看不出来**：工资，三年，涨超过 5%，这是，30 年来，没有过的；但是，实际工资，才刚刚，转正；央行内部，2 比 7，反映了，**真实的分歧**：核心通胀，是不是，真的，稳定在 2%。

**价值判断（留给你）**：日本央行，**该，更快**加息（担心，物价，失控、日元，贬值）？还是，**更慢**（担心，经济，还没有，稳固，政府的债务成本）？

## 七、一个有争议的问题：中国，是不是，在重走日本的路

这是 2023 年以来，一个很热的问题（第 33 讲：中国近年的低通胀；第 44、45 讲：房地产和地方债）。按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：**类比**的逻辑：日本，1990 年代：（1）资产（地产、股票）泡沫，破裂；（2）银行，积累坏账；（3）物价，持续，下降；（4）人口，老龄化；（5）增长，放慢。中国，2021 年以后：（1）房地产，大幅，下行（第 44 讲）；（2）地方债，和土地财政（第 45 讲）；（3）GDP 平减指数，从 2023 年第二季度起，**连续 12 个季度，为负**（第 27、33 讲）；（4）人口，2021 年，达到最高点（第 43 讲）；（5）增长，放慢（第 27 讲）。如果，这些，是，同一种病，那么，中国，可能，也会，进入，很长时间的停滞。

**证据怎么说**（代码 4 的第二部分，世界银行的数据）：

| 指标 | 日本，1992 年（泡沫破裂后的第 2–3 年） | 中国，2024 年 |
|------|------------------------------------|--------------|
| 人均 GDP，相对美国（购买力平价） | **84%** | **31%** |
| 15–64 岁人口占比 | 70.0%（最高点） | 69.3%（最高点是 2009–2010 年，72.9%） |
| 65 岁以上的人口占比 | 13.2% | 14.7% |
| 实际 GDP 增长（当年） | 0.85%（次年，1993 年，−0.5%） | 4.96% |

- **收入水平，差别，很大**：日本，泡沫破裂时，人均收入，已经，是美国的 **84%**，**追赶，基本，完成**；中国，今天，是美国的 **31%**：**还有，很大的追赶空间**（第 28 讲：条件趋同，第 29 讲）。这可能，意味着，**同样的冲击，对中国的长期增长，影响，更小**；也可能，意味着，**在没有追赶完成之前，就老龄化**（"未富先老"）。
- **人口**：中国，2024 年，15–64 岁的占比，69.3%，已经，下降了 3.5 个百分点（从 2009–2010 年的最高点）；65 岁以上，14.7%，**已经，高于**，日本 1992 年的 13.2%。**中国，在人口上，比日本，当年，更"老"**；但是，日本，1992 年之后，又老了很多（2024 年，65 岁以上，29.8%）。
- **物价**：2026 年第二季度，据报道，中国的 GDP 平减指数，**同比，转正**（约 1.6%；名义增长，5.9%，实际，4.3%），结束了，连续 12 个季度的下降；**据报道**，这主要来自，能源价格上升、AI 供应链的成本上升，**不是**，国内需求的回升（见第 33 讲，2026 年更新：PPI，上游，涨，消费品，还在降）。**所以，这一次的"转正"，不能，直接，说明，"走出了通缩"。**
- **性质的不同**：有人认为，日本的通缩，是**需求**的崩溃（泡沫，破裂之后）；而中国的价格下降，是，**供给过剩**（产能，太大，价格战）的故事（Asia Times 的一篇评论，据报道）；也有人，认为，中国，面临，通缩，加上，汇率压力的"有毒组合"，是日本没有的。**这是，观点，不是，事实**。
- **有人，认为，已经，摆脱了**（Bloomberg 的一篇通讯，2026 年 4 月，据报道）；**有人，认为，还没有**（Eurasia Group，据报道）。

**局限**：（1）**类比，是一个，思考的工具，不是证据**：每个国家，都不同；（2）**日本，只是一个样本**；（3）**数据，口径不同**：中国的数据，国际上，有争议（第 27 讲）；（4）**时间，还太短**：中国的下行，才 5 年，日本，是 30 年。

**分歧在哪**：

- **事实上的分歧**：中国的价格下行，有多少，是需求不足，多少，是供给过剩；银行的坏账，有多大；人口，老化，对增长的影响，有多快。
- **政策上的分歧**：要不要，更大的财政刺激（第 34 讲）；要不要，更快地处理，房地产和地方债的风险（第 44、45 讲）；还是，**靠，结构性的改革**（第 29 讲）。

**价值判断（留给你）**：

1. **日本的经验，教了我们什么**：是"**早点，出清坏账**"，是"**更大胆的货币和财政政策**"，是"**接受低增长，保持社会稳定**"？不同的人，会，读出，不同的教训。
2. **短期的痛，和长期的拖累**：要不要，为了避免，现在的失业和倒闭，而，推迟调整？
3. **谁，承担调整的代价**：家庭、企业、银行、地方政府，还是中央？（第 35、44、45 讲）

## 八、局限、常见误用

### 8.1 局限

- **只有一个国家**：日本，是一个样本；它的制度、人口、银行体系、国际地位，都有它自己的特点；
- **数据**：世界银行、FRED 的数据，会修订；2026 年的数据，是初步的；**日经、国债收益率**，是市场数据，天天在变；
- **玩具模型**：第三节，都是示意的，数字，是编的，只显示机制；
- **文献**：多数，只引用了摘要；而且，大部分，早于 2010 年；
- **没有讲**：日本的泡沫，是怎么形成的（1980 年代的金融自由化、汇率）；日本的社会保障；日元和贸易；其他国家的通缩（比如，1930 年代、欧元区）；
- **不是政策建议，也不预测。**

### 8.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "物价下降，就是通缩，通缩，就是坏事" | 要看原因：技术进步的通缩，是好的；伴随着债务和需求崩溃的，是坏的（第 33 讲） |
| "日本，30 年，没有增长" | 总量的 GDP，增长很慢；但是，按每个 15–64 岁的人算，1995–2019 年，年均 1.49%，和美国，差不多 |
| "日本的失业，很严重" | 失业率，最高，5.6%；2019 年，2.5% |
| "日本，一直，通缩" | 1995–2013 年，GDP 平减指数，下降了 18 年（之外，1997 年）；但是，CPI，大部分时候，是在 0 附近，小幅波动 |
| "QQE 没有用，因为，没有达到 2%" | 没有 QQE，会怎样？反事实，看不见；2014 年的通胀，主要来自，消费税 |
| "日本，已经走出了通缩" | 物价、工资，都在回来；但是，核心通胀，仍然，低于 2%（2026 年 8 月：1.7%），央行内部，有分歧 |
| "中国，就是下一个日本" 或者 "中国，不是日本" | 类比，有相同，也有很大的不同；是一个，要问的问题的清单，不是结论 |
| "GDP 平减指数，转正，说明通缩，结束了" | 要看，原因（能源，还是需求），和别的指标（消费品价格、核心 CPI、工资） |

## 九、小结

这一讲有七个想法，请带走：

1. **通缩，是持续的、普遍的物价下降**；技术进步带来的，是好的；伴随着债务和需求崩溃的，是坏的；
2. **日本**：1990 年泡沫破裂（日经，下跌 82%，34 年后，才恢复）；1995–2013 年，GDP 平减指数，下降了 18 年；零利率，实际利率，却是正的；
3. **债务通缩**：名义债务，不变，收入，随物价下降，还款的负担，越来越重；**零利率下限**：物价，越是下降，央行，越难，把实际利率压下去；
4. **僵尸企业**：银行，展期，让低效率的企业，占着位置，把健康企业，挤出去，效率下降；
5. **失去的三十年**：多种解释（货币政策、资产负债表、僵尸银行、生产率和人口）；按每个 15–64 岁的人算，1995–2019 年，日本，1.49%，美国，1.61%：人口，是很大一部分；
6. **央行的实验**：QQE、负利率、收益率曲线控制，效果，难以和别的因素分开；2022 年的通胀，主要，是外部的冲击；2026 年，日本央行，加息到 1.25%；
7. **中国，像日本吗**：有相似（房地产下行、物价、人口），也有很大的不同（收入水平：日本，当年，84%，中国，31%）；2026 年第二季度，GDP 平减指数，转正，主要，来自能源。**事实，我用数据；价值，留给你。**

日本，是一个国家的老龄化和通缩的故事；**下一讲，换到，每个人，迟早，都要面对的问题：养老。** **下一讲：第 49 讲：养老金与老龄化。**

## 思考题

**1.** 一个人，每年还 30 万，收入 100 万。物价和收入，每年下降 2%，10 年后，还款，占收入的比例，是多少？如果，每年，上涨 2%，呢？

> 提示：收入，10 年后：100 × 0.98^10 ≈ 81.7；30 ÷ 81.7 ≈ **36.7%**；上涨：100 × 1.02^10 ≈ 121.9；30 ÷ 121.9 ≈ **24.6%**。（原来，30%：通缩，让负担，增加了 6.7 个百分点；通胀，减少了 5.4 个百分点。）

**2.** 经济，需要的实际利率，是 0.5%。通胀，是 −1.5%，央行，能做到的名义利率，是 0：实际利率，是多少？比需要的，高多少？通胀，要上升到多少，央行，才有，足够的空间？

> 提示：实际利率 = 0 − (−1.5%) = **+1.5%**，比需要的，高 **1 个百分点**；需要的名义利率 = 0.5% + 通胀：通胀 ≥ **−0.5%**，名义利率，才能，≥ 0，这时，才没有，被零利率下限，卡住。

**3.** 用第三节的僵尸企业：如果，僵尸产能 Z = 45，健康企业的产量，是多少？每单位产出，用掉的资源，比 Z = 0 时，多多少？

> 提示：Z ≤ 60：价格 40，健康产量 = 60 − 45 = **15**；真实资源 = 40 × 15 + 60 × 45 = 600 + 2700 = 3300；每单位 = 3300 ÷ 60 = **55**，比 40，多 **37.5%**。

**4.** 日本，1995–2019 年：总量，年均增长 0.83%，而每个 15–64 岁的人，是 1.49%。如果，15–64 岁的人口，没有减少，而是，不变，总量的增长，会是多少（近似）？

> 提示：总量的增长 ≈ 每个工作年龄的人的增长 + 工作年龄人口的增长：0.83% ≈ 1.49% + (−0.66%)。如果，人口不变，总量，约 **1.49%**，**比实际，高 0.66 个百分点**。（近似，对数；这只是**算术**，不是"如果，人口，不减少，日本，就会，增长 1.49%"：人口的变化，本身，和别的因素，互相影响。）

**5.** （开放题）下面的说法，哪些是**事实问题**，哪些是**价值判断**？（a）1995 到 2013 年，日本的 GDP 平减指数，下降了 18 年；（b）中国，应该，学习日本的教训，更快地，出清坏账；（c）日本央行，持有，约 48% 的日本国债；（d）日本，已经，走出了通缩；（e）中国，正在，重走日本的路。

> 提示：（a）事实；（b）价值判断（"应该"，也包含"日本的教训，是什么"的判断）；（c）事实（但，是据报道的数字）；（d）**一半，是事实，一半，是判断**：2022 年以来，CPI，高于 2%，核心，1.7%（事实）；"走出来"，意味着什么（持续稳定在 2%？），是，一个定义，也是预测；（e）**预测**，现有的证据，不能证实，也不能证伪（第七节）。
