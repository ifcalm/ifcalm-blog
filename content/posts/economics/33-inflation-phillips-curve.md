这一讲要回答六个问题：

1. **通胀**是怎么来的？需求、成本、预期，各起什么作用？
2. **菲利普斯曲线**是什么？通胀和失业，有没有取舍？
3. **预期**怎样改变这种取舍？为什么长期里没有取舍？
4. **自然失业率**是什么（第 27 讲留下的问题）？为什么难估？
5. **降通胀**要付出多大的代价？它取决于什么？
6. 2021 到 2022 年美国的高通胀，和中国近年的低通胀，怎么看？

上一讲，我们的 AD–AS 里，用的是**物价水平**。可是，你每天听到的，是**通胀率**，是物价涨得有多快。这一讲，我们把"水平"换成"变化率"，你会看到，上一讲那条向上倾斜的短期供给曲线，换个角度看，就是菲利普斯曲线。

## 一、你和老板的工资合同

你在一家公司上班，年薪 12 万元。年底，你和老板谈明年的工资。合同一签，一年不变。

你们都不知道明年的物价，只能**猜**。假设你们都预期物价涨 2%，于是约定涨 2%，12.24 万元。

**先停一下：如果明年物价实际涨了 5%，谁赚了，谁亏了？赚亏多少？**

你的名义工资涨了 2%，物价涨了 5%，你的实际购买力：1.02 ÷ 1.05 − 1 ≈ **−2.9%**，下降了。老板付出的实际成本，下降了 2.9%，他赚了。反过来，如果你们预期 5%、签了 5%，实际只涨了 2%，你的实际工资涨了 2.9%，老板亏了。

这里的关键是：**合同是按"预期"定的。** 所有的工资合同、价格合同、贷款合同，都是按对未来物价的**预期**定的。预期本身，会影响实际的通胀，这是这一讲的主线。

## 二、通胀是怎么来的

先把几个来源，放在一起：

1. **需求拉动**：总需求太强，产出高于潜在水平（上一讲的"过热"），企业提价，工人要求加薪。这是 AD 曲线右移带来的通胀。
2. **成本推动（供给冲击）**：油价、原材料、供应链的冲击，推高企业的成本，企业提价。这是 SRAS 曲线向上移动带来的通胀（上一讲的滞胀）。
3. **预期和惯性**：人们预期物价会涨，工资和价格的合同，就按这个定；于是，物价真的涨了。**通胀有惯性**。
4. **货币**：长期里，货币增长远快于产出，通胀不可避免（第 30 讲）。

上一讲的短期供给曲线，写成水平：P = Pe + k × (Y − Y\*) + s。把它换成**变化率**，就是：

> **通胀 = 预期通胀 + κ × 产出缺口 + 供给冲击**

这就是**菲利普斯曲线**（用产出缺口的形式）。κ 衡量的，是通胀对经济冷热的敏感程度。再用上一讲的奥肯定律（产出缺口大约是失业率偏离自然水平的 2.4 倍），可以换成失业率的形式：

> **通胀 − 预期通胀 = −β × (失业率 − 自然失业率) + 供给冲击**

经济越热（失业率低于自然水平），通胀比预期越高；经济越冷，通胀比预期越低。

## 三、菲利普斯曲线：从"菜单"到"没有取舍"

### 3.1 一段历史

- **1958 年**，新西兰出生的经济学家 A. W. Phillips（*Economica*，25 卷 100 期），用英国 1861 到 1957 年的数据，发现：**失业率越低，工资上涨越快**。
- **1960 年**，Paul Samuelson 和 Robert Solow（*American Economic Review* 论文与会议录，50 卷 2 期），把它改成美国的**通胀和失业**的关系，说，政策制定者面前，似乎有一张"菜单"：想要更低的失业，就要接受更高的通胀。
- **1967 到 1968 年**，Milton Friedman（1968，*American Economic Review*，58 卷 1 期，他的美国经济学会主席演说）和 Edmund Phelps，提出了反对意见：**这个取舍，不可能长期存在**。因为，一旦通胀持续高于人们的预期，人们就会调整预期；预期一变，曲线就整条移动。长期里，失业率会回到由经济的结构决定的水平，也就是**自然失业率**（Friedman 的说法），与通胀无关。
- **1970 年代**，美国同时出现高通胀和高失业（滞胀），"菜单"崩塌了。这被看作是支持 Friedman 和 Phelps 的证据。

### 3.3 为什么"菜单"会崩塌

用一个小模型，一年一年地算。用上面的菲利普斯曲线：通胀 = 预期 + κ × 缺口，κ = 0.5；预期 = 上一年的通胀。如果央行想让产出，**一直**比潜在水平高 1%（比如，想多创造些工作）（这一部分的算法，在 5.1 节的代码第一部分）：

![预期会追上来：长期压低失业，换来的是不断升高的通胀](/images/economics/33-accelerating.svg)

- 起点通胀 2%。第 1 年，通胀 2.5%；第 2 年，3.0%；第 5 年，4.5%；第 10 年，7.0%。
- **通胀每年多加 0.5 个百分点，没有尽头**：要让产出持续高于潜在水平，通胀要一年比一年高（因为，预期每年追上来）。

这就是 Friedman 和 Phelps 说的：**想靠通胀，换来永久的低失业，换到的，是一路上升的通胀。** 菜单，只在预期还没有调整的时候有效。

> **小结：** 通胀 = 预期通胀 + κ × 产出缺口 + 供给冲击。1960 年代美国的数据，是一条清楚的向下的菲利普斯曲线；1970 年代，它消失了；1984 年以后的 36 年，几乎看不出关系。预期会追上来：长期压低失业，换来的是加速的通胀。

## 四、自然失业率

### 4.1 它是什么

第 27 讲说过：经济再好，也不会有"零失业"，总有人在换工作。**自然失业率**，就是没有周期性失业时的那个失业率：它包括：

- **摩擦性失业**：找工作、招人，都需要时间（第 20 讲：信息不完全）；
- **结构性失业**：工人的技能，和岗位的要求，不匹配，或者，工资高于市场出清的水平（第 13 讲、第 9 讲）。

失业分为**自然的**和**周期性的**（经济冷热带来的）。**自然失业率，在这一讲里，等于"通胀不变时的失业率"（NAIRU，不加速通胀的失业率）。**

### 4.2 它从哪来：工人的流动

一个简单的模型：每个月，有工作的人里，比例 s 的人失去工作；没工作的人里，比例 f 的人找到工作。失业率的变化，是新失业的，减去找到工作的。不再变化的时候，失业率是：

> **u\* = s ÷ (s + f)**

```python
# 自然失业率从哪来：工人在"有工作"和"没工作"之间流动。
#   每个月，有工作的人里，比例 s 的人失去工作（离职率）；没工作的人里，比例 f 的人找到工作（找到工作的概率）。
#   失业率的变化 = s × (1 - u) - f × u；不再变化时，u* = s ÷ (s + f)。
# 玩具数字（一个月为一期），不对应任何国家。
def steady(s, f): return s / (s + f)

def run(months, s_path, f_path, u0):
    u, out = u0, []
    for t in range(months):
        u = u + s_path(t) * (1 - u) - f_path(t) * u
        out.append(u)
    return out

s0, f0 = 0.015, 0.25
u0 = steady(s0, f0)
print(f"基准：每月离职率 s={s0:.1%}，找到工作的概率 f={f0:.0%}：自然失业率 u* = {u0:.2%}")
print(f"  找工作更慢（f 降到 20%）：u* = {steady(s0, 0.20):.2%}；  找工作更慢（f 降到 15%）：u* = {steady(s0, 0.15):.2%}")
print(f"  裁员更多（s 升到 2.5%）：u* = {steady(0.025, f0):.2%}")
print("  同样的失业率，可以来自很不一样的流动：s=1.5%、f=25% 和 s=3%、f=50%，u* 都是", f"{steady(0.015, 0.25):.2%} 和 {steady(0.03, 0.50):.2%}", "（但后者里，工人换工作的频率高一倍）")

print("\n一次衰退：第 1–12 个月，s 升到 2.2%，f 降到 18%（企业裁员，也不太招人）；第 13 个月起恢复原样")
sp = lambda t: 0.022 if t < 12 else s0
```

### 4.3 为什么难估

自然失业率，**看不见**，只能从数据里估。我们用 3.2 节的方法（通胀的变化对失业率回归，通胀不变时的失业率）估计，并用**自助法**（在数据里反复重抽样，每次重估一遍），看估计有多不稳：

![自然失业率，看不见，也估不精确](/images/economics/33-nairu.svg)

- **1961 到 2019 年**：点估计 6.01%，但 95% 的区间，是 **4.90% 到 8.69%**，宽达近 4 个百分点。
- **1961 到 1983 年**：点估计 6.15%，区间 5.23% 到 8.17%。
- **1984 到 2019 年**：斜率几乎为零，区间是 −9.57% 到 19.87%，**什么都说明不了**。有 42% 的重抽样里，斜率根本不是负的，估出来的"自然失业率"，没有意义。
- **文献也这样说**：Douglas Staiger、James Stock 和 Mark Watson 1997 年（*Journal of Economic Perspectives*，11 卷 1 期）估计美国自然失业率，据他们的工作论文，1990 年，95% 的置信区间是 5.1% 到 7.7%：同样很宽。

所以，"自然失业率是多少"，是**一个需要估的、不确定的数**。央行如果把政策建在它上面，要小心：这也是上一讲和第 31 讲提到的"产出缺口看不见"的同一个问题。

## 五、降通胀的代价

### 5.1 谁也不信 vs 完全可信

假设通胀已经 8% 了，央行想降到 2%，3 年走完（8 → 6 → 4 → 2）。如果大家**不信**央行的话，预期就是上一年的通胀，预期降得慢，要把实际通胀压下去，就得让经济足够冷（产出缺口为负）。如果大家**信**，预期直接跟着央行公布的路径走，通胀自然下来，不需要经济变冷。

我们用公式，设可信度为 w：预期 = w × 公布的路径 + (1 − w) × 上一年的通胀。

```python
import numpy as np

# 预期加进来的菲利普斯曲线：通胀 = 预期通胀 + k × 产出缺口（缺口用 % 表示，没有供给冲击）。
# 玩具参数：k = 0.5：产出比潜在水平高 1%，通胀比预期高 0.5 个百分点。
k = 0.5

print("一、央行想让产出一直比潜在水平高 1%（比如，想多创造些工作），预期 = 上一年的通胀（适应性预期），起点通胀 2%：")
pi = 2.0
for t in range(1, 11):
    pi = pi + k * 1.0                                   # 通胀 = 预期（上一年的通胀）+ k × 缺口
    if t in (1, 2, 5, 10): print(f"  第 {t:>2} 年：通胀 {pi:.1f}%")
print("  通胀每年多加 0.5 个百分点，没有尽头：想靠通胀换来永久的高产出，换到的是一路上升的通胀")

print("\n二、把通胀从 8% 降到 2%，3 年走完（8 → 6 → 4 → 2）。如果央行的话，有一部分人信（可信度 w），预期 = w × 公布的路径 + (1-w) × 上一年的通胀；各年需要的产出缺口，累计是多少？")
path = [8, 6, 4, 2]
for w in (0.0, 0.25, 0.5, 0.75, 1.0):
    total, pi_prev = 0.0, 8.0
    gaps = []
    for t in (1, 2, 3):
        expected = w * path[t] + (1 - w) * pi_prev
        gap = (path[t] - expected) / k                  # 要让通胀走到路径上，需要的产出缺口
        gaps.append(gap); total += gap; pi_prev = path[t]
    print(f"  可信度 w={w:.2f}：每年的缺口 {[round(g, 1) for g in gaps]}，累计 {total:+.1f}（百分点·年）")
print("  公式：每年缺口 = (1 - w) × (-2) ÷ k = -4 × (1 - w)；w=0（谁也不信）累计 -12，w=1（完全可信）累计 0")

print("\n三、真实的一次：美国 1979–1986 年（沃尔克的反通胀）。数据：FRED（失业率、CPI 同比、产出缺口：CBO 事后估计的潜在 GDP）")
data = {1979: (5.85, 13.25, 0.88), 1980: (7.18, 12.35, -2.02), 1981: (7.62, 8.91, -1.82), 1982: (9.71, 3.83, -6.22),
        1983: (9.60, 3.79, -4.79), 1984: (7.51, 4.04, -1.12), 1985: (7.19, 3.79, -0.45), 1986: (7.00, 1.19, -0.39)}
for y, (u, p, g) in data.items():
    print(f"  {y}：失业率 {u:.2f}%，通胀 {p:5.2f}%，产出缺口 {g:+5.2f}%")
drop = data[1979][1] - data[1983][1]
for end in (1983, 1986):
    cum = sum(g for y, (u, p, g) in data.items() if 1980 <= y <= end and g < 0)
    print(f"  1979 到 1983 年，通胀从 {data[1979][1]:.2f}% 降到 {data[1983][1]:.2f}%，降了 {drop:.2f} 个百分点；1980–{end} 年累计的负缺口 {cum:.2f}（百分点·年）→ 每降 1 个百分点的通胀，付出 {-cum / drop:.2f} 个百分点·年的产出")
print("  对照第一部分的玩具：谁也不信（w=0）时，每降 1 个百分点，要付出 1/k = 2 个百分点·年")
print("  另：联邦基金利率的月度均值，1981 年 6 月达到 19.1%；失业率的月度最高值，1982 年 12 月是 10.8%（FRED）")
```

- **一个提醒**：这是个玩具模型：可信度，不是一个想要就有的数，央行要"挣"它。Thomas Sargent 1982 年（《四次大通胀的终结》，收在 Robert Hall 编的 *Inflation: Causes and Effects* 里）研究了两次世界大战之间，欧洲四个国家（奥地利、匈牙利、波兰、德国）的恶性通胀，发现，每一次，都是靠一次性的、彻底的财政和货币政策的转变，近乎一夜之间结束的：他的论点是，如果政策的转变足够彻底，预期会马上调整，通胀可以很快结束。（"可信的降通胀没有代价"这个说法，更多来自后来的文献，不是这篇文章的原话。）

### 5.2 真实的一次：沃尔克的反通胀

1979 年 10 月 6 日，美联储在主席 Paul Volcker 领导下，改变了控制货币的方式：不再盯着联邦基金利率，改为盯着银行准备金的数量（据美联储历史网站）。之后，利率大幅上升（联邦基金利率月均值，1981 年 6 月达到 19.1%）。

![沃尔克的反通胀：通胀降下来了，失业率先升到了近 10%](/images/economics/33-volcker.svg)

代码第三部分的结果：

- **通胀**：从 1979 年的 13.25%，降到 1983 年的 3.79%，降了 9.46 个百分点。
- **失业率**：从 1979 年的 5.85%，升到 1982 年的 9.71%（年均），月度最高点是 1982 年 12 月的 10.8%。
- **产出缺口**：1980 到 1983 年累计 −14.85（百分点·年），1980 到 1986 年累计 −16.81。
- **牺牲率**（sacrifice ratio）：每降 1 个百分点的通胀，付出 **1.57 到 1.78** 个百分点·年的产出损失。和玩具模型里（谁也不信）的 1/κ = 2，在同一个量级。

**局限**：（1）产出缺口，是用事后估的潜在 GDP 算的，会随估计变。（2）这个时期，美国同时发生了别的事（油价变动、金融管制放松、两次衰退）：不能把全部的损失，都算在"反通胀"头上。（3）沃尔克的收紧，对降通胀的作用有多大，有多少是因为人们后来相信了它（可信度），学术上有不同的看法（据对相关文献的概述）。

> **小结：** 降通胀的代价，取决于预期调整得有多快，也就是可信度；预期调整得慢，代价大。美国沃尔克时期，通胀降了 9.46 个百分点，累计产出损失约 14.85 到 16.81 个百分点·年，大约每降 1 个百分点，损失 1.6 到 1.8 个百分点·年。

## 六、通胀的成本，和为什么目标是 2%

### 6.1 通胀有什么坏处

- **预期到的通胀**：（1）**鞋底成本**：人们为了少持有现金，要多跑几趟银行；（2）**菜单成本**：企业要频繁改价（上一讲）；（3）**税制扭曲**：税率表、折旧，常常不按通胀调整，通胀让人们多交税；（4）**计价单位混乱**：钱这把"尺子"，在伸缩，合同和比较变难。
- **未预期的通胀**：**再分配**，本讲开头的工资合同：通胀比预期高，债务人（借款的人）受益，债权人受损；工资落后于物价的人受损。它还让**价格噪音**变大：企业分不清，一个价格的上涨，是整体的通胀，还是自己产品的需求变强了。

### 6.2 为什么不是 0%

通胀这么多坏处，为什么，大多数央行，把目标，定在**正的** 2% 左右，而不是零？常被提到的理由有几个（它们不互相排斥，各国央行的说法，也不尽相同）：

- **工资下调很难**（上一讲）：有一点通胀，实际工资才有下调的空间，劳动力市场才更容易调整；
- **零利率下限**（第 31 讲）：通胀太低，实际利率没法降得足够低（第 31 讲的思考题 5）；
- **测量偏差**（第 27 讲）：CPI 可能高估物价上涨（Boskin 委员会估计，美国 1990 年代，每年高估约 1.1 个百分点）。

**一个现实的数字**：美联储 2012 年 1 月 25 日，第一次明确把"价格稳定"的目标，定义为：用个人消费支出（PCE）价格指数衡量的，长期 2% 的通胀。

### 6.3 一个有争议的问题：目标该不该高一点

Olivier Blanchard、Giovanni Dell'Ariccia 和 Paolo Mauro 2010 年（国际货币基金组织工作人员的立场文件 SPN/10/03，注明是作者个人观点）在金融危机之后，建议讨论，是不是该把目标，调高到 4%，让央行有更大的空间降息。这个想法，遭到不少反对（据报道，在德国尤其如此）。

**价值判断（留给你）**：

1. **通胀的成本，落在谁身上**：更高的目标，意味着，持有现金和低利率存款的人，购买力的损耗更快，工资落后的人更吃亏；而更高的通胀，也让债务人（比如，房贷的人）受益。你怎么看这个分配？
2. **稳定的价值**：一个稳定、可预期的物价，对长期合同和规划，有多重要？你愿意为了更大的政策空间，放弃多少稳定？
3. **谁来决定目标**：由央行定，还是由政府、议会定（第 31 讲）？

## 七、一个有争议的问题：2021 到 2022 年美国的高通胀，是怎么来的

按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：按本讲的菲利普斯曲线，通胀上升，可能来自（1）**需求**：经济过热（产出高于潜在水平、失业率低于自然水平）；（2）**供给冲击**：成本上升；（3）**预期**：通胀预期升高，自己推高工资和价格。三者，可能同时起作用。

**证据怎么说**：先看数据（代码 A 的第三部分）：

- 2020 年疫情，失业率升到 8.10%，通胀 1.32%；
- **2021 年**：失业率 5.35%，通胀 **7.17%**（上升 5.85 个百分点），产出缺口 +0.81%；
- **2022 年**：失业率 3.65%，通胀 6.40%，缺口 +0.92%；
- **2023、2024 年**：失业率 3.62%、4.03%，通胀降到 3.32%、2.87%（失业率没有明显上升，而通胀已经降了下来）。
- 第 30 讲的数据：2019 年 12 月到 2021 年 12 月，M2 增加了约 40%。

不同的研究，对"原因"给出了不同的分解：

- **Ben Bernanke 和 Olivier Blanchard**（先是 2023 年的工作论文，后来发表在 *American Economic Journal: Macroeconomics*，2025 年 17 卷 3 期）：他们认为，2021 到 2022 年通胀上升的**大部分**，来自价格方面的冲击（大宗商品价格的上涨；一些部门因为供应链中断、需求从服务转向商品，出现的价格飙升），而不是过热的劳动力市场；但是劳动力市场的紧张，对通胀的影响，**更持久**。他们用岗位空缺和失业人数之比，来衡量劳动力市场的松紧，这个比率，从 2021 年 4 月的不到 1.0，升到一年后的 1.9，是有记录以来的最高值。
- **Shapiro**（旧金山联储，2022 年 6 月的经济快报）：把通胀，按供给因素和需求因素拆开，估计，**供给因素**解释了约一半的上升，**需求**约三分之一，其余不明确。他后来（2025 年 6 月）的一篇快报，用另一种方法，得出的结论是，疫情期间的高通胀，**主要由需求驱动**。
- **Giannone 和 Primiceri**（2024 年的 NBER 工作论文）：他们认为，疫情后的通胀，**主要由意想不到的强劲需求**驱动，美国和欧元区都是如此；他们把需求的强劲，归因于疫情后积压需求的释放、异常扩张的财政政策，和美联储、欧洲央行异常宽松的货币政策；供给冲击，对通胀的推动，没有那么强，虽然它显著限制了经济活动。

**局限**：（1）**把需求和供给分开，本身很难**（上一讲）：这几项研究，用的方法和假设不同，我没有逐项核对。（2）同一时期，几乎所有的因素，同时发生：疫情、财政救助、供应链、战争、宽松的货币政策。（3）这些研究，都是事后的分解，不是实验。

**分歧在哪**：

- **事实上的分歧**：需求和供给，各占多大比重？研究者，结论不同，有的偏向供给，有的偏向需求；
- **机制上的分歧**：菲利普斯曲线是不是"重新出现"（BLS 对 Bernanke 和 Blanchard 的概述：传统的菲利普斯曲线效应，开始重新出现）？还是，在这个时期，是非线性的，或者，是别的东西在起作用？
- **没有争议的部分**：通胀确实大幅上升了；央行也大幅加了息（第 31 讲）。

**价值判断（留给你）**：

1. **在通胀和失业之间取舍**：要把通胀压下来，付出多大的失业，才值得？（5.2 节，沃尔克那一次，是个对照。）
2. **财政支持 vs 通胀**：疫情期间，大规模的财政救助，保护了很多人的收入，如果它也推高了通胀，你认为这样的取舍，值得吗？（第 34 讲讲财政政策。）
3. **通胀的代价，谁承担**：工资跟不上物价的人，和有资产、有债务的人，受到的影响很不一样。

**2026 年更新（截至 2026 年 10 月中旬）：又一次供给冲击**

上面的数据，到 2024 年为止；2025 年和 2026 年，还没有完整的年度数据，我没有把它们放进代码。但是，2026 年，又有了一次值得用这一讲的框架去看的事：油价冲击（第 32 讲 6.7 节有详细的数字）。美国的 CPI 同比，2 月（战前）2.4%，9 月 3.7%；核心 CPI，2.5% → 2.6%，几乎没动；失业率，9 月 4.2%（美国劳工统计局）。

放到本节的三个解释里看：（1）**需求**：核心通胀，几乎没动，不像"全面过热"；（2）**供给冲击**：能源，同比上涨 20.4%，大致，解释了上涨的大部分（我没有在这里，核算能源的权重）；（3）**预期**：这是最关键，也是**现在还不知道**的：能源涨价，会不会，被工资和定价，当成"以后都会涨"。2026 年 9 月，美联储加息（第 31 讲 4.3 节），正是在这个问题上，下注。它**是不是**对的，要等后面的数据。注意它和 2021 到 2022 年的区别：那一次，三个因素，一起上来，很难分开（本节）；这一次，至少，从核心通胀看，**供给的成分，更突出**。这是一个观察，不是定论。

## 八、一个有争议的问题：中国近年的低通胀

第 27 讲看到：2023 到 2025 年，中国的实际 GDP 增速（世界银行，5.42%、4.96%、4.96%）高于名义增速（4.88%、4.16%、3.99%），由此反推，GDP 平减指数连续三年为负（−0.51%、−0.76%、−0.92%，是我反推的），而 CPI 仍然小幅为正（0.23%、0.22%、0.06%）。第 27 讲，把原因，留给了这一讲。

**理论预测什么**：用上一讲的 AD–AS：

- **需求不足**：AD 左移，物价和产出，**同时下降**；
- **供给扩张或成本下降**：SRAS 右移（技术进步、产能扩大、原材料变便宜），物价下降，产出**上升**（"好的"物价下降）。

**证据怎么说**：

- 数据里，实际增长不低（约 5%）；平减指数是负的。这和"价格降、产出升"的供给侧故事，**相容**，也和"需求偏弱，但是产出仍在增长（比如投资和出口在支撑）"的故事，**相容**：单看这两个数字，分不开。
- **物价下降，是不是就是坏事**：Andrew Atkeson 和 Patrick Kehoe 2004 年（*American Economic Review* 论文与会议录，94 卷 2 期）用 17 个国家 100 多年的数据，发现，**物价下降和萧条之间，只有 1929 到 1934 年的大萧条，有明显的联系**，其他时期，几乎没有。Claudio Borio 等人 2015 年（国际清算银行 *Quarterly Review*，2015 年 3 月）用 140 年、最多 38 个经济体的数据，发现，**商品和服务价格的下降**，和产出之间的联系很弱，大部分来自大萧条；而**资产价格的下降**（特别是战后的房地产价格下降），联系强得多，最具破坏性的组合，是房地产价格下降加上私人部门的高债务。

**局限**：（1）平减指数是我反推的，覆盖所有产出（包括投资品和出口品），CPI 只看居民消费：两个指数，讲的是不同的故事。（2）中国的 GDP 数据本身，也有争论（第 27 讲：两篇研究）。（3）上面两项历史研究，主要是别的国家、别的时代，不一定适用于今天的中国。

**分歧在哪**：我没有查到，一个**公认的、把各种因素的作用分开**的结论。常被提到的解释，有几类（它们不互相排斥）：（1）**需求侧**：居民和企业的信心、房地产的调整；（2）**供给侧**：部分行业的产能和竞争；（3）**价格结构**：不同类别的商品和服务，价格走势不同（比如，出口品、投资品，和消费品）。请不要把任何一个解释，当成定论。

**价值判断（留给你）**：

1. **要不要用政策去提高物价和需求**？提高物价，对借钱的人（债务人）有利，对工资和存款，要看情形；
2. **债务的负担**：物价下降，会让名义债务的实际负担变重（第 31 讲：同样的名义利率，通胀越低，实际利率越高）：谁来承担？
3. **短期刺激 vs 长期改革**：用货币和财政政策，托住需求，还是靠结构性的改革，提高效率？你怎么权衡？

**2026 年更新（截至 2026 年 10 月中旬）：低通胀，还在吗？**

上面的数据，到 2025 年。2026 年，画面，有了变化（国家统计局）：2026 年 8 月，CPI 同比 +0.8%（7 月 +0.5%），1 到 8 月平均 +0.9%；核心 CPI（不含食品和能源）+1.0%；其中，猪肉 −11.8%，食品 −1.4%。PPI 同比 **+3.8%**（1 到 8 月平均 +2.0%）：生产资料 +5.0%，采矿业 +17.8%，而**消费品** −0.5%。据报道，价格的上升，主要来自国际大宗商品（包括油价）；同时，经济增长，在放慢：据报道，2026 年第二季度，实际 GDP 同比增长 4.3%（第一季度 5.0%），低于今年 4.5% 到 5% 的目标；上半年，房地产开发投资，同比下降约 18%。

另据报道（财新、Bloomberg，2026 年 7 月），2026 年第二季度，名义 GDP，同比增长 5.9%，实际 4.3%：**GDP 平减指数，同比，转正**（按这两个数反推，约 1.5%；报道，约 1.6%），结束了，连续 12 个季度的负值（从 2023 年第二季度起）；报道，这主要来自，能源价格和 AI 供应链的成本，**不是**国内需求的回升。（日本，1990 年代以来，是怎样的？第 48 讲，把它和中国，放在一起看。）

这个新的画面，和本节前面的"理论预测"，怎么对照？

- **需求不足的故事**：并没有"过时"：消费品的出厂价格，还在下降；增长，在放慢。
- **供给侧的故事**：这一次，上涨的，是上游的原材料和能源，更像是**外部的成本冲击**（上一节：美国的油价冲击），而不是，国内需求回升。上游涨价，没有顺畅地，传到消费品价格上，说明，下游的企业，要么，利润被压缩，要么，需求，撑不住提价：**这是一个可以检验的问题，我没有找到，把它说清楚的研究。**
- **所以，请小心这样的说法**："通胀回来了，说明需求恢复了"（价格的上升，来自哪里？）；"通胀回来了，通缩的担心就过去了"（消费品价格，仍然是负的）。**同样的 CPI 数字，可能来自不同的原因**，这是这一讲，一直在说的事。

**问题留给你**：如果你要判断，中国的物价，正在回到"正常"，还是，在一次外部成本冲击里，暂时抬高，你想看哪些数据？（提示：核心 CPI、消费品 PPI、服务价格、工资增速、居民的通胀预期、剔除能源后的价格……）

## 九、局限、常见误用

### 9.1 局限

- **菲利普斯曲线是一个统计关系**：它随时期、预期、冲击的类型而变，不是一个稳定的"菜单"。
- **预期，我们看不见**：用"上一年的通胀"代替，是一个粗糙的近似。
- **自然失业率看不见，也估不准**（4.3 节）。
- **玩具模型的参数是虚构的**：κ = 0.5、可信度 w、流动的概率，只为演示机制。
- **这一讲没有讲**：理性预期的模型细节、新凯恩斯菲利普斯曲线、工资和价格的螺旋、财政政策对通胀的作用（第 34 讲）。

### 9.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "通胀和失业，永远此消彼长" | 短期、预期不变时是；长期，预期会追上来 |
| "多印钱、压低失业，是免费的" | 想让产出长期高于潜在水平，通胀要一年比一年高 |
| "自然失业率，就是失业率的一个固定数字" | 它是估出来的，随时间变，估计的区间很宽（美国：4.9% 到 8.7%） |
| "失业率低，通胀就一定高" | 美国 1984 到 2019 年，几乎没有关系；2023、2024 年，失业率没有升，通胀就降下来了 |
| "降通胀，一定要付出很大的失业代价" | 取决于预期和可信度；可信的降通胀，代价小 |
| "通胀是一种货币现象，所以，只看货币" | 长期是；短期，需求、供给冲击、预期，都起作用 |
| "物价下降，就是萧条" | 历史上（大萧条之外），商品和服务价格的下降，和萧条的联系较弱；资产价格下降加高债务，才更危险 |
| "央行的目标是 0 通胀才对" | 常见的理由：工资下调难、零利率下限、测量偏差，才定在 2% 左右 |

## 十、小结

这一讲有六个想法，请带走：

1. **菲利普斯曲线**：通胀 = 预期通胀 + κ × 产出缺口 + 供给冲击，是上一讲 AD–AS 里短期供给的"变化率"版本。
2. **它不稳定**：美国 1961 到 1969 年，相关系数 −0.88；1970 年代，关系消失；1984 到 2019 年，几乎为零（−0.03）。
3. **预期**：长期压低失业，换来的是加速的通胀；长期里，没有稳定的取舍。
4. **自然失业率**：通胀不变时的失业率，由工人的流动决定（u\* = s ÷ (s + f)）；看不见，也估不准（美国 1961 到 2019 年，95% 区间 4.9% 到 8.7%）。
5. **降通胀的代价**，取决于预期和可信度；沃尔克的反通胀，每降 1 个百分点的通胀，损失约 1.6 到 1.8 个百分点·年的产出。
6. 两个有争议的问题：**2021 到 2022 年的美国通胀**，需求和供给，各占多少，研究者结论不同；**中国近年的低通胀**，没有公认的分解。

接下来，讲政府的角色：**财政政策**能不能熨平周期？一块钱的政府支出，能带来多少产出？政府债务多高会出问题？**下一讲：第 34 讲：财政政策、乘数与政府债务。**

## 思考题

**1.** 菲利普斯曲线：通胀 = 预期通胀 + 0.5 × 产出缺口。预期 = 上一年的通胀。起点通胀 3%。如果产出缺口，一直是 +2%，3 年后，通胀是多少？

> 提示：每年多加 0.5 × 2 = 1 个百分点：第 1 年 4%，第 2 年 5%，第 3 年 **6%**。要保持高于潜在水平 2% 的产出，通胀必须一年比一年高。

**2.** 一份工资合同，按预期通胀 3% 签的，实际通胀是 6%。实际工资变化了多少？谁受益？

> 提示：1.03 ÷ 1.06 − 1 ≈ **−2.83%**：实际工资下降了；雇主受益。

**3.** 一个经济里，每月离职率 s = 2%，找到工作的概率 f = 30%。自然失业率是多少？如果 f 降到 20% 呢？

> 提示：u\* = s ÷ (s + f) = 2 ÷ 32 = **6.25%**；f = 20%：2 ÷ 22 ≈ **9.09%**。找工作更慢，自然失业率更高。

**4.** 用 5.1 节的玩具模型（κ = 0.5）：把通胀降 4 个百分点（比如，从 6% 到 2%，走 2 步），谁也不信（w = 0）时，累计要付出多少产出损失？如果可信度 w = 0.5 呢？再用奥肯定律（缺口约为失业率偏离的 2.4 倍），折成累计的失业率偏离。

> 提示：w = 0：每降 1 个百分点，要付出 1 ÷ κ = **2** 个百分点·年；降 4 个百分点，累计 **8**；w = 0.5：累计 **4**。折成失业率：8 ÷ 2.4 ≈ **3.3** 个百分点·年（w = 0）；4 ÷ 2.4 ≈ **1.7**（w = 0.5）。可信度，直接减半。

**5.** （开放题）中国 2023 到 2025 年：实际增速约 5%，平减指数为负，CPI 接近 0。你想要什么样的额外证据，来判断，这是需求不足，还是供给侧的原因？

> 提示：（1）**价格和产出的方向**：同方向下降，像需求不足；价格降、产出升，像供给扩张；（2）**分项**：消费品、投资品、出口品的价格，分别怎么走；（3）**工资和就业**：工资增速、就业情况；（4）**信贷、债务、房地产价格**：本讲引用的历史研究，提示，资产价格下降加高债务，更值得担心；（5）**预期**：居民和企业的通胀预期。**每一个指标，都不能单独回答**，要放在一起看，而且，我们对这些数据，也要保留对质量的怀疑。
