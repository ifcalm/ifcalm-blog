## 二、1800 年以前：马尔萨斯的世界

### 2.1 一个最小的模型

Thomas Malthus 1798 年的想法：**人口，会增长，到收入，下降到"维持生存"的水平为止。** 如果，土地，是固定的，更多的人，意味着，每个人，种的地，更少，产出，更少。所以，技术进步，让每个人，变富，只能是**暂时的**：富了，人，就多生孩子，人口，增加，把收入，又压回去。

我们，用一个最小的模型，把这个想法，**跑**一遍：

- 产出 Y = A × T^α × N^(1−α)：A 是技术，T 是土地（固定），N 是人口，α = 0.4 是土地的份额；人均收入 y = A × N^(−α)；
- 人口：收入高于"维持生存的水平"（= 1），就多生；低于，就少生：N(下一代) = N × exp(ε(y − 1))，ε = 0.5。时间单位：一代人（约 25 年）。

```python
import math

# 马尔萨斯的世界（一个最小的模型）。时间单位：一代人（约 25 年）。
# 产出 Y = A × T^α × N^(1−α)：A 是技术，T 是土地（固定 = 1），N 是人口；α = 0.4 是土地的份额。人均收入 y = Y/N = A × N^(−α)。
# 人口：人们的收入，高于"维持生存的水平"（= 1），就多生，低于，就少生：N(下一代) = N × exp(ε × (y − 1))，ε = 0.5。
ALPHA, EPS = 0.4, 0.5

def step(N, A):
    y = A * N ** (-ALPHA)
    return y, N * math.exp(EPS * (y - 1))

# 一、一次性的技术进步：第 5 代，A 从 1，跳到 1.5（技术，进步了 50%）
print("一、起点：A = 1，N = 1，y = 1（维持生存）；第 5 代，技术进步 50%")
print(f"  {'代':>3}{'技术 A':>8}{'人口 N':>8}{'人均收入 y':>12}")
N = 1.0; A = 1.0
for t in range(0, 41):
    if t == 5: A = 1.5
    y, Nn = step(N, A)
    if t in (0, 4, 5, 6, 8, 10, 15, 20, 30, 40):
        print(f"  {t:>3}{A:>8.2f}{N:>8.3f}{y:>12.3f}")
    N = Nn
print(f"  长期：y → 1；N → A^(1/α) = 1.5^(1/0.4) = {1.5 ** (1 / ALPHA):.3f}（技术进步 50%，人口，多了 {1.5 ** (1 / ALPHA) - 1:.0%}，收入，没变）")

# 二、持续的技术进步：每一代，A 增长 g（人口，持续地跟上）。用对数，迭代 500 代，直到稳态
print("\n二、持续的技术进步：每一代，A 增长 g")
print(f"  {'每代技术进步 g':>14}{'相当于每年':>10}{'稳态：人口每代增长':>16}{'人均收入 y（稳态）':>16}{'公式 1+ln(1+g)/(αε)':>20}")
for g in (0.0, 0.05, 0.10, 0.20):
    lnN, lnA = 0.0, 0.0
    for t in range(500):
        lnA += math.log(1 + g)
        y = math.exp(lnA - ALPHA * lnN)
        lnN += EPS * (y - 1)
    n_growth = math.exp(EPS * (y - 1)) - 1
    print(f"  {g:>14.0%}{(1 + g) ** (1 / 25) - 1:>10.2%}{n_growth:>16.1%}{y:>16.3f}{1 + math.log(1 + g) / (ALPHA * EPS):>20.3f}")
print("  人口，被技术，带着，一路增长（g = 10%/代，每代，多 27%）；人均收入，只比维持生存的水平，高一个固定的幅度，不会，一路上升。")

# 三、逃离：人口的反应，在收入高了之后，消失（"人口转型"：生育率，随收入，下降）
print("\n三、逃离马尔萨斯陷阱：技术，每代，进步 10%（约每年 0.38%）；第 20 代起，人口，不再，随收入增加（人口增长 = 0）")
lnN, lnA = 0.0, 0.0
print(f"  {'代':>3}{'人口 N':>10}{'人均收入 y':>12}")
ys = {}
for t in range(0, 41):
    lnA += math.log(1.10)
    y = math.exp(lnA - ALPHA * lnN); ys[t] = y
    if t in (0, 10, 19, 20, 25, 30, 40):
        print(f"  {t:>3}{math.exp(lnN):>10.2f}{y:>12.2f}")
    if t < 20:
        lnN += EPS * (y - 1)
print(f"  第 20 代到第 40 代（约 500 年）：人均收入，从 {ys[20]:.2f}，到 {ys[40]:.2f}（{ys[40] / ys[20]:.1f} 倍；每代 +10%，约每年 0.38%）：技术进步的好处，不再，被人口，吃掉")
```

逐段看：

- **一次性的技术进步**（第 5 代，A 从 1，到 1.5）：人均收入，一下子，到 1.5，然后，随着人口增加，一路，回落；20 代之后，回到 1.011；长期，**y → 1，N → 1.5^(1/0.4) = 2.756**：**技术，进步了 50%，人口，多了 176%，收入，没有变**。
- **持续的技术进步**：每一代，A 增长 g：稳态里，人口，每代，增长 (1+g)^(1/α) − 1（g = 10% 时，每代 26.9%）；人均收入，只比维持生存的水平，高一个**固定**的幅度（y = 1 + ln(1+g) ÷ (αε)：g = 5%，1.244；g = 10%，1.477；g = 20%，1.912），**不会，一路上升**。
- **逃离**：技术，每代，进步 10%（约每年 0.38%），到第 20 代起，人口，**不再随收入增加**（人口增长，为零）：人均收入，从第 20 代的 1.48，到第 40 代的 9.93，是 6.7 倍：**技术进步的好处，不再，被人口，吃掉**。
- **这里的"逃离"**，用的是一个，很粗的假设（"人口转型"，突然发生，人口的反应，直接，消失）。真实的历史，更复杂：**生育率，随收入，下降**，教育，让孩子的"质量"，比"数量"，更重要；这是增长理论里，一个，很大的话题（我这里，没有展开）。

### 2.2 数据，说了什么

Quamrul Ashraf 和 Oded Galor 2011 年（*American Economic Review*，101 卷 5 期，2003–2041 页）：用公元 1 到 1500 年，各国的数据，在**技术**和**土地**的生产率上，有（可以被看作，外生的）差别：据摘要，技术，更先进、土地，更肥沃的地方，**人口密度**，显著更高，而**生活水平**，没有显著差别：和马尔萨斯的预测，一致。

## 三、1800 年以后：起飞

### 3.1 一千年

麦迪逊项目数据库，把各个国家的历史研究，汇集起来，换算成，同一个口径：2011 年的国际元（按购买力平价）。它**用到的原始研究，必须被引用**：英国（1252–1870），Broadberry 等人 2015 年的书；中国（1000–1933），Broadberry、Guan 和 Li 2018 年，以及 Xu 等人 2016 年；（1952 年以后），Wu 2014 年，和 Conference Board；印度（1600–1870），Broadberry、Custodis 和 Gupta 2015 年；日本（724–1874），Bassino 等人 2018 年，（1874–1940）Fukao 等人 2015 年；美国（1650–1870）McCusker 和 Sutch，见 *Historical Statistics of the United States*。（完整的引用，在文末。）

```python
import math

# 数据：麦迪逊项目数据库（Maddison Project Database）2023 版，Bolt 和 van Zanden。每个国家，挑了几个基准年份，人均 GDP（2011 年国际元，不变价、按购买力平价）。
# 来源：英国（1252–1870）Broadberry 等 2015；中国（1000–1933）Broadberry、Guan 和 Li 2018，和 Xu 等 2016；（1952 年以后）Wu 2014 和 Conference Board；
#       印度（1600–1870）Broadberry、Custodis 和 Gupta 2015；日本（724–1874）Bassino 等 2018；美国（1650–1870）McCusker 和 Sutch，见 Historical Statistics of the United States。
MPD = {   # 人均 GDP（2011 年国际元，不变价）
    "GBR": {1000: 1151, 1300: 1159, 1500: 1697, 1600: 1691, 1700: 2412, 1760: 2915, 1800: 3343, 1830: 3550, 1870: 5829, 1913: 8212, 1950: 11061, 1978: 20448, 2000: 31946, 2022: 38407},
    "CHN": {1000: 1225, 1500: 1207, 1600: 1217, 1700: 1543, 1750: 1061, 1800: 926, 1820: 882, 1870: 945, 1913: 985, 1950: 799, 1978: 1744, 2000: 4730, 2022: 19238},
    "IND": {1600: 1264, 1700: 1162, 1750: 1068, 1870: 850, 1913: 1073, 1950: 987, 1978: 1540, 2000: 2753, 2022: 7766},
    "JPN": {1000: 1010, 1600: 1061, 1700: 1073, 1750: 953, 1800: 1317, 1870: 1580, 1913: 2431, 1950: 3062, 1978: 20060, 2000: 33211, 2022: 38269},
    "USA": {1800: 2545, 1870: 4803, 1913: 10108, 1950: 15240, 1978: 29286, 2000: 45886, 2022: 58487},
}

def at(c, y): return MPD[c][y]
def cagr(c, a, b): return (MPD[c][b] / MPD[c][a]) ** (1 / (b - a)) - 1

# 一、几个国家，几个时间点
print("一、人均 GDP（2011 年国际元）")
yrs = (1000, 1500, 1700, 1800, 1870, 1913, 1950, 1978, 2000, 2022)
print(f"  {'':<6}" + "".join(f"{y:>8}" for y in yrs))
for c, nm in (("GBR", "英国"), ("CHN", "中国"), ("IND", "印度"), ("JPN", "日本"), ("USA", "美国")):
    print(f"  {nm:<4}" + "".join(f"{MPD[c][y]:>8,}" if y in MPD[c] else f"{'—':>8}" for y in yrs))

# 二、英国，对中国，的比值

for y in (1000, 1500, 1700, 1800, 1870, 1913, 1950, 1978, 2000, 2022):
    r = MPD["GBR"][y] / MPD["CHN"][y]
    print(f"  {y} 年：{r:5.2f}" + ("  （中国更高）" if r < 1 else ""))
print(f"  中国，对美国的比值：1978 年 {MPD['CHN'][1978] / MPD['USA'][1978]:.1%}，2000 年 {MPD['CHN'][2000] / MPD['USA'][2000]:.1%}，2022 年 {MPD['CHN'][2022] / MPD['USA'][2022]:.1%}")

print("\n三、人均 GDP 的年均增长率")
print(f"  英国：1000–1500 {cagr('GBR', 1000, 1500):.2%}；1500–1700 {cagr('GBR', 1500, 1700):.2%}；1700–1760 {cagr('GBR', 1700, 1760):.2%}；1760–1800 {cagr('GBR', 1760, 1800):.2%}；"
      f"1800–1830 {cagr('GBR', 1800, 1830):.2%}；1830–1870 {cagr('GBR', 1830, 1870):.2%}；1870–1913 {cagr('GBR', 1870, 1913):.2%}；1950–1978 {cagr('GBR', 1950, 1978):.2%}；1978–2022 {cagr('GBR', 1978, 2022):.2%}")
```

想一想，这两个事实，放在一起：

## 四、一个有争议的问题：为什么是英国，为什么是 18 世纪

按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：几类被认真对待的解释，各自，预测，不一样：

1. **要素价格**：Robert Allen 2009 年的书（《全球视野下的英国工业革命》，Cambridge University Press）：据对该书的介绍，在英国，**工资高，资本和能源（煤）便宜**，使得，蒸汽机、棉纺机，这样的、节省劳动、用煤的技术，**在英国，才有利可图**：工业革命，是在，英国，"发明"的，因为那里，"值得"发明。
2. **制度**：Douglass North 和 Barry Weingast 1989 年（*Journal of Economic History*，49 卷 4 期，803–832 页）：1688 年的光荣革命，之后，英国的宪政安排，使得政府，可以**可信地承诺**，保护财产，不随意没收；Acemoglu、Johnson 和 Robinson 2005 年（*American Economic Review*，95 卷 3 期，546–579 页）：据摘要，在 1500 年以前，对君主，就有较多约束的国家，大西洋贸易，增强了商人集团，进而，推动了产权保护的改善，和后来的增长。（第 29、26 讲：制度。）
3. **煤，和新大陆**：Kenneth Pomeranz 2000 年（*The Great Divergence*，Princeton University Press）：据对该书的介绍，18 世纪中叶，欧洲和中国的核心地区，相似，面临土地的限制；后来，欧洲，因为，**煤**（替代木材）的位置，和**新大陆**（提供了，大量的初级产品），才拉开了差距。
4. **文化，和知识**：Joel Mokyr（他和 Aghion、Howitt，分享了 2025 年的诺贝尔经济学奖，第 29 讲 4.6 节）2016 年（*A Culture of Growth*，Princeton University Press）：据对该书的介绍，早期现代欧洲的"增长的文化"（科学、启蒙、对知识的态度），产生了，后来的发明；Gregory Clark 2007 年（*A Farewell to Alms*，Princeton University Press），把**文化**，放在核心；这本书，受到了很多批评。
5. **人口**：Malthus 的约束，在英国，怎样，先被打破（第二节）。

**证据怎么说**：

- 英国的增长，**开头，很慢**（上面）：任何解释，都要解释，"为什么是，慢慢地，长出来的"，而不是，"突然跳起来"；
- **没有一个，决定性的实验**：英国，只有一个；这些因素，又**互相关联**（贸易，带来，财富，带来，制度，改变，也带来，高工资，和便宜的煤）；
- 证据，多是，**比较、历史的**：比如，Allen 比较了，各地，工资和能源价格；North–Weingast，用资本市场，作为证据；Pomeranz，比较，欧洲和中国的核心区域。

**局限**：（1）只有一个，"英国"，没法，做对照实验；（2）历史数据，不确定；（3）**每个解释，都，部分，成立**，也，各有批评：Clark 的书，被批评；Pomeranz，和 Broadberry 等人（下一节），在，分流，开始的时间上，有分歧。

**分歧在哪**：事实上，各个因素的**相对重要性**；"因"和"果"（更高的工资，是原因，还是结果）；"为什么是英国，不是荷兰、不是中国的江南"，每一个，解释，都要面对这个问题。

**价值判断（留给你）**：这里，有一个，必须，分开的问题：**事实问题**："殖民、奴隶贸易，对英国的工业化，到底，贡献了多少？"（有研究，有争论，我这里，没有给出答案）；**价值问题**："一个国家的繁荣，如果，部分，依赖，对别人的掠夺，我们，该怎么评价？该不该，有补偿？"。第一个，可以，通过证据，慢慢，缩小分歧；第二个，是，道德的、政治的判断。**两者，不能，混在一起**（第 4 讲）。

## 五、一个有争议的问题：大分流，什么时候开始

**理论预测什么**：如果，欧洲和中国，在 18 世纪中叶，还大致，相当，那么，分流，是**工业革命之后**的事（煤、新大陆：Pomeranz）；如果，欧洲，更早，就已经，领先，那么，更深的、**长期的**因素（制度、人口、农业），更重要。

**证据怎么说**：

- **Broadberry、Guan 和 Li** 2018 年（《中国、欧洲和大分流：980–1850 年的历史国民账户研究》，*Journal of Economic History*，78 卷 4 期，955–1000 页，据麦迪逊项目数据库的引用）：据摘要，中国的人均 GDP，在北宋和明代，保持在高位，在清代，趋于下降；北宋时，中国是世界领先，但 1300 年，已经落后于意大利；**到 1750 年，差距已经，大到**，不能，用中国内部的区域差异来弥合：所以，**大分流，在工业革命之前，就已经开始**。他们的估计，处在"加州学派"（分流较晚）和"欧洲中心论"（分流很早）之间。
- **Allen 等人** 2011 年（*Economic History Review*，64 卷，8–38 页）：用**实际工资**，比较：据摘要，18 世纪，亚洲建筑工人的实际收入，和欧洲落后地区，相似，但**远低于**西北欧的领先经济；中国的实际工资，在 18 世纪和 19 世纪早期，**停滞**，之后，缓慢上升。
- **Allen 2001 年**（*Explorations in Economic History*，38 卷 4 期，411–447 页）：用欧洲的工资和物价，据转述，英国和荷兰，工资，保持稳定，而欧洲其他地方，1500 到 1750 年间，实际工资，下降：分流，在欧洲内部，也发生了。（这一结论，也有，后续的争论：比如，据转述，Malanima 2013 年，认为，意大利的实际工资，到 18 世纪初，仍然，不低于英国。）
- **我们的数据**（上一节）：英国 ÷ 中国，1500 年，1.41；1700 年，1.56；1800 年，3.61，和 Broadberry 等人的叙述，一致；可是，中国，1700 到 1750 年的**下降（−31%）**，来自，两套估计的拼接，和 Allen 等人，"18 世纪中国实际工资，大体停滞"的结论，**并不完全一致**，我没有能力，判断，哪一个，更接近真实。

**局限**：（1）历史的 GDP 估计，极不确定，不同研究，差别很大；（2）人均 GDP，实际工资，各自，测的，是不同的东西；（3）"中国"，是一个，很大、很不均匀的地方：江南，和其他地方，不同。

**分歧在哪**：事实上，1750 年，中国最富的地区（比如，长江下游），是否，和英国，相当；**分流的时间**；理论上，解释，是"更早的、制度和人口的"，还是"更晚的、煤和新大陆的"。

**价值判断**：这里，**几乎没有，价值判断**；主要是，**事实和方法**的争论。

### 6.3 一个有争议的问题：中国增长，靠什么，能不能持续

**理论预测什么**：几类力量：（1）**激励和市场化**：家庭联产承包责任制，乡镇企业，价格双轨制；（2）**开放**：贸易、外资、WTO（第 40 讲）；（3）**追赶**：后发优势（第 28、29 讲），高储蓄、高投资；（4）**人口红利**；（5）**政府的能力**（第 26 讲：中国官员的晋升）。

**证据怎么说**：

- **家庭联产承包责任制**：Justin Yifu Lin 1992 年（*American Economic Review*，82 卷 1 期，34–51 页）：用省级的面板数据；据摘要，**放弃集体耕作**，提高了全要素生产率，解释了 1978–1984 年产出增长的**约一半**；其他的、市场相关的改革，影响很小。（后来，有批评：据转述，如 Xu 2012 年，指出，对"家庭承包的采用率"的度量，有误。）
- **双轨制**：Lawrence Lau、Yingyi Qian 和 Gérard Roland 2000 年（*Journal of Political Economy*，108 卷 1 期，120–143 页）：据摘要，他们的模型认为，**继续执行原有的计划**，同时，放开市场（"双轨"），相当于，**隐含的补偿**，给了可能的输家，因此，是"没有输家的改革"：这是一个**解释**，不是，对所有环节的检验。
- **增长核算**（第 29 讲）：中国的增长，大约 39%，来自"效率"（残差），其余，来自资本、劳动、人力资本。
- **生产率的争论**：Alwyn Young 2003 年（*Journal of Political Economy*，111 卷 6 期，1220–1261 页）：据摘要，企业，系统地，低估了通胀，使得 1978–1998 年，非农业部门，测得的增长，每年，高出约 2.5 个百分点；劳动参与率、教育、劳动力，从农业，转出，解释了，大部分，其余；**非农业部门的生产率**，是"可观，但并不突出"；改革，对效率的提高，也许，主要，在农业。Xiaodong Zhu 2012 年（*Journal of Economic Perspectives*，26 卷 4 期，103–124 页）：据摘要，认为，1978 年以来，中国的增长，主要，来自**生产率**的增长，而不是，资本投入；他把它，归因于，渐进的、持续的制度改革，减少了扭曲、改善了激励。

**局限**：（1）生产率，是一个**残差**（第 29 讲），对数据的质量，很敏感（Young 的讨论，就是，一个例子）；（2）各个因素，**互相关联**，很难，单独识别；（3）"中国"，也只有一个，没有对照。

**分歧在哪**：**事实上**：全要素生产率，增长了多少（Young，对 Zhu）；**未来**：人口，在减少，投资率，已经很高，增长，会放缓到哪里？这是，一个，没有被公认的答案的问题：我这里，**不做预测**。

**价值判断（留给你）**：

1. **速度，和代价**：高速的增长，伴随，高投资、低消费，也伴随，不平等（第 42 讲）、环境的压力；你，愿意，用多少"现在的消费"，换"未来的增长"？
2. **国家，和市场**：政府，在增长里，起了多大的作用，应该起多大的作用？第 26 讲，政府失灵，和第 40 讲，产业政策：**哪些是事实（证据），哪些是价值（你更信任谁）**？
3. **"成功"，的标准**：人均 GDP、贫困率（第 42 讲，从 83% 到 0）、寿命、自由、环境，你，看哪几个？

经济学，能告诉你：每一种力量，大约，有多大，每一种选择，有什么代价；**你，更看重哪些，是你的价值判断。**

### 7.2 三个想法

整门课，是**三个想法**，的变形：

- **权衡**：从第 1 讲的机会成本，到第 9 讲的无谓损失，到第 42 讲的"漏桶"：**每一个选择，都有代价**；
- **激励**：从第 2 讲的边际思维，到第 21 讲的道德风险，到第 39 讲的默认选项，到第 6.3 节的家庭联产承包：**人，会对"做这件事对我有什么好处"，做出反应**；
- **均衡**：从第 7 讲的价格，到第 18 讲的纳什，到第 35 讲的银行挤兑，到第 40 讲的关税战：**大家各自调整，直到没人想单方面改变；这个状态，未必好**。

### 7.3 六个问句

遇到一个新的经济问题，或者，一条新闻，可以，先问自己：

1. **谁得到什么，谁失去什么？**（权衡，分配：第 3、40 讲）
2. **机会成本，是什么？**（权衡：第 1 讲）
3. **激励，是什么？人们，会怎么，反应？**（激励：第 2 讲）
4. **均衡，在哪里？有没有人，想单方面改变？**（均衡：第 7、18 讲）
5. **证据，是什么？是相关，还是因果？样本，多大？能重复吗？**（第 4 讲）
6. **哪一部分，是事实，哪一部分，是价值判断？**（第 4 讲，和每一个"有争议的问题"）

### 7.4 三个提醒

- **模型，是地图，不是土地**（第 4 讲）。它，故意，画错了一些东西，才有用；用的时候，要问"它，忽略了什么"。
- **证据，会改变**。这门课里，很多数字，会过时，原理，不会。每次，引用，数字，都问：**什么时候的、谁测的、口径是什么**。
- **在有争议的地方，诚实**。这门课，没有，替你，下结论：在**事实**上，我，给出，证据和局限；在**价值判断**上，我，只给出，各种选择，大约的后果。**你，要自己，决定，你，更看重什么。**

## 八、局限、常见误用

### 8.1 局限

- **历史数据，极不确定**：麦迪逊项目数据库，是一个，不断，更新的估计；1800 年以前的，尤其；
- **模型，是示意**：马尔萨斯模型，参数，是虚构的；
- **数据**：数字，是，人均 GDP（平均），不是，一般人的生活水平；
- **文献**：多数，只引用了摘要，没有重做；
- **这一讲没有讲**：人口转型的细致理论；印度、日本、非洲的历史；殖民的具体影响；中国改革开放的具体政策细节和争议；中国经济的，其他挑战（比如，债务、房地产）；
- **本讲，不是政策建议，也不是对中国经济的预测。**

### 8.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "人类，一直，在增长" | 1800 年以前，人均收入，几乎不动；增长，是近 200 年的事 |
| "技术进步，一定，让人变富" | 在马尔萨斯的世界里，技术进步，主要，变成了更多的人口 |
| "工业革命，是一个，突然的事件" | 在人均 GDP 上，英国，开头，很慢，到 1830 年之后，才明显加速 |
| "某一个原因（制度、煤、文化），解释了一切" | 各个解释，部分成立；没有，被公认的分解 |
| "1750 年，中国，和欧洲，一样富" | 这是一个有争议的问题；不同的研究，结论不同 |
| "中国的增长，只是，投资的结果"，或"只是，生产率的结果" | 两种说法，都太简单；各因素，互相关联；有争议 |
| "高增长，会一直持续" | 增长，会放缓；人口，在变化；追赶，有"后发优势"，也在耗尽 |
| "历史告诉我们，应该怎么做" | 历史，是一个，只有一次的实验；它，给出线索，不给出处方 |

## 九、小结

这一讲，有六个想法，请带走：

1. **马尔萨斯的世界**：技术进步，让人口，多了 176%，收入，没变；逃离，需要，人口的反应，消失。
2. **一千年**：英国，1000 到 1800 年，人均 GDP，是原来的 2.9 倍（每年 0.13%），1800 到 2022 年，11.5 倍；中国，同样，几乎不动，之后，20.8 倍。
3. **工业革命，开头，很慢**：英国，1700–1830，年均 0.2%~0.34%；1830–1870，1.25%。
4. **大分流**：英国 ÷ 中国，1000 年 0.94；1700 年 1.56；1950 年 13.84（最大）；2022 年 2.00。何时开始，有争议。
5. **中国，1978–2022**：人均 GDP，11.0 倍，每年 5.61%；在东亚的追赶者里，不是最快；增长率，从 10%，到 4.9%；投资率，44%；15–64 岁人口，已经，不再增长。
6. **有争议**：为什么是英国（要素价格、制度、煤和新大陆、文化）；大分流，何时开始；中国的增长，靠什么。

## 思考题

**1.** 马尔萨斯模型：土地的份额 α = 0.4。如果，技术，一次性，进步 20%，长期，人口，会是原来的几倍？人均收入呢？

> 提示：长期，y → 1（维持生存）；N → A^(1/α) = 1.2^(1/0.4) = 1.2^2.5 ≈ **1.58 倍**。技术，进步了 20%，人口，多了约 58%，人均收入，不变。

**2.** 英国，1000 到 1800 年，年均增长 0.13%；1800 到 2022 年，年均 1.11%。人均 GDP，翻一番，各需要多少年？

> 提示：ln 2 ÷ ln(1.0013) ≈ **520 年**；ln 2 ÷ ln(1.0111) ≈ **63 年**。（第 36 讲的 72 法则：72 ÷ 1.11 ≈ 65 年，大致一致。）

**3.** 中国，人均 GDP，是美国的 32.9%（2022 年）。如果，中国，今后，每年，增长 3%，美国，每年，增长 1.5%（假设），要多少年，才能，到美国的 50%？如果，增长，仍然，是 5.61%，呢？

> 提示：比值，每年，乘以，(1.03 ÷ 1.015)；要从 0.329，到 0.5：ln(0.5 ÷ 0.329) ÷ [ln(1.03) − ln(1.015)] ≈ 0.4187 ÷ 0.01467 ≈ **28.5 年**。如果是 5.61%：ln(0.5÷0.329) ÷ [ln(1.0561) − ln(1.015)] ≈ 0.4187 ÷ 0.0405 ≈ **10.3 年**。**这只是算术，不是预测**：增长率，会随着收入的上升，而放缓（追赶的"后发优势"，在耗尽）。

**4.** （开放题）把下面的说法，分成**事实问题**和**价值判断**：（a）18 世纪，英国的工资，比欧洲大陆高；（b）因此，煤和机器，在英国，才有利可图；（c）欧洲的工业化，依赖对别人的剥削；（d）如果（c）成立，今天的富国，应该，补偿；（e）为了追赶，一个国家，可以，牺牲，当代人的一部分消费。

> 提示：（a）**事实**（可以，用工资数据，检验；Allen）；（b）**理论 + 证据**（有争议，Allen 的解释）；（c）**混合**：它的"依赖了多少"，是**事实**（有争议，没有公认的答案），"剥削"，带着道德判断；（d）**价值判断**；（e）**价值判断**（第 6.3 节，速度和代价）。

**5.** （综合题）一座城市，要限制网约车的数量（发放有限的牌照）。请用 7.3 节的**六个问句**，分析：谁得到什么，谁失去什么？机会成本？激励？均衡？证据？事实和价值判断？

> 提示：（1）牌照持有人、乘客、司机、传统出租车，各得什么、失什么（第 9 讲：数量限制，和价格管制；第 40 讲 4.3：配额，等价于关税，租金归谁）；（2）机会成本：乘客的等待时间，司机的收入；（3）激励：牌照，有价值，人们，会争夺（寻租，第 26 讲）；（4）均衡：牌照价格，会，把"租"资本化；（5）证据：要看，真实的数据，（比如，有牌照限制和没有的城市，价格、等待时间的比较），要小心，因果；（6）事实：价格、等待时间、拥堵；价值：该不该，保护传统司机的生计，该不该，减少拥堵，更看重谁。**没有"唯一的答案"**，但有**更好的问法**。
