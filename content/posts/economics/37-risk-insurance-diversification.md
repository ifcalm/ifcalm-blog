## 一、一套值 100 万元的房子

你有一套房子，值 100 万元。一年之内，它被烧毁的概率，是 1%。保险公司说，保费是 **1.2 万元**，烧毁了，赔 100 万。

**先停一下：1% 的概率，100 万元的损失，期望的损失是 1 万元。你付 1.2 万，比"期望的损失"还多。你还会买吗？**

想一想：你多半会买。1% 听上去很小，可是，一旦发生，你失去的，是你家最大的一笔财产，**几乎是一场灾难**。付 1.2 万，换来"睡得着觉"。这不是算错了账，是因为，**对你来说，100 万的损失，比 1.2 万的小开支，痛得多**，不止多 100 倍。

这就是**风险厌恶**：同样的期望值，一个确定的结果，比一个有风险的结果，更好。

## 二、期望效用：为什么期望值不够

### 2.1 圣彼得堡游戏

1738 年，Daniel Bernoulli 讨论过一个游戏（后来叫**圣彼得堡悖论**）：抛硬币，直到出现正面为止；第 n 次才出现正面，奖金 2^n 元。你愿意付多少钱来玩？

期望奖金：(1/2) × 2 + (1/4) × 4 + (1/8) × 8 + …… = 1 + 1 + 1 + ……，**无穷大**。可是，没有人愿意付一大笔钱来玩。

Bernoulli 的解释：**钱给人的满足感（效用），不和钱成正比**：第 100 万元，比第 1 万元，带来的满足感，要小。如果用"财富的对数"来衡量，这个游戏的期望效用，是有限的。（Bernoulli 的论文，最初用拉丁文，1738 年发表于圣彼得堡科学院的《评论集》，英文译本，刊于 *Econometrica*，1954 年，22 卷 1 期，译者 Louise Sommer。）

### 2.2 风险厌恶 = 凹的效用

如果一个人的效用，是**凹**的（财富越多，每多一块钱，增加的满足感，越小），那么，他就是**风险厌恶**的：

- **期望效用**：不是"期望的财富"的效用，而是，每种可能的结果的效用，按概率加权的平均；
- **确定性等价**：一个"确定的财富"，使你觉得，和这个有风险的赌局，一样好；
- **风险溢价**：期望的财富，减去确定性等价，就是你为了避免风险，愿意放弃的。

```python
import math

# 一、圣彼得堡悖论：抛硬币，直到出现正面为止。第 n 次才出现正面，奖金 2^n 元。你愿意付多少钱来玩？
print("一、圣彼得堡游戏：期望奖金是多少？")
for cap_n in (10, 20, 30, 40):
    ev = sum((0.5 ** n) * (2 ** n) for n in range(1, cap_n + 1))      # 每一项都是 1：(1/2)^n × 2^n
    print(f"  如果最多抛 {cap_n} 次（庄家最多付 2^{cap_n} 元）：期望奖金 = {ev:.0f} 元（每多允许抛一次，期望多 1 元；不设上限，就是无穷大）")
# 对数效用：用"财富的对数"来衡量满足感（Bernoulli 的想法）。从 0 元起步，奖金 2^n 的效用 = ln(2^n) = n ln 2
eu = sum((0.5 ** n) * (n * math.log(2)) for n in range(1, 200))
print(f"  对数效用下，这个游戏的期望效用 = {eu:.4f}（= 2 ln 2）；对应的确定性等价 = e^({eu:.4f}) = {math.exp(eu):.2f} 元：一个理性的、风险厌恶的人，只愿意付约 4 元")

# 二、风险厌恶：效用是凹的。用 u(W) = ln W
u = math.log
def certainty_equivalent(outcomes, probs):
    return math.exp(sum(p * u(w) for w, p in zip(outcomes, probs)))

print("\n二、你有 100 万元，一个赌局：一半的机会赢 40 万，一半的机会输 40 万。期望值是 0，你愿意玩吗？")
W = 100.0
ce = certainty_equivalent([W + 40, W - 40], [0.5, 0.5])
print(f"  玩的结果：140 万或 60 万，期望财富 {0.5 * 140 + 0.5 * 60:.0f} 万，确定性等价 {ce:.2f} 万：比不玩的 100 万少 {W - ce:.2f} 万，这就是'风险溢价'：为了避免这个赌局，你愿意放弃最多 {W - ce:.2f} 万")

print("\n三、买保险：你有一套房子，值 100 万，一年内被毁的概率是 1%；你另外还有 W 万的其他财富。保险公平的价格是多少？你最多愿意付多少？（对数效用）")
for other in (100, 200, 1000, 10000):
    Wt = other + 100                                                    # 总财富
    # 愿付的最高保费 P：确定地付 P（房子总是被保住），和不买保险（1% 失去房子）一样好：ln(Wt - P) = 0.99 ln Wt + 0.01 ln(Wt - 100)
    target = 0.99 * u(Wt) + 0.01 * u(Wt - 100)
    P = Wt - math.exp(target)
    print(f"  其他财富 {other:>5} 万：公平保费 1.0000 万；最多愿付 {P:.4f} 万（比公平保费，多 {P - 1:.4f} 万）")
print("  其他财富越少，越怕那 1% 的损失，愿意多付；其他财富越多，越接近'风险中性'，只愿意付接近公平的价格")

print("\n四、为什么有保险这门生意：保险费，高于公平价格，只要不高于'最多愿付'，买卖双方，都变好了：")
fair = 1.0
Wt0 = 200.0                                                           # 房子 100 万 + 其他财富 100 万
wtp = Wt0 - math.exp(0.99 * u(Wt0) + 0.01 * u(Wt0 - 100))
loading = 1.15
print(f"  公平保费 {fair:.2f} 万；公司收 {fair * loading:.2f} 万（加价 {loading - 1:.0%}，用于成本和利润）；其他财富 100 万的人，愿付到 {wtp:.2f} 万：1.15 < {wtp:.2f}，买卖成交，双方都得到好处；其他财富 1000 万的人，只愿付到 1.05 万 < 1.15，不会买")
```

### 2.3 买保险

现在，回到你的房子。代码的第三部分，用对数效用，算：你**最多**愿意付多少保费？

- 如果你**另外**还有 100 万的其他财富（总财富 200 万）：最多愿付 **1.3815 万**，比公平保费 1.0 万，多 0.38 万。
- 其他财富 200 万：1.2139 万；1000 万：1.0479 万；10000 万：1.0049 万。**其他财富越多，越接近"风险中性"，愿意付的，越接近公平保费。**
- **保险为什么是一门生意**：公平保费是 1.0 万（期望的损失）。保险公司收 1.15 万（加价 15%，用来付成本和利润）。其他财富 100 万的人，愿意付到 1.38 万，1.15 < 1.38：**买卖成交，双方都变好**。可是，其他财富 1000 万的人，只愿意付到 1.05 万，低于 1.15，不会买。

**保险，是风险的"交易"：把风险，从厌恶它的人，转给更能承担它的人（或者，把很多人的风险，汇在一起）。**

### 2.4 期望效用的局限

- 同一个人，既买保险（厌恶风险），又买彩票（喜欢风险），怎么解释？Milton Friedman 和 Leonard Savage 1948 年（*Journal of Political Economy*，56 卷 4 期）就问过这个问题。
- 人们对概率，常常判断不准，对"损失"和"收益"的感受，不对称（第 39 讲会讲前景理论）。
- **所以，期望效用，是一个标准的、好用的基准，不是对人类行为的完整描述。**

> **小结：** 风险厌恶：效用是凹的。确定性等价低于期望财富，差额是风险溢价。因此，人们愿意付高于"公平价格"的保费；其他财富越少，越愿意付。

## 三、保险公司：大数定律，和它的边界

保险公司，不"厌恶"那 1% 的风险，因为，它的客户很多。**大数定律**：很多互相独立的小风险，加起来，平均的损失，会很接近期望值。

```python
import math, random

# 保险公司：靠"大数定律"赚钱。每份保单：一年内，概率 p = 1% 要赔 100（万元），收保费 1.1（比公平保费 1.0，加价 10%）。
# 问：保单数 N 越多，公司"亏本"（赔的钱，超过收的保费）的概率，是不是越小？
p, L, premium = 0.01, 100.0, 1.1

def binom_tail(n, p, k):
    """P(赔付的份数 >= k)：二项分布，精确计算（用对数，避免数字太大）"""
    total = 0.0
    for i in range(k, n + 1):
        logterm = math.lgamma(n + 1) - math.lgamma(i + 1) - math.lgamma(n - i + 1) + i * math.log(p) + (n - i) * math.log(1 - p)
        term = math.exp(logterm)
        total += term
        if i > k + 20 and term < 1e-18 * max(total, 1e-300): break
    return total

print("一、风险是互相独立的（每份保单，自己着火）：公司亏本的概率")
for n in (10, 100, 1000, 10000, 100000, 1000000):
    k = math.floor(n * premium / L) + 1                       # 赔付的份数，达到 k 份，赔的钱 k × L，才会超过收到的保费 n × 1.1
    sd = math.sqrt(p * (1 - p) / n) * L
    print(f"  N = {n:>7}：每份保单的平均赔付，标准差 {sd:7.4f}（期望 {p * L:.2f}，保费 {premium:.2f}）；公司亏本的概率 {binom_tail(n, p, k):.4%}")

print("\n二、风险是相关的（比如，同一场洪水，同时淹了很多房子）：每年有 1% 的概率发生一场灾难；灾难发生时，每份保单，各自有 p_c = 50% 的概率受损；平时，没有别的损失。")
print("  这样，每份保单的平均赔付概率，也是 1% × 50% = 0.5%（比上面的更低，保费更宽裕）")
rng = random.Random(37)
def sim_correlated(n, years=20000, q=0.01, pc=0.5):
    bad = 0
    for _ in range(years):
        if rng.random() < q:                                   # 这一年，有灾难
            claims = sum(1 for _ in range(n) if rng.random() < pc)
            if claims * L > n * premium: bad += 1
    return bad / years
for n in (10, 100, 1000):
    print(f"  N = {n:>5}：公司亏本的概率约 {sim_correlated(n):.2%}（模拟 20000 年）")
print("  保单越多，亏本的概率，不再变小，而是停在 1% 附近（灾难的概率）：风险是'相关'的时候，分散，不管用")
print("  第 35 讲：银行的资产，如果是相关的（同时发生违约），分散，也救不了你；这是'系统性风险'")
```

逐段看：

- **第一部分（风险互相独立）**：每份保单，1% 的概率赔 100，收保费 1.1。每份保单的平均赔付的标准差，随 N 变大，快速变小：N = 10：3.15；N = 1000：0.315；N = 100 万：0.0099。可是，**公司亏本的概率**，不是一路下降：N = 10：9.56%（只要有一份赔付就亏）；N = 100：26.4%；N = 1000：30.3%；N = 10000：14.6%；N = 10 万：0.08%；N = 100 万：几乎为零。**为什么先升后降**：保费只比期望高 10%，这个"安全垫"，要比平均赔付的标准差大，才管用：N 太小，标准差比安全垫大得多，亏本的概率，主要看"会不会赔上一两份"；到了 N 很大，标准差，才小于安全垫。**靠大数定律赚钱，要"大数"：而且，实际上，保险公司，还要留资本，做缓冲。**
- **第二部分（风险相关）**：假设每年，有 1% 的概率，发生一场灾难（比如，一场洪水），灾难发生时，每份保单，各自有 50% 的概率，受损。每份保单的平均赔付概率，是 0.5%，比第一部分更低，保费更宽裕。可是，N = 10、100、1000：公司亏本的概率，是 1.06%、0.95%、0.92%：**不再下降，停在灾难的概率 1% 附近**。**风险相关时，分散不管用**：保单越多，灾难一来，亏得越多。（第 35 讲：银行的资产，如果同时违约，也是一样的道理。）

### 3.1 什么风险，可以被保险

从这里，可以看到，保险的几个条件（这是一种常见的总结，不是每个保险都完全满足）：

1. **风险基本独立**：不是同时发生；
2. **概率可以估计**：保险公司，要定价；
3. **损失可以核实**：不会被轻易地"制造"出来。

当这些条件有问题，保险就会**不存在**，或者**不完整**：

- **逆向选择**（第 20 讲）：买保险的人，比保险公司更了解自己的风险，高风险的人，更愿意买，保费涨，低风险的人退出；
- **道德风险**（第 21 讲）：投保之后，人们不那么小心了；所以，保险常常有**免赔额**和**共同支付**；
- **系统性风险**：灾难、金融危机，是相关的：私人保险，很难承担，常常要政府来做（比如，第 34 讲的自动稳定器，第 35 讲的存款保险）。

> **小结：** 保险公司靠大数定律：独立的小风险汇在一起，平均损失接近期望。但是，它需要很大的数，也需要风险互相独立；相关的风险，分散不了。

## 四、分散：几乎免费的午餐

### 4.1 两个资产

你有两项投资，每一项的年度波动是 σ，两者的相关系数是 ρ，各投一半：

> 组合的波动 = σ × √[(1 + ρ) ÷ 2]

- ρ = 1（完全同步）：σ，不降；
- ρ = 0.5：0.87σ；
- ρ = 0（互相独立）：0.71σ；
- ρ = −1（完全相反）：0，风险完全消除。

**关键**：只要两者**不完全同步**，混在一起，风险就比单独持有的平均风险小。

### 4.3 特有风险和系统性风险

- **特有风险**（idiosyncratic risk）：只和某一家公司、某一个行业有关的风险：可以通过分散消除。
- **系统性风险**（systematic risk）：影响所有资产的：不能通过分散消除。

理论的一个有名的预测（Harry Markowitz 1952 年，*Journal of Finance*，7 卷 1 期，的组合理论，William Sharpe 1964 年，*Journal of Finance*，19 卷 3 期，的资本资产定价模型）：**既然特有风险，可以免费地分散掉，市场不会因此给你补偿；只有系统性风险，才会被"定价"**。这个预测，第 38 讲会讲，它有多少证据支持。

### 4.4 人们真的分散了吗

Laurent Calvet、John Campbell 和 Paolo Sodini 2007 年（*Journal of Political Economy*，115 卷 5 期）用瑞典全体家庭的详细数据，研究家庭投资中的"错误"。据摘要：（1）只有一部分家庭，分散严重不足，大多数家庭，通过国际分散，表现比本国股指更好；（2）**不参与**风险资产市场，带来的福利损失，在考虑了"不参与的人，即使参与，也未必投资得好"之后，几乎少了一半；（3）更有金融知识的家庭，投资更有效，也更激进，所以，它们在效率上的"福利成本"更高。（我只引用摘要的概括，请读原文。）

> **小结：** 分散化：只要资产不完全同步，混在一起，风险就降低。10 个行业的数据：从 21.5% 降到 16.1%，之后降不动，因为剩下的，是系统性风险。头几个最管用。

## 五、风险值多少钱

### 5.1 风险溢价

第 36 讲，我们说，折现率，反映时间。如果现金流是有风险的，折现率，还要加上**风险溢价**：

> 折现率 = 无风险利率 + 风险溢价

风险越大的现金流，要求的回报越高，所以，现值越低。

### 5.3 一个有争议的问题：股权溢价之谜

按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：Rajnish Mehra 和 Edward Prescott 1985 年（《股权溢价：一个谜》，*Journal of Monetary Economics*，15 卷 2 期）的发现：用一个标准的、校准过的一般均衡模型，在"合理"的风险厌恶程度下，模型给出的股权溢价，**远低于**数据里的数字（据对论文的转述，模型的溢价，不到 1%，数据里，约 6%；不同的转述，具体的数字不一致，请读原文）。要解释数据里的这么高的溢价，需要，**极高的风险厌恶**。这就是"谜"。

**证据怎么说**（几种常被提到的解释，不互相排斥）：

- **罕见的灾难**：Robert Barro 2006 年（*Quarterly Journal of Economics*，121 卷 3 期）认为，我们没有把"罕见的、严重的经济灾难"（20 世纪全球历史里的：第一次世界大战、大萧条、第二次世界大战）的概率，放进模型；放进去之后，可以解释高股权溢价、低无风险利率和股市的高波动。
- **习惯形成**：John Campbell 和 John Cochrane 1999 年（《出于习惯的力量》，*Journal of Political Economy*，107 卷 2 期）：人们的效用，取决于消费**相对于**一个"习惯水平"；在衰退时，消费接近习惯，人们对风险格外敏感，要求更高的补偿。（卷期页，我没有在这里核对到；请核对期刊。）
- **其他**：幸存者偏差（我们看的美国，是 20 世纪的赢家）、市场摩擦、人们的偏好（第 39 讲）。

**局限**：（1）每一种解释，都有后续的争论（比如，罕见灾难的概率，怎么估，是一个难题）；（2）数据里的溢价，本身，随时期和国家而变，用的是美国 99 年；（3）它是一个"校准的模型，和数据对不上"的问题，不是一个直接的因果问题。

**分歧在哪**：事实上，股权溢价，到底是"风险的补偿"（罕见灾难、习惯），还是"人们的错误"（行为金融），还是"样本的运气"（幸存者偏差）。这些，数据里，很难完全分开。

**价值判断（留给你）**：这个问题，事实的成分居多。涉及价值的，是它在现实里，带来的选择：

1. **风险该由谁承担**：养老金，是由个人自己投资、自己承担（市场的颠簸），还是由集体、雇主、政府来分担？你觉得，多大的风险，该让个人自己承担？
2. **安全和回报**：一个 20 年的长期投资者，历史上，股市从没有输给国库券（美国的数据），但是，这不是保证；你愿意为了更高的预期回报，承担多大的颠簸？
3. **灾难的保险**：罕见的灾难，谁来买保险？只有政府，能承担吗？

经济学能告诉你：每一种风险和回报的组合，大约是什么；**你愿意承担多大的风险，是你的价值判断（和你的处境）。**

## 六、个人和社会，怎么对付风险

四种办法：

1. **自己承担**：留一笔储蓄做缓冲（经济学里叫"预防性储蓄"）；
2. **分散**：把鸡蛋，放在不同的篮子里（第四节）；
3. **买保险**：把风险，转给能承担的人（第二、三节）；
4. **社会保险**：由政府组织，强制参加，汇集风险（比如，基本医疗保险、养老保险、失业保险）。

为什么有的保险，由政府强制？常被提到的理由（第 20、21 讲）：

- **逆向选择**：如果自愿，健康的人，会退出，保费涨，保险就崩溃；强制，让所有人，都进来；
- **近视**（第 36 讲、第 39 讲）：人们可能，低估将来的需要；
- **系统性风险**：私人，难以承担。

**价值判断（留给你）**：

1. **强制，还是自愿**：强制参加，减少了逆向选择，也减少了人们的选择自由。你觉得，该强制到什么程度？
2. **谁来付钱**：保险的成本，由个人缴费，还是由政府补贴（也就是，由别的纳税人）？
3. **道德风险**：慷慨的保障，也可能让人们不够小心（第 21 讲）：你怎么权衡"保障"和"激励"？

## 七、局限、常见误用

### 7.1 局限

- **期望效用，是一个基准**：人们的真实行为，更复杂（第 39 讲）。
- **对数效用**，只是一个常见的简化。
- **保险模拟**：参数是虚构的；真实的保险公司，有资本、再保险，监管。
- **美国的数据，不一定适用于别国**；过去的收益，不等于未来。
- **这一讲没有讲**：衍生品、期权、风险的更细的衡量、中国的保险和资本市场的具体情况。

### 7.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "期望值最大的选择，就是最好的" | 风险厌恶的人，要看效用；确定性等价，比期望值低 |
| "买保险，是亏的，因为保费高于期望的赔付" | 保费高于期望的赔付，仍然可以划算：它买的，是风险的转移 |
| "保险公司，保单越多越安全" | 要看风险是不是独立；相关的风险，保单再多，也没用 |
| "多买几只股票，就分散了" | 如果它们同步涨跌，分散不了多少；10 个行业，平均相关 0.53 |
| "分散化，可以消除所有的风险" | 只能消除特有风险；系统性风险，分散不掉 |
| "持有 20 年，股票就不会输" | 美国 99 年的重叠窗口，是个经验，不是保证 |
| "风险高的资产，一定有高回报" | 只有"系统性风险"，理论上才会被补偿；而且，回报是预期的，不是保证的 |
| "股权溢价，就是风险的补偿，没有谜" | 标准的模型，给不出这么高的溢价；几种解释，各有争论 |

## 八、小结

这一讲有六个想法，请带走：

1. **风险厌恶**：效用是凹的；确定性等价，低于期望财富；差额是风险溢价。
2. **保险**：风险的交易；人们愿意付高于公平保费的价格（其他财富越少，越愿意），保险公司，加价之后，双方都变好。
3. **大数定律**：独立的小风险，汇在一起，平均损失接近期望；需要很大的数，也需要风险独立；相关的风险（灾难、危机），分散不了。
4. **分散**：资产不完全同步，混在一起，风险降低；10 个行业，从 21.5% 到 16.1%，之后降不动；剩下的，是系统性风险。
5. **风险值钱**：美国股市 99 年，平均超额收益 8.86%，波动 20.1%，24 年下跌，最差 −43.8%；持有 20 年，没输给国库券，但这只是一个国家的经验。
6. **股权溢价之谜**：标准模型，解释不了这么高的溢价；罕见灾难、习惯形成等几种解释，各有争论。

## 思考题

**1.** 对数效用，你有 100 万元，一半的机会赢 20 万，一半的机会输 20 万。确定性等价是多少？风险溢价是多少？

> 提示：确定性等价 = exp(0.5 × ln 120 + 0.5 × ln 80) = √(120 × 80) = √9600 ≈ **97.98 万**；风险溢价 = 100 − 97.98 ≈ **2.02 万**。赌局的赢亏，越大，风险溢价越大（比较 2.2 节：±40 万，8.35 万）。

**2.** 两个资产，波动都是 20%，各投一半。相关系数是 0.5、0、−0.5 时，组合的波动是多少？

> 提示：组合波动 = σ × √[(1 + ρ) ÷ 2]：ρ = 0.5：20 × √0.75 ≈ **17.3%**；ρ = 0：20 × √0.5 ≈ **14.1%**；ρ = −0.5：20 × √0.25 = **10%**。相关系数越低，分散的效果，越好。

**3.** 一个保险公司：每份保单，2% 的概率赔 50，保费 1.2。N = 10000 份，风险互相独立。（用正态分布近似）每份保单平均赔付的标准差是多少？公司亏本的概率，大约是多少？

> 提示：期望赔付 = 0.02 × 50 = 1.0；每份保单的赔付的标准差 = √(0.02 × 0.98) × 50 ≈ 7.0；平均赔付的标准差 = 7.0 ÷ √10000 = **0.07**。安全垫 = 1.2 − 1.0 = 0.2，约 2.86 个标准差；亏本的概率，约 **0.2%**。

**4.** 本讲的美国股市数据：平均超额收益 8.86%，波动 20.1%，夏普比率 0.44。如果你，一半的钱买股市，一半买国库券（无风险），组合的超额收益、波动、夏普比率，是多少？

> 提示：超额收益 = 0.5 × 8.86 = **4.43%**；波动 = 0.5 × 20.1 = **10.05%**（国库券无风险）；夏普比率 = 4.43 ÷ 10.05 = **0.44**：不变。把钱，在"无风险资产"和"风险资产"之间分配，改变的是风险的大小，不是每单位风险的回报。

**5.** （开放题）"美国股市，持有 20 年，80 个窗口里，赢了 80 次，所以，长期持有股票，没有风险。"这个推理，有什么问题？

> 提示：（1）**窗口是重叠的**：99 年里，只有大约 4 到 5 个互不重叠的 20 年，80 个窗口，不是 80 次独立的实验；（2）**一个国家的经验**，美国是 20 世纪的赢家，别的国家的经历，不一定；（3）**"没输给国库券"，不等于"没有风险"**：你的 20 年，可能，真的是一个糟糕的 20 年，而你的人生，只有一个 20 年；（4）**未来不保证**，（5）你能不能撑过中间的下跌（比如，亏 44% 的一年），也影响你的真实结果。
