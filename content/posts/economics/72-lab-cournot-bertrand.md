这是第三个**实验**。第 16 讲，我们用手算和一小段代码，得到了景区门口两家烤肠摊的几个结果：比卖量（Cournot），各卖 300 根，价格 5 元；比价格（Bertrand），价格被一分钱一分钱地压到 2.01 元；产能一限，价格又回到 5 元。那一讲有一个没有说破的问题：**摊主是怎么走到这些均衡的？**

均衡只是说："如果大家已经在那里，就没人想动。"它没有说："不管从哪里出发，都到得了那里。"这个实验要做的，就是让摊主**一轮一轮地调整**，看他们走不走得到、走到哪里、走的方式有没有影响。你会发现，有的结果和你的直觉一致，有的不一致。

**怎么用**：和前两个实验一样，代码块是**接着往下写**的：后面的块会用到前面块里定义的东西。把它们依次拼成一个文件（比如 `lab72.py`），用 `python lab72.py` 运行；也可以一段一段地在 Python 里依次运行。**只需要 Python 3 和 NumPy**，全部运行约 6 秒。这个实验里**没有随机数**：每一步都是确定的，所以你跑出来的数字，会和下面的输出一模一样。

## 一、四个问题

**先停一下：请先凭直觉，回答下面四个问题，写下来。**

**问题 1：** 景区那条街上有十家烤肠摊。每天，每家摊主都看别人昨天卖了多少，然后把自己调整到"在这个条件下最好"的卖量。大家同时调整。时间长了，会走到 Cournot 均衡（每家 81.8 根）吗？

**问题 2：** 十家摊里，有两家合并成一家（成本不变）。合并后的这一家，利润会比合并前两家的利润之和更高吗？价格会涨吗？

**问题 3：** 两家烤肠摊比价格，轮流降价抢客。价格牌上最小只能写到"一分钱"，和最小只能写到"一块钱"，价格战的结局一样吗？

**问题 4：** 两家烤肠摊都把每天的产能扩到 500 根（第 16 讲的 Cournot 均衡是 300 根）。价格会稳定在 5 元吗？

我们会一个一个回来。

## 二、实验的设计

### 2.1 市场和摊主

市场和第 16 讲完全一样：游客的需求是 P = 11 − 0.01 Q（Q 是每天卖出的根数），每根成本 2 元，没有固定成本。

摊主是什么样的人？我们有意把他们设计得**很"笨"**：每一轮，他们**看到别人现在卖多少（或者标什么价），就按第 16 讲 3.1 节的办法，算出"在这个条件下我最好的做法"，然后照做**。他们不会想"如果我这样，对方会怎样反应"，不会记仇，也不会考虑将来。这在经济学里叫**最佳反应调整**（best-reply dynamics）。

为什么要这么笨？因为实验 70 已经给了我们一个启发：一群没有多少智力的交易者，也能把一个市场带到均衡。那么，一群"只会对眼前做最好反应"的摊主，能不能把寡头市场带到均衡？答案要看他们**调整的节奏**，这就是这个实验的第一个主角。

### 2.2 三种节奏

- **同时调整**：每一轮，所有摊主一起看**上一轮**别人的卖量，一起调整。
- **轮流调整**：摊主一个接一个地调整，后面的人看到的，是前面的人**刚刚调整完**的卖量。（第 16 讲里，"甲按乙调整，再乙按甲调整"，就是轮流。）
- **带惯性的调整**：每一轮只往"最佳卖量"的方向走一部分（比例是 λ，0 < λ ≤ 1）；λ = 1 就是没有惯性。

### 2.3 价格竞争的设定

比价格时，两家的产品一模一样，游客只买便宜的那家，价格一样就各买一半。价格只能是某个"最小单位"（step）的整数倍：1 分钱、5 分钱，或者 1 块钱。两家**轮流**调整价格，每次都是对对方当前价格的最佳反应。产能有限时，便宜的那家先卖，卖完了，顾客才去另一家，而且先被便宜的那家拿走的，是**愿付价最高的**顾客（和第 16 讲 4.3 节一样，这叫"有效率的配给"）。

## 三、第一步：把第 16 讲的数字算一遍

```python
import numpy as np

# 景区门口的烤肠摊（和第 16 讲一样）：游客的需求 P = 11 - 0.01 Q，每根成本 2 元，没有固定成本
A, B, MC = 11.0, 0.01, 2.0

def price(total):
    return max(A - B * total, 0.0)

def profit(q, others, c=MC):
    """我卖 q 根、别的摊一共卖 others 根时，我的利润"""
    return (price(q + others) - c) * q

def best_reply(others, c=MC):
    """令边际收益 = 边际成本，得到最佳卖量的公式；卖量不能是负的"""
    return max((A - c - B * others) / (2 * B), 0.0)

# 核对 1：公式，和"把 0 到 900 的卖量全试一遍"，答案一样吗？
grid = np.arange(0, 900.01, 0.5)
for others in (0, 150, 300, 450):
    brute = grid[np.argmax([profit(q, others) for q in grid])]
    print(f"别的摊卖 {others:>3} 根：公式 {best_reply(others):6.1f}，全部试一遍 {brute:6.1f}")

# 核对 2：N 家一样的摊，均衡里每家卖 (A - c) / (B (N + 1))
print("\n  N   每家卖    价格    每家利润")
for n in (1, 2, 3, 5, 10):
    q = (A - MC) / (B * (n + 1))
    print(f"{n:>3} {q:>8.1f} {price(n * q):>7.2f} {profit(q, (n - 1) * q):>10.2f}")

# 核对 3：两家轮流调整（第 16 讲那一行输出）。每一轮：甲按乙调整，然后乙按甲调整
q1, q2 = 100.0, 500.0
path = [(q1, q2)]
for _ in range(5):
    q1 = best_reply(q2); q2 = best_reply(q1); path.append((q1, q2))
print("\n轮流调整：" + " -> ".join(f"({a:.0f}, {b:.0f})" for a, b in path))
```

- **同时调整**：路径不一样，(100, 500) → (200, 400) → (250, 350) → ……，但也走到了 (300, 300)。两家的时候，两种节奏都行。

## 四、第二步：N 家摊同时调整

第 16 讲只看了两家。现在，让摊数增加，每家从均衡附近出发（甲比均衡多卖 20 根，其他家刚好在均衡上），**同时**调整：

```python
def iterate(q0, rounds, mode="simul", lam=1.0, costs=None):
    """N 家摊反复调整卖量。
    mode="simul"：大家同时看上一轮对方的卖量，一起调整（lam < 1 表示只调整一部分，叫"惯性"）
    mode="alt"  ：轮流来，每家调整时，看到的是别人最新的卖量
    返回一个数组：第 r 行是第 r 轮之后每家的卖量"""
    q = np.array(q0, dtype=float); n = len(q)
    costs = np.full(n, MC) if costs is None else np.asarray(costs, dtype=float)
    hist = [q.copy()]
    for _ in range(rounds):
        if mode == "simul":
            new = np.array([best_reply(q.sum() - q[i], costs[i]) for i in range(n)])
            q = (1 - lam) * q + lam * new
        else:
            for i in range(n):
                q[i] = (1 - lam) * q[i] + lam * best_reply(q.sum() - q[i], costs[i])
        hist.append(q.copy())
    return np.array(hist)

# 先看两家：同时调整，和轮流调整，都能走到 (300, 300) 吗？
for mode in ("simul", "alt"):
    h = iterate([100, 500], 12, mode)
    print(f"{mode:>5}：" + " -> ".join(f"({a:.0f},{b:.0f})" for a, b in h[[0, 1, 2, 3, 6, 12]]))

# 再看 N 家，从均衡附近出发（每家比均衡多卖 20 根），同时调整 8 轮
print("\n同时调整，每家的卖量（均衡值 = 450 / (N + 1)）：")
for n in (2, 3, 4, 5):
    star = (A - MC) / (B * (n + 1))
    start = np.full(n, star); start[0] += 20
    h = iterate(start, 8, "simul")
    print(f"N = {n}（均衡 {star:6.1f}）：甲的卖量 " + " ".join(f"{x:6.1f}" for x in h[:9, 0]))

# N = 5 时，市场上整体发生了什么？看总卖量和价格
n = 5; star = (A - MC) / (B * (n + 1))
start = np.full(n, star); start[0] += 20
h = iterate(start, 12, "simul")
print("\nN = 5：总卖量和价格（均衡：总卖量 750，价格 3.50）")
for r in range(0, 13, 2):
    print(f"  第 {r:>2} 轮：总卖量 {h[r].sum():7.1f}，价格 {price(h[r].sum()):.2f}，各家卖量 {np.round(h[r], 0)}")
```

这和你的直觉一样吗？看每一行：

- **N = 2**：甲的卖量 320 → 300 → 305 → 300 → 301.2 → ……，来回摆动，幅度一次比一次小，走到 300。
- **N = 3**：245 → 225 → 235 → 220 → 232.5 → 218.7 → 231.9 → 218.4 → 231.7。**摆动的幅度不再缩小**，也不放大，永远在 218 和 232 附近来回。

均衡是**存在的**（N = 4 时每家 180，N = 5 时每家 150），可是这群"笨"摊主，**同时调整，走不到它**。问题 1 的答案：**不会**。十家摊同时调整，卖量会剧烈摆动，直到撞上"卖量不能是负的"这堵墙。

## 五、第三步：为什么？怎么救？

### 5.1 为什么

看均衡附近。别人的总卖量每多 1 根，我的最佳卖量少 0.5 根（最佳反应的斜率是 −0.5，见第 16 讲 3.1 节）。如果**所有其他 N − 1 家**都多卖了 1 根，我的最佳卖量就少 (N − 1) ÷ 2 根。而大家又都这样反应，所以，**一轮之后，偏差大致被乘以 −(N − 1) ÷ 2**：负号表示"反向"，绝对值表示"放大还是缩小"。

- N = 2：乘以 −0.5，偏差缩小一半，反向，再缩小……，收敛。
- N = 3：乘以 −1，大小不变，反向，永远摆动。
- N ≥ 4：绝对值大于 1，越摆越大。

这就是 Theocharis（1960 年，*Review of Economic Studies*，27 卷 2 期，133–134 页；也有文献把年份标为 1959）发现的结果：**需求是直线、成本不变时，Cournot 均衡在同时调整下，企业多于三家就不稳定**。（这是一篇很短的文章；我只核对了它的出处，没有逐行读它的推导，所以这里的解释是我们自己用代码验证的。）

我们让代码把"乘数"算出来，并试两个药方：

```python
# 为什么：均衡附近，"同时调整"每一轮把偏差乘以一个数。这个数，就是调整的"雅可比矩阵"的特征值
def one_round_matrix(n, mode):
    """在均衡附近，一轮调整把「偏差」变成多少：一个 n × n 的矩阵（对均衡处的微小偏差做一轮，逐列读出来）"""
    star = np.full(n, (A - MC) / (B * (n + 1))); G = np.zeros((n, n))
    for j in range(n):
        start = star.copy(); start[j] += 1e-3
        G[:, j] = (iterate(start, 1, mode)[1] - star) / 1e-3
    return G

print("一轮调整之后，偏差被放大（>1）还是缩小（<1）？最大特征值的绝对值：")
print("  N     同时调整   轮流调整")
for n in (2, 3, 4, 5, 10, 20):
    rho = lambda mode: np.abs(np.linalg.eigvals(one_round_matrix(n, mode))).max()
    print(f"{n:>3} {rho('simul'):>11.3f} {rho('alt'):>10.3f}   （同时调整：(N - 1) / 2 = {(n - 1) / 2:.1f}）")

# 药方一：加"惯性"，每一轮只调整一部分 lam。用二分法找：最大的、还能收敛的 lam
def converges(n, lam, rounds=4000):
    star = (A - MC) / (B * (n + 1))
    start = np.full(n, star); start[0] += 20
    h = iterate(start, rounds, "simul", lam)
    return abs(h[-1] - star).max() < 1e-6

print("\n药方一：惯性。最大的可收敛调整比例 lam（对照公式 4 / (N + 1)）：")
for n in (4, 5, 10, 20):
    lo, hi = 0.0, 1.0
    for _ in range(25):
        mid = (lo + hi) / 2
        if converges(n, mid): lo = mid
        else: hi = mid
    print(f"N = {n:>2}：{lo:.4f}（公式 {4 / (n + 1):.4f}）")

# 药方二：轮流调整。N = 10，每家从 100 根出发，看离均衡（81.8）最远的那家差多少
n = 10; star = (A - MC) / (B * (n + 1))
h = iterate(np.full(n, 100.0), 60, "alt")
print("\n药方二：轮流调整，N = 10，离均衡最远的那家差多少：")
print("  第 0、1、2、5、10、20、40 轮：" + "、".join(f"{abs(h[r] - star).max():.2f}" for r in (0, 1, 2, 5, 10, 20, 40)))
print("轮流调整，要几轮才能让每家离均衡都不超过 0.5 根：")
for n in (2, 5, 10, 20, 40):
    star = (A - MC) / (B * (n + 1)); h = iterate(np.full(n, 100.0), 4000, "alt")
    r = int(np.argmax(abs(h - star).max(axis=1) < 0.5))
    print(f"  N = {n:>2}：{r} 轮")
```

逐段看：

- **放大倍数**：同时调整，N = 2、3、4、5、10、20，最大特征值的绝对值是 0.5、1.0、1.5、2.0、4.5、9.5，恰好是 (N − 1) ÷ 2。**轮流调整，每一个都小于 1**：0.25、0.35、0.46、0.54、0.78、0.92，所以一定收敛。（对任何 N 都小于 1，是有数学定理保证的：这个迭代，等价于用 Gauss–Seidel 方法解一个对称正定的线性方程组。这里我们只验证到 N = 20。）
- **药方一：惯性**。如果每一轮只调整一部分（比例 λ），能收敛的最大 λ 是 4 ÷ (N + 1)：N = 4 是 0.8、N = 10 是 0.364、N = 20 是 0.19。企业越多，**每个摊主越要"慢"**。
- **药方二：轮流调整**。N = 10 时，轮流调整，二十来轮之内，每家都走到了 81.8 附近（20 轮时最远的一家只差 0.28 根）。代价是慢：N = 2 要 5 轮，N = 10 要 18 轮，N = 40 要 198 轮。**企业越多，越慢，但一定到。**

### 5.2 这说明了什么

**到得了均衡，不只取决于均衡本身，还取决于"怎么走"。** 同一个市场、同一群笨摊主，同时调整走不到，轮流调整走得到。这对现实的含义是：当一个市场里的企业很多、而且对彼此的行动反应得**又快又过头**（比如，价格每天按对手昨天的价格重新定），**稳定的均衡也可能表现为剧烈的波动**。

这不是说现实里的摊主真的这么调整。它说的是：**"均衡存在"和"均衡会被走到"是两个不同的命题**。第 18 讲 5.2 节，让两个人"对对方到目前为止的出手频率做最佳应对"，在点球博弈里，频率走到了均衡；那是零和博弈，收敛有保证。这个实验里的寡头市场不是零和博弈，摊主又只盯着上一轮，结果就不同了：**用最佳反应的"互相适应"去找均衡，并不是在所有博弈里都找得到。**

## 六、第四步：成本不同；两家合并

### 6.1 成本不同

现实里的摊主，成本不会一模一样。设三家摊的成本是 1.5、2.0、2.5（甲有便宜的货源）。成本不同时，Cournot 均衡的公式是 q_i = (A − (N + 1)c_i + 所有人的成本之和) ÷ (B (N + 1))；如果某家算出来是负的，说明它根本进不了市场，把它去掉，再算一遍。

### 6.2 合并

第 16 讲 7 节讲了合并：企业合并，少了一个对手，价格会不会涨？Cournot 模型给出了一个出人意料的答案。

```python
def cournot(costs):
    """成本各不相同的 Cournot 均衡。公式：q_i = (A - (n+1) c_i + 所有人的成本之和) / (B (n+1))；
    如果某家算出来是负的，它就不卖了，把它去掉再算一遍。"""
    costs = np.asarray(costs, dtype=float)
    active = np.ones(len(costs), dtype=bool)
    while True:
        n = active.sum()
        q = np.where(active, (A - (n + 1) * costs + costs[active].sum()) / (B * (n + 1)), 0.0)
        if (q >= 0).all(): break
        active[np.argmax(np.where(q < 0, costs, -1))] = False     # 去掉成本最高的、卖量为负的那家
    p = price(q.sum())
    return q, p, (p - costs) * q
```

最后这一条，对应 Farrell 和 Shapiro 1990 年（*American Economic Review*，80 卷 1 期，107–126 页）的结论：在 Cournot 模型里，没有成本节约（协同效应）的合并，一定涨价；只有协同效应**足够大**，价格才可能下降。我们的数字，是这个结论的一个具体例子（线性需求、十家一样的摊、两家合并）。

**这不是说，现实里的合并都是坏事，也不是说，企业的合并都是亏本买卖。** 它说的是：**在"同质产品、数量竞争"这个具体模型里**，不涉及成本节约的合并，对合并企业自己可能是亏的，对消费者一定是涨价的。如果换成"价格竞争、产品有差异"的模型，合并更容易有利可图（这是文献里常见的对照；本实验没有计算，这门课也没有专门展开产品差异）。所以，监管者审合并，要问的是**具体问题**：产品是不是同质的？企业比的是什么？合并能省多少成本？这是第 16 讲 7.2 节和 Williamson（1968）"成本节约对涨价"的权衡。

## 七、第五步：价格战

现在比价格。每家摊轮流定价，每次都是对对方当前价格的最佳反应。**如果有好几个价格一样好，选最接近自己成本的那个**（赚不了钱，就别乱降价）。

```python
demand = lambda p: np.maximum(1100.0 - 100.0 * p, 0.0)          # 把 P = 11 - 0.01 Q 反过来写：Q = 1100 - 100 P

def bertrand_br(p_rival, c, step):
    """产品一模一样、产能不限。我的价格只能是 step 的整数倍。在这些价格里，选利润最大的；
    如果有好几个一样好，选最接近我自己成本的那个（没有赚头，就别乱降价）。"""
    prices = np.arange(0.0, 11.0 + step / 2, step)
    d = demand(prices)
    sold = np.where(prices < p_rival - 1e-9, d, np.where(prices > p_rival + 1e-9, 0.0, d / 2))   # 便宜的全拿，一样平分
    pi = (prices - c) * sold
    best = np.flatnonzero(pi >= pi.max() - 1e-9)
    return prices[best[np.argmin(abs(prices[best] - c))]]

def price_war(p1, p2, c1=2.0, c2=2.0, step=0.01, max_moves=5000):
    """两家轮流定价（甲先），每次都是对对方当前价格的最佳反应，直到谁也不想动"""
    path = [(p1, p2)]; still = 0
    for t in range(max_moves):
        if t % 2 == 0: new = bertrand_br(p2, c1, step); changed = abs(new - p1) > 1e-9; p1 = new
        else:          new = bertrand_br(p1, c2, step); changed = abs(new - p2) > 1e-9; p2 = new
        path.append((p1, p2)); still = 0 if changed else still + 1
        if still == 2: break
    return np.array(path)

print(f"一分钱一档：从 (6.50, 6.50) 出发，共调整 {int((abs(np.diff(w, axis=0)).sum(axis=1) > 1e-9).sum())} 次，停在 ({w[-1][0]:.2f}, {w[-1][1]:.2f})；每家利润 {(w[-1][0] - MC) * demand(w[-1][0]) / 2:.2f}")

# 成本不一样：甲 2 元，乙 3 元（第 16 讲思考题 3）
```

## 八、第六步：产能中等，价格不稳定

第 16 讲 4.3 节说：每家产能 300 根时，(5, 5) 是均衡。那么，产能如果是别的数呢？先看，对不同的产能 k，网格上有没有"谁也不想单独改价"的价格组合；再看没有的时候，价格怎么走。

```python
# 产能有限（每家最多 k 根）。便宜的先卖，卖完了顾客才去另一家；愿付价最高的顾客，先被便宜的那家拿走
def sales(p_me, p_rival, k_me, k_rival):
    d_me, d_rival = demand(p_me), demand(p_rival)
    cheaper = np.minimum(k_me, d_me)                                                           # 我更便宜：顾客都来，但我最多卖 k_me
    dearer = np.minimum(k_me, np.maximum(d_me - np.minimum(k_rival, d_rival), 0.0))            # 我更贵：对方先卖，剩下的才是我的
    same = np.minimum(k_me, np.maximum(d_me / 2, d_me - k_rival))                              # 一样价：平分，对方卖不完的归我
    return np.where(p_me < p_rival - 1e-9, cheaper, np.where(p_me > p_rival + 1e-9, dearer, same))

def capacity_br(p_rival, k_me, k_rival, step):
    prices = np.arange(0.0, 11.0 + step / 2, step)
    pi = (prices - MC) * sales(prices, p_rival, k_me, k_rival)
    best = np.flatnonzero(pi >= pi.max() - 1e-9)
    return prices[best[-1]]                                      # 一样好的，选最高的价格

def pure_equilibria(k, step=0.05):
    """网格上所有「谁也不想单独改价」的价格组合（两家产能一样，所以只要查一家的利润）"""
    prices = np.arange(MC, 11.0 + step / 2, step)
    best_vs = np.array([((prices - MC) * sales(prices, r, k, k)).max() for r in prices])       # 对方定 r，我最多能赚多少
    out = []
    for i, p1 in enumerate(prices):
        for j, p2 in enumerate(prices):
            u1 = (p1 - MC) * sales(p1, p2, k, k); u2 = (p2 - MC) * sales(p2, p1, k, k)
            if u1 >= best_vs[j] - 1e-9 and u2 >= best_vs[i] - 1e-9: out.append((round(float(p1), 2), round(float(p2), 2)))
    return out

print("产能各 k 根，有没有「谁也不想单独改价」的价格组合？（价格取到 5 分钱，只列出最低的一个）")
for k in (100, 200, 250, 300, 350, 500, 700, 800, 900, 1000):
    eq = pure_equilibria(k)
    print(f"  k = {k:>4}：" + (f"有，价格 {eq[0][0]:.2f}（网格上共 {len(eq)} 个组合）" if eq else "没有"))

# 没有稳定的价格，会怎样？让两家轮流、各自对对方当前的价格做最佳反应，看价格怎么走
def edgeworth(k, start=(6.0, 6.0), moves=3000, step=0.01):
    p = list(start); path = [tuple(p)]
    for t in range(moves):
        i = t % 2
        p[i] = capacity_br(p[1 - i], k, k, step); path.append(tuple(p))
    return np.array(path)

print("\n轮流最佳反应（价格一分钱一档，从 (6.00, 6.00) 出发，丢掉前 1000 次，看后面的）：")
for k in (300, 500, 700):
    w = edgeworth(k)[1000:]
    avg_profit = np.mean([((a - MC) * sales(a, b, k, k) + (b - MC) * sales(b, a, k, k)) / 2 for a, b in w])
    jumps = [t for t in range(1, len(w)) if w[t, 0] - w[t - 1, 0] > 0.5]
    period = f"，每 {jumps[1] - jumps[0]} 次调整循环一圈" if len(jumps) > 1 else "，不循环"
    print(f"  k = {k}：价格在 {w.min():.2f} 到 {w.max():.2f} 之间，平均价格 {w.mean():.2f}，每家平均利润 {avg_profit:.1f}{period}")
```

逐段看：

  - k = 700：价格在 2.15 到 3.00 之间循环，平均价格 2.58，利润 237。

**循环是怎么来的？** 看图中蓝色的锯齿：两家互相降价，每次降一分钱，因为降价就能抢走对方的顾客。降到 2.81，再降下去，不如**放弃抢客**：跳回"对方卖完以后，剩下的游客愿意付的最好价格"（4.00），只卖给剩下的游客。可是，价格一高，对方马上又来降一分钱抢你的顾客，**战争重新开始**。这就是**Edgeworth 价格循环**；Maskin 和 Tirole 在 1988 年（*Econometrica*，56 卷 3 期，571–599 页），用"轮流定价"的博弈，给了它一个博弈论的基础。

问题 4 的答案：**不会稳定**。每家产能 500 根时，价格不是 5 元，而是在 2.81 到 4.00 之间循环，平均 3.40，每家平均利润 525.5，比产能 300 时的 901.5 少了四成多。**产能多了，不是好事**（即使这些产能不花钱）。这和 Kreps 和 Scheinkman（1983 年，*Bell Journal of Economics*，14 卷 2 期，326–337 页）的直觉是一致的：两家同时把产能扩大，对双方都不利。至于**一家单独扩产**划不划算，要看扩产本身要花多少钱，这正是他们用"产能有成本"回答的问题；我们的实验里产能不花钱，没有模拟这一步。

**这里有三个要提醒的地方**：

1. 我们模拟的，是一种**最佳反应调整**，不是对博弈"均衡"的求解。严格的 Kreps–Scheinkman 结论，需要的是整个两阶段博弈的均衡，中等产能下，价格阶段的均衡是**混合策略**（价格是随机的）。我们的实验只是给出了一个**直观的、看得见的**版本。
2. 它依赖**配给规则**。我们用的是"有效率的配给"（愿付价最高的顾客，先被便宜的那家拿走）。Davidson 和 Deneckere（1986 年，*RAND Journal of Economics*，17 卷 3 期，404–415 页）指出：只有这一条规则，才能让 Kreps–Scheinkman 的 Cournot 结果成立；换成别的规则，两阶段博弈的结果，会比 Cournot **更竞争**。（据二手转述，请读原文。）
3. 现实里确实有价格循环。Eckert（2002 年，*Canadian Journal of Economics*，35 卷 1 期，52–77 页）研究了加拿大温莎市（Windsor, Ontario）的零售汽油价格；Noel（2007 年，*Review of Economics and Statistics*，89 卷 2 期，324–334 页）用加拿大多个城市的数据，估计了价格循环出现的频率，发现小企业多的市场，循环更常见。（我只核对了这两篇文章的摘要和出处。）汽油站和烤肠摊是类比，不是同一个模型。

## 九、第七步：合谋的门槛

最后，把第 19 讲的合谋门槛，用代码再算一遍，并问两个新问题：**惩罚更狠，合谋会更容易吗？比价格，和比数量，哪个更难合谋？**

N 家摊约好：每家卖垄断量的 1/N。某家**偷偷多卖一次**，当期多赚，以后被惩罚。δ 是耐心程度（下一期的 1 元，今天值 δ 元）。偷偷多卖划算与否，要比的是：今天多赚的，对比以后每期少赚的（折现之后）。打平的 δ，叫门槛 δ*：**δ 大于门槛，合谋能维持**。

```python
def collusion(n):
    """N 家摊约好：每家卖垄断量的 1/N。返回：守约的利润、偷偷多卖一次的利润、永远回到 Cournot 的利润"""
    q_m = (A - MC) / (2 * B) / n
    q_dev = best_reply((n - 1) * q_m)
    q_c = (A - MC) / (B * (n + 1))
    return profit(q_m, (n - 1) * q_m), profit(q_dev, (n - 1) * q_m), profit(q_c, (n - 1) * q_c)

def delta_star(stay, dev, punish):
    """偷偷多卖一次，今天多得 dev - stay；之后每期少得 stay - punish。两边打平的耐心程度"""
    return (dev - stay) / (dev - punish)

# 在"无限期"里（这里取 4000 期，之后的折现小到可以忽略）直接比一比两条路
def value(first, later, delta, T=4000):
    return first + sum(later * delta ** t for t in range(1, T))

print("N 家摊合谋，偷偷多卖一次，被发现后永远回到 Cournot 的卖量：")
print("  N   守约    偷偷多卖   惩罚期的   门槛 δ*   δ*±0.01 时，守约的总收益 − 偷偷多卖的")
for n in (2, 3, 5, 10):
    stay, dev, pun = collusion(n); d = delta_star(stay, dev, pun)
    gaps = [value(stay, stay, x) - value(dev, pun, x) for x in (d - 0.01, d + 0.01)]
    print(f"{n:>3} {stay:>7.1f} {dev:>9.1f} {pun:>9.1f} {d:>9.3f}   {gaps[0]:>+8.1f}, {gaps[1]:>+8.1f}")

print("\n换成更狠的惩罚，或者换成比价格的市场，门槛 δ* 怎么变？")
print("  N   数量竞争      数量竞争        价格竞争（偷偷的人在垄断价上降一分钱，")
print("      Cournot 惩罚  价格战惩罚      吃下全部游客）+ 价格战惩罚")
p_m = (A + MC) / 2
for n in (2, 3, 5, 10):
    stay, dev, pun = collusion(n)
    steal = (p_m - 0.01 - MC) * demand(p_m - 0.01)
    print(f"{n:>3} {delta_star(stay, dev, pun):>10.3f} {delta_star(stay, dev, 0.0):>14.3f} {delta_star((p_m - MC) * demand(p_m) / n, steal, 0.0):>14.3f}（1 - 1/N = {1 - 1 / n:.3f}）")

delta = 0.9
print(f"\nδ = {delta} 时，最多几家还能维持合谋：")
for name, f in (("数量竞争 + Cournot 惩罚", lambda n: delta_star(*collusion(n))),
                ("数量竞争 + 价格战惩罚", lambda n: delta_star(*collusion(n)[:2], 0.0)),
                ("价格竞争 + 价格战惩罚", lambda n: 1 - 1 / n)):
    print(f"  {name}：{max(n for n in range(2, 400) if f(n) <= delta)} 家")
```

## 十、这个实验说明了什么，没说明什么

**说明了：**

1. **均衡不一定"走得到"。** 同样的市场、同样的笨摊主，同时调整，企业多于三家，就不收敛；轮流调整，就收敛；加一点惯性，也能收敛。企业越多，越要"慢"。
2. **Cournot 里，没有成本节约的合并，多数时候让合并企业自己亏**，对消费者一定涨价。（十家摊里，要合并到 90% 才开始有利可图。）
3. **Bertrand 的极端结果，取决于价格能标多细，和产能。** 价格有最小单位，停在"成本 + 一格"；产能中等时，没有稳定价格，价格循环。
4. **合谋的门槛，随企业数上升，随惩罚加重而下降，比价格比比数量更高。**

**没说明：**

1. 现实里的摊主，**不是机械的"最佳反应"**。他们会预测对手、会学习、会记仇，也会用我们没有建模的方式沟通。同时调整不收敛的结果，是**对这一种调整规则**的结果。
2. 所有结果，来自一个**特定的例子**：线性需求、成本不变、产品完全一样、没有固定成本、没有进入。换一个设定，数字会变，有的定性结论也会变。
3. 合并分析，只看了合并对价格和利润的作用，没有看**进入**（涨价会引来新摊）、**产品差异**和**质量**。
4. 价格循环，是一种特定动力学的结果，不是对它是不是"现实的解释"的证明。

> 提示：（a）**(2.50, 2.50)**，每家 (2.5 − 2) × 850 ÷ 2 = **212.5**。（b）k = 250：11 − 0.02 × 250 = **6.00**（代码里网格上还有 6.05，是网格的缘故）。k = 400：价格在 **3.57 到 4.50** 之间循环，平均 **4.04**，每家平均利润 **704.5**，比 500 时（525.5）高，比 300 时（901.5）低。

**练习 6（合谋）。** 四家摊。（a）用 Cournot 做惩罚，门槛 δ* 是多少？（b）用价格战做惩罚，是多少？

> 提示：N = 4：守约 **506.25**，偷偷多卖 **791.02**，Cournot 惩罚 **324.00**。（a）(791.02 − 506.25) ÷ (791.02 − 324.00) = **0.610**（和第 19 讲一致）。（b）(791.02 − 506.25) ÷ 791.02 = **0.360**。

## 十三、局限

- **线性需求、不变成本、一模一样的产品**：几乎所有数字，都是这个例子的。不要把它们当成"一般规律"。
- **最佳反应调整**是一个**模型**，不是现实的描述；同时调整是否收敛，取决于企业的反应方式。
- **产能的实验**，用的是网格上的最佳反应，价格一分钱一档；循环的周期和范围，取决于网格。
- **没有进入、没有产品差异、没有不完全信息、没有学习算法。** 最后这一条，第 19 讲 9.3 节已经讨论过：Calvano、Calzolari、Denicolò 和 Pastorello（2020 年，*American Economic Review*，110 卷 10 期，3267–3297 页）让会学习的定价算法（Q 学习）在重复的价格竞争里交手，算法学会了高于竞争水平的价格。那是一个仍有争议的研究方向。我们这里的"笨摊主"，比它们简单得多：他们不会学习，只会对眼前做最佳反应。
