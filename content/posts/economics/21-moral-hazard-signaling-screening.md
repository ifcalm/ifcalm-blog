这一讲要回答五个问题：

1. 什么是**道德风险**？有了保险，为什么人会变得不那么小心？合同怎么应对？
2. **委托—代理问题**：怎么设计合同，让一个你看不到努力的人，做你想要的事？为什么激励总要付出风险的代价？
3. **效率工资**：为什么有的企业，故意付高于市场的工资？
4. **信号**：教育是在提高能力，还是在证明能力？什么样的信号才可信？
5. **筛选**：没有信息的一方，怎么设计选项，让对方自己说出真相？

上一讲，我们看了**交易之前**的信息问题：买家看不出车的好坏，卖家知道。这一讲看**交易之后**，以及双方各自怎么"主动出手"对付信息问题。注意一个顺序：**有信息的一方先出手**（用信号证明自己），还是**没有信息的一方先出手**（设计菜单让对方自选）？这决定了信号和筛选的区别。

## 一、买了保险之后

你给新手机买了碎屏险。

**先停一下：买保险之前和买保险之后，你对这部手机的态度，会有什么变化？**

你大概会承认，有一点点不一样：不装手机壳了，随手放在口袋边缘，在桌上放得更随意一点。你不是变坏了，而是你对**激励**做出了反应（第 2 讲）：手机摔碎，以前你要自己出钱修，现在大部分由保险公司付。**小心的代价没变，小心的好处变小了。**

这就是**道德风险**（moral hazard）：

> 合同达成之后，一方的**行动**，另一方**看不到**（或者没法证实），而这个行动会影响双方的利益。有保险的人变得不那么小心，是最典型的例子。

这个词最早来自保险业。它里面的"道德"，并不是说被保险人品德有问题：**他只是在做对自己最有利的选择。** 和第 20 讲对比：逆向选择里，问题是对方**是什么类型**（交易之前就定了）；道德风险里，问题是对方**会做什么**（交易之后才发生）。

## 二、保险里的道德风险

### 2.1 一个能算的例子

你有 20 万财富，开车一年，有可能出事故，损失 10 万。你可以选择：

- **小心**：事故概率 10%，但小心要花力气，折合 0.5 万；
- **随意**：事故概率 20%，不花力气。

保险公司看不到你小不小心，只看得到事故。保险公司之间竞争，保费等于预期赔付（不赚不亏），并且保险公司会**预料到**你在这份合同下会怎么做。

合同的一个关键参数是**免赔额** d：出了事故，前 d 万你自己付，其余由保险公司赔。

- **全额保险**（d = 0）：出了事故你一分钱不用付，小心对你没有好处，你就不小心。事故概率是 20%，保费就是 2 万，你的财富稳定在 18 万。
- **免赔额很高**：你仍然要承担大部分损失，所以你有动力小心，但你得到的保障很少。

怎么权衡？用代码把"保险公司按你的行为定价，你在这个价下自己选"算清楚：

```python
from math import log

# 开车：财富 20 万；出事故损失 10 万。你可以"小心"（事故概率 10%，但小心要花力气，折合 0.5 万）或"随意"（事故概率 20%，不花力气）。
# 保险合同：保费 + 免赔额 d（出了事故，前 d 万你自己付，其余保险公司赔）。保险公司看不到你小不小心，只能在合同下按你"会选的做法"定公平保费。
W, LOSS, EFFORT = 20.0, 10.0, 0.5
P_CAREFUL, P_LAX = 0.10, 0.20
u = log                                                      # 对数效用：怕风险

def eu(action, premium, d):
    p = P_CAREFUL if action == "小心" else P_LAX
    cost = EFFORT if action == "小心" else 0.0
    ok, bad = W - premium - cost, W - premium - cost - d     # 没出事故 / 出事故（自己付 d）
    return (1 - p) * u(ok) + p * u(bad)

def fair_premium(action, d):                                 # 保险公司不赚不亏：保费 = 事故概率 × 赔付额
    return (P_CAREFUL if action == "小心" else P_LAX) * (LOSS - d)

def outcome(d):
    """合同 d 下的均衡：保费按你会选的做法定；你在这个保费下，确实愿意选这个做法"""
    pc = fair_premium("小心", d)
    if eu("小心", pc, d) >= eu("随意", pc, d):               # 按"小心"定价，你是否真的小心？
        return "小心", pc, eu("小心", pc, d)
    pl = fair_premium("随意", d)
    return "随意", pl, eu("随意", pl, d)

print("免赔额 d 越高，你越有动力小心（出事故你自己要付 d）；但保障也越少")
best = None
for d in (0, 1, 2, 3, 4, 5, 6, 8, 10):
    act, prem, val = outcome(d)
    print(f"  d={d:>2}：你会{act}，公平保费 {prem:.2f}，期望效用 {val:.4f}")
for d10 in range(0, 101):                                    # 细一点：每 0.1 万一格，找最好的免赔额
    d = d10 / 10
    act, prem, val = outcome(d)
    if best is None or val > best[3] + 1e-12: best = (d, act, prem, val)
print(f"\n细搜之后最好的免赔额：d={best[0]:.1f}，你会{best[1]}，保费 {best[2]:.2f}，期望效用 {best[3]:.4f}")

# 对照：如果保险公司看得到你小不小心，可以写进合同——全额保险 + 你必须小心
first_best = u(W - P_CAREFUL * LOSS - EFFORT)                  # 全额保险：不管出不出事故，财富都一样
print(f"看得见行动时（全额保险 + 要求小心）：保费 {P_CAREFUL * LOSS:.2f}，期望效用 {first_best:.4f}")
naive = outcome(0)[2]
print(f"道德风险带来的损失：{first_best - best[3]:.4f}（效用单位）；如果不管道德风险、照样卖全额保险，损失是 {first_best - naive:.4f}")
```

![道德风险：激励和保障之间的取舍](/images/economics/21-deductible.svg)

逐段看：

- **d < 约 4.6**：不管怎么设，你都选**随意**，保费按 20% 的事故概率定，你的期望效用最高只有 2.8904。
- **d ≥ 约 4.6**：你有动力**小心**（再多自付一点，事故概率少 10 个百分点就值得），保费按 10% 定。最好的免赔额就在这个临界点，大约 4.6 万，期望效用 2.9145。
- **再往上加免赔额**，你依然小心，但保障越来越少，你承担的风险越来越大，期望效用反而一路降。
- **和"行动看得见"的对照**：如果保险公司看得到你小不小心，直接写"全额保险 + 你必须小心"，期望效用是 2.9178。道德风险带来的损失，是 2.9178 − 2.9145 = 0.0032；如果保险公司不管道德风险，照样卖全额保险，损失是 0.0274。**设计一个合适的免赔额，收回了大约 88% 的损失，不是全部。**

这是**激励和保险的取舍**，也是整个这一讲的核心问题：**保险的意义，是让人不用承担风险；激励的意义，是让人承担自己行动的后果。两者互相冲突。**

### 2.2 为什么不直接要求"小心"

你可能想：写进合同，"必须小心"不就行了？问题是**看不到、证明不了**。你有没有锁车、有没有放在安全的地方、有没有及时保养，保险公司很难知道，更没法在法庭上证明。所以合同只能围绕**可观察的东西**设计：事故是否发生、损失多少。免赔额、共同付费（出了事你付一定比例）、保费随记录调整（出险少的第二年保费更低）、除外条款，都是应对道德风险的办法。

### 2.3 医疗保险：自付比例该多高

医疗保险里，道德风险有一个很实在的版本：有了医保，病人和医生对**要不要做这项检查、用不用贵一点的药**，不那么在乎价格了。我国基本医疗保险，和很多国家的医保一样，设有起付标准（相当于免赔额）、报销比例和最高支付限额，具体数字各地不同。自付比例该多高，是一个有争议的问题。按"理论预测 → 证据与局限 → 分歧在哪 → 价值判断留给读者"来写。

**理论预测什么**：自付比例越高，病人用得越少，道德风险造成的"多用"减少；但自付比例也会让保障变少，让有价值的医疗也被放弃。

**证据怎么说**：

- **随机实验**：RAND 健康保险实验（1970 年代到 80 年代初，美国）把家庭随机分到不同的自付比例（从完全免费到自付 95%）。Manning 等人 1987 年（*American Economic Review*，77 卷 3 期）报告，自付越多，用得越少：自费价格弹性约 −0.2；"灾难性"计划（几乎全部自付，只在大额支出时保险）比免费计划的支出少约 31%；门诊使用量，在免费和自付 25% 之间下降最多。
- **一个雇主换了保险计划**：Brot-Goldberg、Chandra、Handel 和 Kolstad 2017 年（*Quarterly Journal of Economics*，132 卷 3 期）研究一家大雇主，把员工从免费计划换成高免赔额计划。据 NBER 摘要，总支出下降约 11.8% 到 13.8%，而且**完全是因为用得少**，不是员工学会了货比三家；被砍掉的，既有可能有价值的服务（比如预防），也有可能浪费的服务（比如影像检查）。
- **保障本身的价值**：Oregon 的医疗保险实验（Baicker 等人 2013 年，*New England Journal of Medicine*，368 卷 18 期）抽签决定谁有资格申请 Medicaid（美国针对低收入人群的公共医保）。大约两年后，得到保障的人，抑郁筛查阳性的比例下降约 9 个百分点；但是，血压、胆固醇等客观指标，没有统计上显著的改善（作者指出，研究只持续了约 17 个月，长期效果可能不同）。

**局限**：RAND 是几十年前的美国实验，现在的医疗和保险都变了；Brot-Goldberg 等人只研究一家雇主；Oregon 研究的是"有保险和没保险"的差别，不是自付比例本身。这些证据不能直接推到别的国家和体制。

**分歧在哪**：

- **事实上的分歧**：自付少一点，砍掉的是"多余"的医疗，还是"该做"的医疗？研究发现，价格上去的时候，人们（至少在这些样本里）**没有**很好地区分两者。
- **价值上的分歧**：下面三个问题，数据回答不了。

**价值判断（留给你）**：

1. 医疗，应该按"需要"来使用，还是可以按"付得起"来使用？自付比例的设置，其实是在回答这个问题。
2. 你愿意为了"保障"，接受多一点"多用"的浪费吗？
3. 这些浪费和保障的成本，应该由谁承担：病人本人、所有参保的人，还是财政？

经济学能告诉你的是：自付比例提高，会减少多少使用，被减少的是什么，保障又损失了多少。**该选哪一个点，是价值判断。**

> **小结：** 道德风险：合同之后的行动看不到，被保险人因为不用承担后果，变得不那么小心。应对办法是让对方承担一部分后果（免赔额、共付），代价是保障变少。最优的合同，在激励和保障之间取舍。医疗保险里自付比例该设多高，是事实和价值交织的争议。

## 三、委托—代理：怎么让一个你看不到努力的人，替你办事

### 3.1 回到销售员

第 2 讲讲过一个例子：销售员的提成按销售额算，他选了打折，公司却更希望不打折。我们说"他没有做错，他只是对你给他的激励做出了反应"，并说这类问题叫**委托—代理问题**，第 21 讲会系统讲。现在来讲。

- **委托人**（principal）：出钱、想要结果的人（公司）；
- **代理人**（agent）：替委托人做事的人（销售员、经理、医生、律师……）；
- **问题**：代理人的目标和委托人**不完全一致**，而且委托人**看不到**代理人的努力（道德风险）。

### 3.2 一个能算的模型

公司请销售员去谈一个单子。成功，公司收入 R；失败，收入 0。销售员的选择：

- **努力**：成功的概率 0.8，努力的"代价"折合 1 个效用单位；
- **不努力**：成功的概率 0.4，没有代价。

销售员的效用 = √工资 − 努力的代价（√ 表示他**怕风险**：工资翻倍，效用不翻倍）。他在别处能得到的效用是 3，相当于稳拿 9 的工资。公司**看得到成败，看不到他努不努力**。

合同只能写成：**成功给 w_g，失败给 w_b**。想让他努力，合同要满足两条：

1. **激励相容**：他自己愿意努力（努力的期望效用 ≥ 不努力的期望效用）；
2. **参与约束**：他愿意接这份工作（期望效用 ≥ 3）。

```python
from math import sqrt

# 公司（委托人）请销售员（代理人）去谈一个单子。成功（收入 R）或失败（收入 0）。
# 销售员努力：成功概率 0.8，努力的"代价"折合 1 个效用；不努力：成功概率 0.4，没有代价。
# 销售员的效用 = sqrt(工资) - 努力的代价；他在别处能得到的效用是 3（相当于稳拿 9 的工资）。公司看得见成败，看不见他努不努力。
P_HI, P_LO, COST, RESERVE = 0.8, 0.4, 1.0, 3.0

# 一、努力看不见：设计"成功拿 w_g，失败拿 w_b"。(IC) 他愿意努力；(IR) 他愿意接这份工作
#    IC: 0.8 v_g + 0.2 v_b - 1 >= 0.4 v_g + 0.6 v_b   =>  v_g - v_b >= 2.5     （v = sqrt(工资)）
#    IR: 0.8 v_g + 0.2 v_b - 1 >= 3
v_b = RESERVE + COST - P_HI * (COST / (P_HI - P_LO))       # 令两个约束都"刚好成立"
v_g = v_b + COST / (P_HI - P_LO)
w_b, w_g = v_b ** 2, v_g ** 2
pay_hi = P_HI * w_g + (1 - P_HI) * w_b
print(f"想让他努力：成功给 {w_g:.2f}，失败给 {w_b:.2f}，公司期望要付 {pay_hi:.2f}")

# 二、用网格暴力搜索，核对这就是"让他努力"的最便宜合同
best = None
steps = [i * 0.05 for i in range(0, 801)]                  # 工资从 0 到 40，每 0.05 一格
for wg in steps:
    for wb in steps:
        if wg < wb: continue
        eu_hi = P_HI * sqrt(wg) + (1 - P_HI) * sqrt(wb) - COST
        eu_lo = P_LO * sqrt(wg) + (1 - P_LO) * sqrt(wb)
        if eu_hi >= eu_lo - 1e-9 and eu_hi >= RESERVE - 1e-9:
            cost = P_HI * wg + (1 - P_HI) * wb
            if best is None or cost < best[0]: best = (cost, wg, wb)
print(f"网格搜索：最便宜的合同，成功 {best[1]:.2f}，失败 {best[2]:.2f}，期望支出 {best[0]:.2f}")

# 三、如果努力看得见：直接要求努力，固定工资就行（让他的效用刚好等于 3 + 努力代价 1）
pay_first = (RESERVE + COST) ** 2
print(f"努力看得见：固定工资 {pay_first:.2f}。看不见时多付的 {pay_hi - pay_first:.2f}，就是为了让他承担风险而付的补偿（代理成本）")
print(f"不要求努力（固定工资，他会偷懒）：要付 {RESERVE ** 2:.2f}，成功概率只有 {P_LO}")

# 四、值不值得让他努力？看成功时的收入 R
print("\n成功收入 R 多大，公司才愿意花 17 去换他努力？")
for R in (15, 20, 25, 50):
    hi = P_HI * R - pay_hi
    lo = P_LO * R - RESERVE ** 2
    print(f"  R={R}：让他努力，公司期望利润 {hi:6.2f}；不管他（固定工资 9），{lo:6.2f} -> {'让他努力' if hi > lo else ('一样' if abs(hi - lo) < 1e-9 else '不值得，宁可固定工资')}")

# 五、他越怕风险，代理成本越大（效用 = 工资 的 alpha 次方；alpha=1 是不怕风险）
print("\n他越怕风险，让他承担风险的补偿越大（努力的代价、保留效用都不变）：")
for alpha in (1.0, 0.7, 0.5, 0.3):
    vb = RESERVE + COST - P_HI * (COST / (P_HI - P_LO)); vg = vb + COST / (P_HI - P_LO)
    pay = P_HI * vg ** (1 / alpha) + (1 - P_HI) * vb ** (1 / alpha)
    first = (RESERVE + COST) ** (1 / alpha)
    print(f"  alpha={alpha}：看不见努力时公司多付 {pay - first:.2f}（努力看得见时要付 {first:.2f}）")
```

输出：

```text
想让他努力：成功给 20.25，失败给 4.00，公司期望要付 17.00
网格搜索：最便宜的合同，成功 20.25，失败 4.00，期望支出 17.00
努力看得见：固定工资 16.00。看不见时多付的 1.00，就是为了让他承担风险而付的补偿（代理成本）
不要求努力（固定工资，他会偷懒）：要付 9.00，成功概率只有 0.4

成功收入 R 多大，公司才愿意花 17 去换他努力？
  R=15：让他努力，公司期望利润  -5.00；不管他（固定工资 9）， -3.00 -> 不值得，宁可固定工资
  R=20：让他努力，公司期望利润  -1.00；不管他（固定工资 9）， -1.00 -> 一样
  R=25：让他努力，公司期望利润   3.00；不管他（固定工资 9），  1.00 -> 让他努力
  R=50：让他努力，公司期望利润  23.00；不管他（固定工资 9）， 11.00 -> 让他努力

他越怕风险，让他承担风险的补偿越大（努力的代价、保留效用都不变）：
  alpha=1.0：看不见努力时公司多付 0.00（努力看得见时要付 4.00）
  alpha=0.7：看不见努力时公司多付 0.15（努力看得见时要付 7.25）
  alpha=0.5：看不见努力时公司多付 1.00（努力看得见时要付 16.00）
  alpha=0.3：看不见努力时公司多付 20.78（努力看得见时要付 101.59）
```

逐段看：

- **合同长什么样**：成功拿 20.25，失败拿 4.00。**成功和失败的差距很大，这是在给他"努力的理由"。** 公司期望要付 17.00。网格搜索暴力验证，没有更便宜的合同能同时满足两条约束。
- **代理成本**：如果努力看得见，公司只要付一份固定工资，让他的效用刚好等于 3 加上努力的代价 1，也就是工资 16。看不见时，公司要多付 1.00。**这多付的 1.00，不是为了让他更努力，而是补偿他因为合同而承担的风险**（成功拿 20.25，失败只拿 4.00，他的收入不再稳定）。这叫**代理成本**。
- **值不值得激励**：成功收入 R 太小（比如 15），花 17 去换努力不值得，不如给他固定工资 9、让他偷懒。R = 20 时两者一样；R = 25 以上，值得激励。**并不是任何时候都值得激励。**
- **他越怕风险，代价越大**：不怕风险（α = 1）时，代理成本是 0（激励完全不需要补偿）；α = 0.5 时是 1.00；α = 0.3（非常怕风险）时是 20.78。

这里有一个深刻的结论：**激励是有成本的。** 要让人对自己的努力负责，就要让他的收入随结果波动，而结果里又掺着运气。把风险转嫁给他，他要钱来补偿。**激励（让他承担后果）和保险（让他免于风险）又一次互相冲突。** 这和 2.1 节的免赔额，是同一个取舍。

### 3.3 三个延伸

- **信息量原则**：Bengt Holmström 1979 年（*Bell Journal of Economics*）的结果之一是：只要某个信号，能提供关于代理人行动的信息，就应该把它用进合同。比如，评价一个经理，可以不只看他公司的业绩，还看同行业其他公司的业绩（扣掉行业整体的运气，剩下的更反映他的作为）。
- **多任务**：真实的工作往往有好几项任务，有的容易度量，有的难度量。Holmström 和 Milgrom 1991 年（*Journal of Law, Economics, and Organization*，7 卷）指出：如果你对容易度量的那项给很强的激励，代理人就会把精力从难度量的那项上移开。**第 2 讲思考题里"按代码行数给程序员发奖金"，就是这样：行数好度量，软件好不好用难度量；奖励前者，他就把一行拆成多行。** 这也解释了为什么很多工作，实际上是固定工资加弱激励。
- **激励有时反而坏事**：Gneezy 和 Rustichini 2000 年（*Journal of Legal Studies*，29 卷 1 期）在以色列的日托中心做了一个有名的实验：家长迟到接孩子，老师要多待。中心开始对迟到的家长**罚款**之后，迟到反而**增加**了，取消罚款之后，也没有减少。他们的解释是：罚款把"迟到给老师添麻烦"这件有道德分量的事，变成了一个**价格**，家长觉得"付了钱就心安理得"。**激励不总是按照经济模型里的方向起作用，特别是当它改变了人们对这件事的看法时。** （这是一个被反复引用的实验，但它只在少数日托中心做过，这里只用来说明一种可能性，不是说罚款总会适得其反。）

### 3.4 证据：计件工资到底有没有用

Edward Lazear 2000 年（*American Economic Review*，90 卷 5 期）研究了 Safelite Glass（一家安装汽车玻璃的美国公司）。公司把工人从**固定的小时工资**，改成**按件计酬**。结果：每个工人的产出，增加了约 44%；据 Lazear 后来的归纳，大约一半来自现有工人更努力，另一半来自**更高效的工人被吸引进来、效率低的离开**（也就是"选择"，下一节会讲）。

**局限**：有研究者（一篇 McGill 大学的工作论文）指出，这次改革同时有最低工资保证，而且工人的平均工资也上升了约 10.6%，所以，效果有多少来自"计件"本身，有多少来自"工资涨了"，不容易分开。这是单一公司的案例，不能直接推到所有行业。

> **小结：** 委托—代理：委托人看不到代理人的努力，要靠"结果好奖励多"的合同来激励。激励要代理人承担风险，风险要补偿，这就是代理成本；越怕风险，成本越大；不是任何时候都值得激励。多任务、度量的缺陷、激励改变人们的想法，都会让激励偏离设计者的本意。

## 四、效率工资：为什么故意付高工资

### 4.1 另一种激励：丢掉这份工作的代价

激励不一定要靠"成功多给钱"。还有一种办法：**让他丢掉这份工作变得很可惜。**

第 13 讲提过：有的企业**故意**付高于市场的工资，来换更少的离职和更多的努力，叫**效率工资**（Shapiro 和 Stiglitz 1984 年，*American Economic Review*，74 卷 3 期）。道理：老板看不到每个工人是不是在偷懒，但每一期有一定概率抓到；抓到就解雇。如果工资和别处一样，被解雇不过是换份工作，没什么损失，那么偷懒不用付代价。**只有工资高于外面，丢了这份工作才有损失，他才不敢偷懒。**

这和第 19 讲的冷酷触发是同一个结构：**今天偷懒的好处，对比"以后丢掉高薪"的代价。**

### 4.2 算一下

工人每期选择"干活"（花 10 的力气）或"偷懒"（省下这 10）；每期以概率 q 抓到偷懒的人并解雇；被解雇后只有失业时的收入 20。折现因子 0.9。

```python
# 效率工资：工人每期选"干活"（花 10 的力气）或"偷懒"（省下这 10）。老板每期以概率 q 抓到偷懒的人并解雇；
# 被解雇后，每期只有失业时的收入 W0 = 20。折现因子 delta = 0.9（和第 19 讲同一个意思：下一期还在的价值）。
E, W0, DELTA = 10.0, 20.0, 0.9

def prefers_work(w, q):
    """价值迭代：在职时每期选"干活"或"偷懒"，哪个终身价值高就选哪个。返回（是否干活，在职价值）"""
    v_u = W0 / (1 - DELTA)                                   # 失业：每期 W0，一直如此
    v_e = 0.0
    for _ in range(5000):
        work = (w - E) + DELTA * v_e
        shirk = w + DELTA * ((1 - q) * v_e + q * v_u)
        v_new = max(work, shirk)
        if abs(v_new - v_e) < 1e-10: break
        v_e = v_new
    return work >= shirk, v_e

q = 0.25
need = E + E * (1 - DELTA) / (DELTA * q)                     # 解析结果：w - W0 >= E + E(1-delta)/(delta q)
print(f"抓到的概率 q={q}：工资要比失业收入高至少 {need:.2f}（{E:.0f} 补偿力气，{need - E:.2f} 是'不敢偷懒'的溢价）")
for premium in (12, 14, 14.4, 14.5, 15, 18):
    ok, v = prefers_work(W0 + premium, q)
    print(f"  工资比失业收入高 {premium}：{'干活' if ok else '偷懒'}")

print("\n监督越松（q 越小），要多付的'不敢偷懒的溢价'越大：")
for q in (1.0, 0.5, 0.25, 0.1, 0.05):
    rent = E * (1 - DELTA) / (DELTA * q)
    ok_above, _ = prefers_work(W0 + E + rent + 0.05, q)
    ok_below, _ = prefers_work(W0 + E + rent - 0.05, q)
    print(f"  q={q}：溢价 {rent:.2f}，工资 {W0 + E + rent:.2f}（比溢价多 0.05 时{'干活' if ok_above else '偷懒'}，少 0.05 时{'干活' if ok_below else '偷懒'}）")
```

输出：

```text
抓到的概率 q=0.25：工资要比失业收入高至少 14.44（10 补偿力气，4.44 是'不敢偷懒'的溢价）
  工资比失业收入高 12：偷懒
  工资比失业收入高 14：偷懒
  工资比失业收入高 14.4：偷懒
  工资比失业收入高 14.5：干活
  工资比失业收入高 15：干活
  工资比失业收入高 18：干活

监督越松（q 越小），要多付的'不敢偷懒的溢价'越大：
  q=1.0：溢价 1.11，工资 31.11（比溢价多 0.05 时干活，少 0.05 时偷懒）
  q=0.5：溢价 2.22，工资 32.22（比溢价多 0.05 时干活，少 0.05 时偷懒）
  q=0.25：溢价 4.44，工资 34.44（比溢价多 0.05 时干活，少 0.05 时偷懒）
  q=0.1：溢价 11.11，工资 41.11（比溢价多 0.05 时干活，少 0.05 时偷懒）
  q=0.05：溢价 22.22，工资 52.22（比溢价多 0.05 时干活，少 0.05 时偷懒）
```

![监督越松，工资溢价越高](/images/economics/21-effwage.svg)

- **门槛**：q = 0.25 时，工资要比失业收入至少高 14.44：10 是补偿他的力气，**另外 4.44 是"不敢偷懒的溢价"**。价值迭代的结果（工人每期自己选）和公式一致：高 14.4 偷懒，高 14.5 干活。
- **监督越松，溢价越高**：q = 1（每次偷懒都被抓）只要 1.11；q = 0.1 要 11.11；q = 0.05 要 22.22。**抓得越少，要用越高的工资来补。** 公式是：溢价 = 力气 × (1 − δ) ÷ (δ × q)。
- **监督和工资，是互相替代的**：企业可以花钱监督（提高 q），也可以付高工资（提高丢工作的代价）。

Shapiro 和 Stiglitz 的一个重要想法是：如果**所有**企业都这样做，工资普遍升高，劳动力需求会下降，出现**失业**；而失业本身，又让"被解雇"更可怕，成了管住工人的"纪律"。也就是说，**即使没有任何工资刚性，均衡里也可能有"非自愿失业"。** 这给第 13 讲讲的工资"黏住"，提供了一种不靠合同的解释。

### 4.3 证据与局限

Peter Cappelli 和 Keith Chauvin 1991 年（*Quarterly Journal of Economics*，106 卷 3 期）比较了同一家企业的**不同工厂**：工资比当地高出越多的工厂，因违纪而被解雇的人越少；当地越难找到别的工作，违纪越少。这和效率工资的预测吻合。**不过**，作者自己也怀疑，溢价省下的违纪成本，是否真的超过了多付的工资；而且，效率工资的前提（工资高→努力多）本身，"测得不多"。

还有别的解释：高工资也许只是在招更好的人（选择）、或者员工觉得受到公平对待、回报以努力（"礼物交换"）。**效率工资是一种解释，不是唯一的解释。**

> **小结：** 效率工资：看不到努力时，企业可以故意付高于市场的工资，让丢掉这份工作变得很可惜。监督越松，溢价越高；和第 19 讲的惩罚威胁是同一个结构。证据方向一致，但解释不唯一。

## 五、信号：怎么让对方相信你

### 5.1 会说话的行动

第 20 讲说过，质保是一种"信号"。现在系统讲。

**信号**（signal）：有信息的一方，主动做一件**有成本**的事，让没有信息的一方，从这件事推断出自己的类型。

最有名的例子，是教育。Michael Spence 1973 年（*Quarterly Journal of Economics*，87 卷 3 期）的《就业市场信号》：

- 一半工人是**高能力**（产出 2），一半是**低能力**（产出 1）。雇主看不出，只能看到**读了几年书**；
- **教育本身，不提高产出**（先假设是这样，纯粹的信号）；
- 但读书的**代价因人而异**：高能力的人读书更轻松（每年的代价 0.2），低能力的人更吃力（每年 0.5）。

雇主的规则："读够 e\* 年，就当高能力付 2；否则当低能力付 1。"

问题是：e\* 设在哪里，这个规则才**稳**，即高能力的人愿意读，低能力的人不会"装"？

```python
# 教育当信号：一半工人高能力（产出 2），一半低能力（产出 1）；企业看不出，只看得见"读了几年书"。
# 假设教育本身不提高产出（纯信号）；但读书的"代价"因人而异：高能力每年 c_H，低能力每年 c_L。
# 企业的规则：读够 e* 年，就当高能力付 2；否则当低能力付 1。
def separating(e_star, c_h, c_l):
    low_mimic = (2 - c_l * e_star) > 1                       # 低能力者装高能力（也读 e* 年），是否更划算？
    high_gets = (2 - c_h * e_star) >= 1                      # 高能力者读 e* 年，是否比不读（当低能力）更好？
    return (not low_mimic) and high_gets, low_mimic, high_gets

c_h, c_l = 0.2, 0.5
print(f"读书代价：高能力每年 {c_h}，低能力每年 {c_l}。企业规则：读够 e* 年付 2，否则付 1")
print(f"  低能力者不装：1 <= {c_l} e*，即 e* >= {1 / c_l:.1f}；高能力者愿读：1 >= {c_h} e*，即 e* <= {1 / c_h:.1f}")
for e in (1, 1.5, 2, 3, 4, 5, 6):
    ok, mimic, high = separating(e, c_h, c_l)
    why = "能分开" if ok else ("低能力者也会装" if mimic else "高能力者嫌太贵")
    print(f"  e*={e}：{why}")

e = 2.0
h_net, l_net = 2 - c_h * e, 1.0
print(f"\ne*={e} 时：高能力净得 {h_net:.2f}，低能力 {l_net:.2f}；如果谁都不读书，企业只能按平均付 1.5，两类人各得 1.5")
print(f"  人均净产出（产出 - 读书的代价）：分开 {0.5 * h_net + 0.5 * l_net:.2f}，谁都不读 {1.5:.2f}；教育本身没提高产出，这 {1.5 - (0.5 * h_net + 0.5 * l_net):.2f} 是白花的")

c_h2 = c_l2 = 0.35
print(f"\n如果读书的代价对谁都一样（每年 {c_h2}）：")
for e in (2, 2.5, 2.85, 2.9, 3, 4):
    ok, mimic, high = separating(e, c_h2, c_l2)
    why = "能分开" if ok else ("低能力者也会装" if mimic else "高能力者嫌太贵")
    print(f"  e*={e}：{why}")
```

输出：

```text
读书代价：高能力每年 0.2，低能力每年 0.5。企业规则：读够 e* 年付 2，否则付 1
  低能力者不装：1 <= 0.5 e*，即 e* >= 2.0；高能力者愿读：1 >= 0.2 e*，即 e* <= 5.0
  e*=1：低能力者也会装
  e*=1.5：低能力者也会装
  e*=2：能分开
  e*=3：能分开
  e*=4：能分开
  e*=5：能分开
  e*=6：高能力者嫌太贵

e*=2.0 时：高能力净得 1.60，低能力 1.00；如果谁都不读书，企业只能按平均付 1.5，两类人各得 1.5
  人均净产出（产出 - 读书的代价）：分开 1.30，谁都不读 1.50；教育本身没提高产出，这 0.20 是白花的

如果读书的代价对谁都一样（每年 0.35）：
  e*=2：低能力者也会装
  e*=2.5：低能力者也会装
  e*=2.85：低能力者也会装
  e*=2.9：高能力者嫌太贵
  e*=3：高能力者嫌太贵
  e*=4：高能力者嫌太贵
```

![信号：代价因人而异，读书才能当信号](/images/economics/21-signal.svg)

- **门槛是一个范围**：低能力的人**不装**，要求读书的代价大于工资差，即 0.5 × e\* ≥ 1，e\* ≥ 2；高能力的人**愿意读**，要求 0.2 × e\* ≤ 1，e\* ≤ 5。**e\* 在 2 到 5 年之间，规则都稳**：又是第 18 讲遇到过的**多重均衡**。哪个会出现，要看惯例和预期。
- **关键是代价因人而异**：如果读书的代价对谁都一样（每年 0.35），没有任何一个 e\*，能同时让低能力的人不装、高能力的人愿读（2.857 年是刚好无差别的临界点，只在那一点上）。**信号要有用，必须是"好人做起来比坏人便宜"的事。** 这就是为什么廉价的话（"我是好人"）不能当信号（第 18 讲讲过"廉价的话"），而长质保能（第 20 讲）：车况好的人，给质保的成本低。
- **信号可能是社会性的浪费**：e\* = 2 时，高能力者净得 1.60（比谁都不读的 1.5 更好），低能力者得 1.00（比 1.5 更差）；人均净产出，分开是 1.30，谁都不读是 1.50：**教育没有提高产出，这 0.20 是白花的。** 信号让高能力者"证明了自己"，却是以资源浪费为代价。（如果有了信息，雇主可以把人安排到更合适的岗位，产出会更高，那么，信号也可能是净好处，取决于信息有多大用处。）

### 5.2 教育，是人力资本还是信号

这是劳动经济学里争论多年的问题，第 13 讲留了伏笔。按四步写。

**理论预测什么**：

- **人力资本观点**：教育教会了你技能，让你更有生产率，所以工资更高。
- **信号（筛选）观点**：教育多半没有提高你的生产率，只是证明了你本来就更有能力、更能坚持。

两种观点都预测"受教育多的人工资更高"，所以，光看这个，分不出来。

**证据怎么说**：要找两种观点预测**不一样**的地方。

- **"文凭效应"**（sheepskin effect）：如果教育只是在教技能，那么第 16 年和第 15 年的差别，应该和第 15 年与第 14 年的差别差不多；如果文凭是信号，拿到学位的那一年，工资应该有一个**跳升**。David Jaeger 和 Marianne Page 1996 年（*Review of Economics and Statistics*，78 卷 4 期）用美国的调查数据发现，按实际拿到的学位来估计，文凭效应，比只按受教育年数估计时更大。
- **义务教育法**：Kevin Lang 和 David Kropp 1986 年（*Quarterly Journal of Economics*，101 卷 3 期）发现，美国各州提高义务教育年限的法律，让**法律管不到的**年龄段的入学率，也上升了。这和"信号"的预测一致（别人多读了，你不读就显得差了），不好用"只是学技能"解释。
- **拿到毕业证，本身值不值钱**：Damon Clark 和 Paco Martorell 2014 年（*Journal of Political Economy*，122 卷 2 期）用得克萨斯州和佛罗里达州的数据，比较"刚好通过高中毕业考试、拿到毕业证"和"刚好没通过、没拿到"的人，发现两者的收入**差别很小**：毕业证本身的信号价值不大（据他们工作论文版本，可以排除超过 5% 到 6% 的信号价值）。

**局限**：这三项研究，测的是不同的东西，而且每一项都有别的解释：文凭效应也可能是因为"读完学位"本身反映了技能；义务教育法也可能带来别的变化；Clark 和 Martorell 比较的是**高中毕业证**，大学学位的情形未必一样。

**分歧在哪**：多数研究者认为，**两者都有**，问题是各占多少。这个比例，因国家、因专业、因学历层次而不同，没有一个公认的数字。

**价值判断（留给你）**：如果相当一部分教育，是在做"筛选"，那么：

- 社会该不该大量投入公共资源，去支持一个有"筛选"成分的教育？
- 招聘时，把学历设成门槛，是公平的筛选，还是对出身不同的人的不公平？
- 如果别人都读到某个年限，你不读就显得更差：这算不算一种"囚徒困境"（第 18 讲）？

经济学可以帮你把这些问题的**代价和证据**讲清楚，但不替你回答。

> **小结：** 信号：有信息的一方，用一个有成本的行动证明类型。条件是：好人做起来比坏人便宜。信号可以分开不同的人，但可能是社会性的浪费；规则往往有很多个都稳（多重均衡）。教育是人力资本还是信号，证据表明两者都有，各占多少，没有定论。

## 六、筛选：设计选项，让对方自己说出真相

### 6.1 没有信息的一方先出手

信号是**有信息**的一方先出手。**筛选**（screening）反过来：**没有信息的一方**，设计一组选项，让不同类型的人，**自己选**给自己设计的那一份。

第 15 讲的航空公司，就是筛选。我们用第 15 讲的数字，把它算清楚：休闲旅客、商务旅客各 100 人。成本：经济舱 100，商务舱 200。愿付价：休闲旅客，经济舱 250、商务舱 300；商务旅客，经济舱 300、商务舱 550。航空公司**看不出谁是谁**。

```python
# 第 15 讲的航空公司：休闲旅客、商务旅客各 100 人。成本：经济舱 100，商务舱 200。
# 愿付价：休闲旅客 经济舱 250 / 商务舱 300；商务旅客 经济舱 300 / 商务舱 550。公司看不出谁是谁，只能设计"菜单"（经济舱价、商务舱价），让旅客自己选。
COST = {"经": 100, "商": 200}
VALUE = {"休闲": {"经": 250, "商": 300}, "商务": {"经": 300, "商": 550}}
N = 100

def choice(kind, p_eco, p_biz):
    """旅客在"经济舱 / 商务舱 / 不买"里选净好处最大的；好处一样时，选对公司更有利的（利润高的）"""
    opts = [("不买", 0, 0), ("经", VALUE[kind]["经"] - p_eco, p_eco - COST["经"]), ("商", VALUE[kind]["商"] - p_biz, p_biz - COST["商"])]
    return max(opts, key=lambda o: (o[1], o[2]))

best = None
for p_eco in range(0, 601, 5):
    for p_biz in range(0, 601, 5):
        profit = sum(choice(k, p_eco, p_biz)[2] * N for k in ("休闲", "商务"))
        if best is None or profit > best[0]: best = (profit, p_eco, p_biz)
profit, p_eco, p_biz = best
print(f"最好的菜单：经济舱 {p_eco}，商务舱 {p_biz}，利润 {profit}")
for k in ("休闲", "商务"):
    c = choice(k, p_eco, p_biz)
    print(f"  {k}旅客：选{c[0]}，净好处 {c[1]}，给公司的利润（每人）{c[2]}")

# 约束检查：参与（愿意来买）和激励相容（自愿选给自己设计的那份）
biz_biz = VALUE["商务"]["商"] - p_biz; biz_eco = VALUE["商务"]["经"] - p_eco
leis_eco = VALUE["休闲"]["经"] - p_eco
print(f"\n商务旅客：选商务舱得 {biz_biz}，假装休闲、买经济舱得 {biz_eco}，{'前者不比后者差，激励相容成立' if biz_biz >= biz_eco else '不成立'}")
print(f"休闲旅客：买经济舱得 {leis_eco}（>= 0，愿意来）")

# 对照：看得出谁是谁时；只卖一个价时
full = (250 - COST["经"]) * N + (550 - COST["商"]) * N
only_biz = max((pb - COST["商"]) * N for pb in range(0, 601, 5) if choice("商务", 10 ** 6, pb)[0] == "商" and choice("休闲", 10 ** 6, pb)[0] == "不买")
print(f"\n看得出谁是谁（各收到他们的最高愿付价）：利润 {full}；只卖商务舱、不卖经济舱：{only_biz}；菜单：{profit}")
print(f"商务旅客拿到的'信息租金'：{biz_biz} × {N} = {biz_biz * N}（公司看不出谁是谁，让出去的）")
```

输出：

```text
最好的菜单：经济舱 250，商务舱 500，利润 45000
  休闲旅客：选经，净好处 0，给公司的利润（每人）150
  商务旅客：选商，净好处 50，给公司的利润（每人）300

商务旅客：选商务舱得 50，假装休闲、买经济舱得 50，前者不比后者差，激励相容成立
休闲旅客：买经济舱得 0（>= 0，愿意来）

看得出谁是谁（各收到他们的最高愿付价）：利润 50000；只卖商务舱、不卖经济舱：35000；菜单：45000
商务旅客拿到的'信息租金'：50 × 100 = 5000（公司看不出谁是谁，让出去的）
```

- **最好的菜单**：经济舱 250，商务舱 500，利润 45000；休闲旅客买经济舱，商务旅客买商务舱。
- **两个约束**，是机制设计里最基本的两个：
  - **参与约束**：每类人愿意来买。休闲旅客买经济舱，净好处 0（≥ 0，愿意来）。
  - **激励相容**（incentive compatibility）：每类人，自愿选**给自己设计的那份**，而不是假装另一类。商务旅客选商务舱得 50，假装休闲、买经济舱得 300 − 250 = 50，**前者不比后者差**，所以他不会"降级"。
- **为什么商务舱定在 500，不是 550**：如果定 550，商务旅客买商务舱净好处是 0，而买经济舱是 50，他就会买经济舱。**为了让他愿意买商务舱，公司必须让他得到至少 50 的好处**，这 50 就是他"假装休闲能得到的东西"。
- **信息租金**：商务旅客拿到的 50 × 100 = 5000，是公司因为**看不出谁是谁**而让出去的。公司看得出谁是谁时，可以向商务舱收 550，向休闲旅客收 250，利润 50000；菜单是 45000，**差的 5000，就是信息不对称的代价**。只卖商务舱、不卖经济舱，利润是 35000。

这是一个一般的规律：**让有私人信息的人"说真话"，要给他"信息租金"。** 第 22 讲的机制设计，会把这个想法推广到一般情形。

### 6.2 其他的筛选

- **保险的菜单**：同时提供"保费高、免赔低"和"保费低、免赔高"两份保险。风险高的人，更愿意选前者（出事故的概率高，不想自己付）；风险低的人，选后者（不怕自己付）。Michael Rothschild 和 Joseph Stiglitz 1976 年（*Quarterly Journal of Economics*，90 卷 4 期）指出，在竞争的保险市场里，风险低的人往往只能买到不完全的保险（以免被风险高的人"冒充"），而且在一定条件下，**这样的均衡可能根本不存在**。
- **试用期**：企业不知道新员工的能力，让他先干一段时间，用实际表现来观察。我国《劳动合同法》第十九条规定了试用期的上限（劳动合同期限三年以上或无固定期限的，不得超过六个月），并规定同一用人单位和同一劳动者只能约定一次试用期。
- **免费试用与付费版**（第 15 讲）：对产品估值高的人，选付费版；估值低的人，用免费版。

### 6.3 信号和筛选：对照

| | 信号 | 筛选 |
|---|------|------|
| 谁先出手 | **有信息**的一方 | **没有信息**的一方 |
| 做什么 | 做一件有成本的事，证明自己 | 设计一组选项，让对方自选 |
| 例子 | 教育、质保、品牌广告 | 航空公司的舱位菜单、保险的免赔额菜单、试用期 |
| 关键条件 | 好人做起来比坏人便宜 | 激励相容 + 参与约束 |
| 代价 | 信号本身的资源浪费 | 给对方的信息租金 |

## 七、回到规制：成本加成，还是固定价格

第 14 讲讲自然垄断时，我说过：监管者要知道企业的成本，但成本信息在企业手里，企业有理由夸大成本。这就是信息不对称：**监管者（委托人）看不到企业（代理人）的成本和努力。** 两种极端的办法：

- **成本加成**（成本多少，就按成本加一个合理利润）：企业没有动力降成本（降了反而少收），但它不需要从监管者那里隐藏什么。
- **固定价格**（规定一个价格，成本是多少你自己看着办）：企业有强烈的动力降成本（省下的都是自己的），但如果价格定得太低，企业会亏，太高，企业赚走大笔租金。

这和 3.2 节的合同，是同一个取舍：**激励（企业为成本负责）和租金（企业赚多少，监管者没法知道）。** 现实里，往往是两者之间的某种折中（成本部分分摊）。把这个想法一般化，就是机制设计，下一讲就是它的开头。

## 八、局限、常见误用

### 8.1 这些模型的局限

- **行动和类型不是截然分开的。** 现实里，逆向选择和道德风险往往同时存在，实证上很难分开（比如，买了更多保险的人风险更高，是因为本来就是高风险的人，还是因为买了保险才变得不小心？）。
- **合同往往不完全。** 模型里，合同可以精确地写，法庭能执行；现实里，很多东西没法写进合同，需要信任、声誉和惯例（第 19 讲）。
- **人不只被金钱激励。** 内在动机、公平感、对"这是什么性质的事"的判断，会改变激励的效果（Gneezy 和 Rustichini 的实验）。
- **度量本身就是问题。** 能度量的，不一定是想要的（行数 vs 好用的软件）。
- **信号和筛选的模型，假设对方理性、规则清楚。** 现实里，规则可能有很多个，大家选哪个，靠惯例。

### 8.2 常见的误用

| 误用 | 正确的想法 |
|------|-----------|
| "道德风险就是人品不好" | 不是品德问题：合同后行动看不到、不承担后果时，对激励做出反应 |
| "加大激励，员工就会更努力" | 激励要让员工承担风险，需要补偿；而且可能改变他对这件事的看法，甚至适得其反 |
| "按能度量的指标发奖金" | 能度量的不等于想要的；多任务下，会把精力从难度量的事上移开 |
| "高工资就是浪费" | 效率工资：高工资可以替代监督，换来更少的偷懒和离职；但不是总划算 |
| "教育就是学技能" 或 "教育就是信号" | 两者都有，各占多少没有定论，因情形而异 |
| "有学历的人更有能力，所以学历门槛合理" | 学历是信号，有成本（也是一种浪费），而且对不同出身的人，获得学历的成本差别很大，会引出公平问题 |
| "筛选就是歧视" | 不同的菜单，让人自己选；但也要看设计是否让某些人被迫选了不利的一份 |
| "保险公司不该设免赔额" | 免赔额在对付道德风险，没有它，保费会更高（保障更全，激励更差） |

## 九、小结

这一讲有六个想法，请带走：

1. **道德风险**：合同之后的行动看不到，保险让人不再承担后果，变得不那么小心。应对办法是让他承担一部分后果（免赔额、共付）。**激励和保障互相冲突。**
2. **委托—代理**：委托人看不到努力，要靠"结果好奖励多"的合同。激励让代理人承担风险，要补偿，这就是代理成本；越怕风险，代价越大；不是任何时候都值得激励。度量不全、多任务和激励改变想法，会让激励偏离本意。
3. **效率工资**：企业可以故意付高工资，让丢掉工作变得可惜；监督越松，溢价越高；和第 19 讲同一个结构。
4. **信号**：有信息的一方，用有成本的行动证明类型；条件是"好人做起来比坏人便宜"。信号会分开人，但可能是社会性的浪费；教育是人力资本还是信号，证据表明两者都有。
5. **筛选**：没有信息的一方设计选项，让人自选。关键是参与约束和激励相容；让有私人信息的人说真话，要给他信息租金（航空公司的 5000）。
6. **取舍**：这一讲所有的问题，都是同一个取舍：**让人承担后果（激励），和让人免于风险（保险）**；监管里，则是**激励和租金**。

到这里，Unit 5 已经走了大半。我们从博弈，到重复博弈，再到信息不对称，一直在问同一件事：**当人们的目标不同、知道的不同，怎么设计规则，让个人的选择，导向好的结果？** 这个问题有一个名字：**机制设计**。**第 22 讲：拍卖与机制设计**，我们会看一个机制设计里最成功的例子：拍卖。你会看到，同样是卖一件东西，规则不同，大家的出价会很不一样，卖家的收入却可能一样；也会看到上一讲提到的"赢者诅咒"。

## 思考题

**1.** 2.1 节的保险，如果用最简单的方式，不考虑怕风险，只看期望的钱：事故概率 10%（小心）和 20%（随意），小心的代价 0.5 万。让你愿意小心，免赔额至少要多大？代码里算出来的是 4.6，为什么比你算出来的小一点？

> 提示：不考虑怕风险：小心的期望总成本 = 事故概率 10% × d + 0.5；随意的期望自付 = 20% × d。令两者相等：0.1d + 0.5 = 0.2d，d = **5**。代码是 4.6，比 5 小一点，因为对数效用代表你**怕风险**：出事故的状态下财富更低，这个状态的"边际效用"更高，所以同样少 10 个百分点的事故概率，对你更值钱，不用到 5 就愿意小心。

**2.** 3.2 节的销售员，如果努力的代价从 1 提高到 2（其他不变），让他努力的合同是什么？代理成本是多少？成功收入 R 至少多大，公司才愿意激励他？

> 提示：努力的代价 2：v_g − v_b = 2 ÷ 0.4 = 5；参与约束 0.8v_g + 0.2v_b = 3 + 2 = 5，解得 v_b = 1，v_g = 6；工资 w_b = 1，w_g = 36，期望支出 0.8 × 36 + 0.2 × 1 = **29.0**。努力看得见时，固定工资是 (3 + 2)² = 25，**代理成本 = 29 − 25 = 4.0**。公司愿意激励的条件：0.8R − 29 ≥ 0.4R − 9（不管他，固定工资 9），即 R ≥ **50**。努力的代价越高，要付的越多，值得激励的门槛越高。

**3.** 4.2 节的效率工资：如果每期抓到偷懒者的概率是 q = 0.5，折现因子是 0.8，其他不变（力气 10），要多付的"不敢偷懒的溢价"是多少？

> 提示：溢价 = 力气 × (1 − δ) ÷ (δ × q) = 10 × 0.2 ÷ (0.8 × 0.5) = **5.0**（力气 10 另外补偿，所以工资要比失业收入至少高 15）。对比：δ = 0.9、q = 0.5 时溢价是 2.22。**δ 越小，溢价越大**：越不看重以后，丢掉工作的威胁越没分量，要用更高的工资来补；q 越大（抓得越勤），溢价越小。

**4.** 5.1 节的教育信号：如果高能力的人每年读书的代价是 0.25，低能力的人是 0.4，工资差是 1。e\* 的范围是多少？如果工资差变成 1.5 呢？

> 提示：低能力者不装：0.4 × e\* ≥ 1，e\* ≥ **2.5**；高能力者愿读：0.25 × e\* ≤ 1，e\* ≤ **4**。范围是 2.5 到 4 年。工资差变成 1.5：e\* ≥ 1.5 ÷ 0.4 = **3.75**，e\* ≤ 1.5 ÷ 0.25 = **6**，范围是 3.75 到 6 年。工资差越大，需要的门槛越高：好处越大，低能力者越愿意"装"，所以要把门槛抬高才拦得住。

**5.** 6.1 节的航空公司：如果商务旅客对商务舱的愿付价从 550 提高到 600（其他不变），最好的菜单是什么？公司给商务旅客的信息租金变了吗？为什么？

> 提示：最好的菜单：经济舱 **250**，商务舱 **550**，利润 50000（看得出谁是谁时是 55000）。商务旅客选商务舱得 600 − 550 = 50，假装休闲、买经济舱得 300 − 250 = 50，激励相容刚好成立。**信息租金没变，仍是 50 × 100 = 5000**：因为租金，是由"假装的那一份能得到的好处"（经济舱 300 − 250 = 50）决定的，不是由商务舱的愿付价决定的。商务舱愿付价升高，公司的利润多了 5000（550 比 500 高出的 50 × 100），租金不变。
