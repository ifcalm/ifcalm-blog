"六个确认就安全了"——**你**大概听过这句话。这个实验让你把它跑出来：**六个确认到底对应多小的概率，而攻击者算力占比变化时它怎么动。**

### 打个比方

这像**称一称"差不多"到底有多重**。

PoW 的安全性是概率性的，日常说法里它被压缩成了"等几个块就行"。跑一遍之后你会看到那条曲线的形状——**它在某个算力占比之前掉得飞快，之后就再也掉不下去了。**

⚠️ **一个容易让人得出错误结论的坑**：模拟次数太少时，曲线会看起来"很安全"。

你要测的是**小概率事件**，而小概率事件在几百次模拟里可能一次都不出现——于是你会得到一条漂亮但错误的曲线。**跑不够次数时，得到的不是"噪声大一点的答案"，是"系统性偏乐观的答案"。** 这本身就是这个实验想让你记住的一件事。

对应[第 15–19 讲]({{< ref "15-proof-of-work.md" >}})。

**这个实验分两部分，它们的目的正好相反**：第一部分让你看到 PoW 的**概率性质**，第二部分让你看到 BFT 的**确定性边界**。

```

⭐ **然后回答：**

```

### 任务 1.4：自私挖矿模拟

**实现[第 16 讲第五节]({{< ref "16-longest-chain-forks.md" >}})的策略：**

```go
// SelfishMining 返回攻击者获得的【收益份额】。
// alpha: 攻击者算力占比
// gamma: 平局时跟随攻击者区块的诚实算力比例
func SelfishMining(alpha, gamma float64, blocks int) float64
```

**状态机（`state` = 私链领先的区块数）：**

```
攻击者挖到块（概率 α）：  state++

诚实方挖到块（概率 1−α）：
    state == 0 ⟹ 诚实方的块直接成为主链
    state == 1 ⟹ ⭐ 攻击者【立即发布】，形成竞争
                   以概率 γ 攻击者赢，1−γ 诚实方赢
    state == 2 ⟹ 攻击者发布两个块，诚实方那个作废
    state >  2 ⟹ 攻击者发布一个块盖过去，state−−
```

**扫描 α 从 0.10 到 0.45，找出"收益份额 > 算力份额"的临界点：**

```
                γ=0      γ=0.5     γ=1
理论阈值        33.3%     25%       →0
你的模拟结果      ?         ?         ?
```

**亲眼看到 α = 0.26、γ = 0.5 时收益份额确实超过 0.26，比读十遍公式有说服力得多。**

## 常见错误

```
① 用 math/rand 的固定种子 ⟹ 每次结果相同，看不出分布
② ⭐ 自私挖矿状态机漏掉 state = 2 的特殊处理（"一次发布两个块"）
③ PBFT 里统计"收到 2f+1 条消息"而不是"来自 2f+1 个【不同节点】"
   ⟹ 一个作恶节点重复发送就能凑数
④ 忘记按 (view, sequence, digest) 三元组区分消息 ⟹ 跨轮次串味
```
