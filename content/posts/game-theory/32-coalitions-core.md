## 一、一笔要分的钱

你、同事小周和小林，一起接了一个项目。

- 三个人合作做完，项目能赚 **100**。
- 如果只有**两个人**做（缺一个人，只能做一部分），能赚 **60**。
- 一个人**单干**，什么也赚不到：**0**。

三个人合作，100 比任何两个人的 60 都多，所以大家都想一起做。现在问题是：**这 100 怎么分？**

你的第一反应也许是**平分**，每人 33.3。那我们换一个分法：**(50, 30, 20)**，你得 50，小周得 30，小林得 20。

先别往下读。请你想一想：**这个分法，小周和小林会同意吗？**

我们看看他们俩的处境：他们两人合起来只分到 30 + 20 = **50**。可是他们俩**自己联手干**，不带你，能赚 **60**。60 比 50 多，他们俩分 60，每人都能比现在多。所以他们会**退出**，另起炉灶。**(50, 30, 20) 站不住。**

这一讲就是要把这个想法一般化：**什么样的分法，没有任何一群人想退出？**

## 二、特征函数和核

先把问题写清楚。有几个人（我们叫它们"局中人"），他们可以组成各种**联盟**。每一个联盟 S，如果撇开其他人自己干，能创造的价值是 **v(S)**。这个对应关系，叫**特征函数**。

在我们的例子里：

- v(单人) = 0，
- v(任意两个人) = 60，
- v(三个人一起) = 100。

一个分法（把 100 分给三个人，每人 x₁、x₂、x₃）要满足两件事，才算站得住：

1. **分得完，也不浪费**：x₁ + x₂ + x₃ = 100（大联盟的价值全部分掉）。
2. **任何联盟都不想退出**：对每一个联盟 S，S 里的人**分到的总和**，不能低于 v(S)。（否则这群人单干，每个人都能多分。）

满足这两个条件的所有分法，合起来叫**核**（core）。

"核"这个词的意思，就是**一个稳定的内核**：核里的任何一个分法，没有任何一群人有理由推翻它。

## 三、第一个例子：核是一块区域

我们来找上面那个例子的核。设分法 (x₁, x₂, x₃)。

联盟的条件：

- 每个人单干：x₁ ≥ 0，x₂ ≥ 0，x₃ ≥ 0。
- 每一对：x₁ + x₂ ≥ 60，x₁ + x₃ ≥ 60，x₂ + x₃ ≥ 60。

再用 x₁ + x₂ + x₃ = 100。第一对条件 x₁ + x₂ ≥ 60，等价于 x₃ ≤ 100 − 60 = **40**。同理 x₁ ≤ 40，x₂ ≤ 40。

所以核就是：**每个人拿到的都不超过 40**（并且总和 100）。因为另外两个人加起来不能超过 80，所以每个人其实还至少能拿 100 − 80 = **20**。

核是一个三角形区域，三个顶点是 (40, 40, 20)、(40, 20, 40)、(20, 40, 40)。平分 (33.3, 33.3, 33.3) 就在这个区域的中央。

![三个人分 100：核是中间一小块](/images/game-theory/32-core-triangle.svg)

图里，三角形的三个角分别表示"某个人拿走全部"。绿色的小三角是核；外面红色虚线围出的三个角，是"某个人拿到超过 40"的分法，剩下的两人加起来不到 60，会联手退出。我们开头的 (50, 30, 20) 就在你的红色角里。

⚠️ **这里第一次读会觉得别扭。** 你会想：核里有很多个分法，那么到底该选哪一个？(40, 40, 20) 和平分，哪个"对"？

核**不回答**这个问题。它只回答"**哪些分法站不住**"：核之外的分法，一定会有人退出。核之内的分法，都站得住，到底落在哪一个，取决于别的东西：谈判力量、公平观念、先后顺序。（也有别的办法来挑一个，比如给每个人算一个"公平的份额"。）核是一个**稳定性**的标准，不是一个**公平**的标准。

## 四、第二个例子：稀缺的人拿走一切

再看一个经典的例子，叫**手套博弈**。

你有一只**左手套**，小周和小林**各有一只右手套**。一副手套（一只左加一只右）值 **100**，单独一只手套不值钱。

- v(单人) = 0。
- v(你，小周) = 100，v(你，小林) = 100。
- v(小周，小林) = 0（两只右手套凑不成一副）。
- v(三人) = 100（三个人最多也只能凑成一副）。

核里的分法要满足：x₁ + x₂ ≥ 100，x₁ + x₃ ≥ 100，且 x₁ + x₂ + x₃ = 100。两条不等式相加：2x₁ + x₂ + x₃ ≥ 200，也就是 x₁ + 100 ≥ 200，所以 **x₁ ≥ 100**。而 x₁ 又不能超过总数 100，所以 x₁ = 100，x₂ = x₃ = 0。

**核只有一个点：(100, 0, 0)。你拿走全部。**

道理很直观：左手套是**稀缺**的，右手套有两个，彼此竞争。小周只要多要一点，你就会转去找小林，反过来也一样。两个竞争者互相压价，最后价格被压到 0。

这个结论和"稀缺决定价格"的想法是一回事。早在 1881 年，Edgeworth 就用类似的想法讨论过交易中的"核"，Debreu 和 Scarf 1963 年证明：当交易者越来越多（把每种交易者都复制很多份）时，核会缩小到竞争均衡。（据二手转述，我没有核对原文。）

反过来，**如果左手套和右手套一样多**呢？比如两只左、两只右，一副值 1，总共能凑成两副，核是一条线段：左手套的人各得 a，右手套的人各得 1 − a，a 在 0 到 1 之间任意。**双方一样稀缺，谁拿多少就不确定了。**

## 五、第三个例子：核是空的

最后看一个让人不安的例子：**三人多数决**。

三个人分 100。规则是：**任意两个人只要同意，就能拿走全部 100**；一个人单干拿 0；三个人一起也是 100。

- v(单人) = 0，
- v(任意两人) = 100，
- v(三人) = 100。

核的条件是：x₁ + x₂ ≥ 100，x₁ + x₃ ≥ 100，x₂ + x₃ ≥ 100，且 x₁ + x₂ + x₃ = 100。

把三条不等式加起来：2 × (x₁ + x₂ + x₃) ≥ 300，也就是 2 × 100 ≥ 300，即 200 ≥ 300。**这是不可能的。核是空的。**

直观上看：任何一个分法，总有两个人加起来分得不到 100，他们可以联手独吞。

我们看看这个循环是怎么发生的。从 (50, 50, 0) 开始：

- 你和小林联手：你从 50 涨到 60，小林从 0 涨到 40，得到 **(60, 0, 40)**。（他们两个能拿走全部 100，其中 60 加 40 等于 100。）
- 小周和小林联手：小周从 0 涨到 50，小林从 40 涨到 50，得到 **(0, 50, 50)**。
- 你和小周联手：你从 0 涨到 40，小周从 50 涨到 60，得到 **(40, 60, 0)**。
- 你和小林联手：你从 40 涨到 60，小林从 0 涨到 40，又回到 **(60, 0, 40)**。

……一圈接一圈，永远没有一个分法站得住。

![三人多数决：任何分法都会被推翻](/images/game-theory/32-majority-cycle.svg)

⚠️ **这里第一次读会觉得别扭。** 你会想：核是空的，是不是说这三个人就不会合作了？

不是。核为空，**只**说明：**没有任何一个分法，能挡住所有联盟的退出。** 现实里，人们仍然会组成联盟、分钱，只是结果是**不稳定的**：今天这两个人联手，明天换另一对。政治里的联合政府有时候就有这样的味道（这是一个类比，不是对某个政府的断言）。

### 什么时候核是空的

我们把"两人联盟的价值"改成一般的 p：三个人分 100，任意两人联手价值 p，一个人 0。核的条件加起来：2 × 100 ≥ 3p，也就是 **p ≤ 200/3 ≈ 66.7**。

- p = 60：核非空（就是第三节的例子）。
- p = 66：核非空，但已经很小了。
- p = 67：核是空的。

我用程序对整数分法逐一检验过：p = 66 时有 6 个整数分法，p = 67 时一个也没有。

这个检验背后有一个一般的结论。想象把几个联盟按权重"凑起来"，让每个人恰好被"用满一次"（比如三个两人联盟，每个权重 1/2，每个人恰好被两个联盟各用半次，合计一次）。如果这些联盟的价值加权和，**超过**大联盟的价值（这里是 1/2 × (100 + 100 + 100) = 150，大于 100），核就是空的。**反过来也成立**：没有这样的"凑法"，核就非空。这就是 Bondareva–Shapley 定理，条件叫"平衡"。

## 六、证据：现实里人会选核吗

**理论预测。** 核里的分法最稳定；核为空时，分法不稳定；稀缺的一方拿走更多。

**证据。**

- **核的出处。** 核通常被认为由 Gillies 在 1950 年代提出并推广（Gillies 1959，《博弈论文集》第四卷，47–86 页）；有后来的论文认为 Shapley 更早定义过。（据二手转述。）
- **核非空的判据。** Bondareva 1963 年和 Shapley 1967 年（Naval Research Logistics Quarterly，14 卷，453–460 页）分别独立得到平衡条件（据二手转述，Bondareva 的年份各来源不一）。
- **市场里的核。** Edgeworth 1881 年的《数学心理学》（Mathematical Psychics）；Debreu 和 Scarf 1963 年，据转述发表在《国际经济评论》（International Economic Review，4 卷 3 期，235–246 页），不过有一份文献目录把它列在别的期刊，请核对。
- **实验。** 据我看到的几篇摘要和工作稿（**没有核对原文**）：在三人合作博弈的自由谈判实验里，**核存在时**，人们更倾向于组成包含所有人的大联盟，得到的分法常常在核里；**核为空时**，人们常常只组成两人联盟，并且常常平分。（我没有核对到这几篇的正式出处，所以不写具体数字。）

**局限。** 核有一个很强的前提：联盟里的人能**签订有约束力的协议**，而且每个联盟都能自由退出。实验里的自由谈判，和这个前提不完全一样。

**分歧。** 核是不是预测真实分配的好工具，要看场合：市场里的稀缺性，核预测得不错；在公平观念很强的场合，人们常常偏离核。这是**事实**问题。至于"是否应该按核来分"（把稳定放在第一位）还是"按公平来分"，则是**价值判断**。

## 七、常见的误用

- **"核就是公平的分法。"** 不对。核只保证稳定：手套博弈里，核是"你拿走一切"，很不平均。
- **"核是唯一的。"** 不一定。有的有一个点，有的是一块区域，有的是空的。
- **"核为空，就不会有合作。"** 不对。只是没有稳定的分法，联盟可能不断重组。
- **"核里的分法一定被选中。"** 不对。核没有说选哪个。
- **"平分一定在核里。"** 不一定。手套博弈里，平分会被"你和任一右手套拥有者联手"推翻。

## 八、小结

- **特征函数** v(S)：联盟 S 自己干能创造的价值。
- **核**：分得完（总和等于大联盟的价值），并且每个联盟分到的不低于它自己干的价值。
- **三个人分 100，两人联手 60**：核是每人都不超过 40 的区域，三个顶点 (40, 40, 20) 等，平分在核里。
- **手套博弈**：稀缺的一方拿走一切，核只有一个点 (100, 0, 0)；一样稀缺时，核是一条线段。
- **三人多数决**：三个两人联盟的条件相加，得到 200 ≥ 300，核是空的；分法永远在被推翻、循环。
- **核非空的条件**：两人联盟价值 p 不超过 200/3。
- **证据**：理论上，Edgeworth 到 Debreu–Scarf 的核与竞争均衡；实验里，核存在时更倾向于大联盟。

回到那个三个人的项目。下次你们要分一笔钱，请想一想：有没有一群人，在这个分法下得到的比他们自己干的少？如果有，这个分法就会有人退出。

## 思考题

1. 三个人分 100，单干 0，任意两人联手 60。分法 (45, 35, 20) 在核里吗？(36, 32, 32) 呢？
2. 把"任意两人联手"的价值改成 **80**（三人一起仍是 100）。核是不是空的？为什么？
3. 手套博弈：**两只左手套、两只右手套**，一副值 1。写出核的条件，并说明核是形如 (a, a, 1 − a, 1 − a) 的线段。
4. 三个人分 100，规则：**必须有你参与**，你和任意一个别人在一起就能拿 100；没有你，其他人拿 0。求核。
5. 三人多数决，分法 (40, 30, 30)：找一对会推翻它的联盟，并写出一个新的分法。再对你找到的新分法，找另一对推翻它的联盟。
6. 想一个生活里"合伙分钱"的例子（合租分摊房租、合买团购、一起接项目……），说说特征函数是什么，核大概是什么样（一块区域、一个点，还是空的）。

## 思考题提示

1. (45, 35, 20)：小周和小林合起来 35 + 20 = 55，小于 60，**不在核里**（他们俩联手能多得）。(36, 32, 32)：每对的和分别是 68、68、64，都不低于 60；三个人都不超过 40，**在核里**。
2. 核的条件相加：2 × 100 ≥ 3 × 80，即 200 ≥ 240，不成立，所以**核是空的**。（只要两人联手的价值超过 200/3，核就是空的。）
3. 四个人：a、b 是两个左手套持有人，c、d 是两个右手套持有人。条件：a + c ≥ 1，a + d ≥ 1，b + c ≥ 1，b + d ≥ 1，且 a + b + c + d = 2。把 a + c ≥ 1 和 b + d ≥ 1 相加：a + b + c + d ≥ 2，等号成立，所以这两个不等式都是等式：a + c = 1，b + d = 1。同理 a + d = 1，b + c = 1。由 a + c = 1 和 a + d = 1 得 c = d；由 a + c = 1 和 b + c = 1 得 a = b。令 a = b，c = d = 1 − a，a 在 0 到 1 之间，就是线段。
4. 你和任一人的联盟条件：x₁ + x₂ ≥ 100，x₁ + x₃ ≥ 100，相加得 2x₁ + x₂ + x₃ ≥ 200，即 x₁ + 100 ≥ 200，x₁ ≥ 100。所以 **x₁ = 100，x₂ = x₃ = 0**：核只有一个点，你拿走全部。"必不可少的人"和手套博弈里的稀缺方是同一个道理。
5. (40, 30, 30)：小周和小林合起来才 60，小于 100。他们联手，可以得到 (0, 50, 50)（你被甩开）。新分法 (0, 50, 50)：你和小周联手，你得 0，可以涨到 40，小周从 50 涨到 60，得到 (40, 60, 0)。（也可以用别的分法，只要联手的两人都比原来多、总和不超过 100。）
6. 开放题。例：三个人合买一台大设备，设备对单人不划算，对两人划算，对三人最划算。v(单人) 可能是负的或 0；v(两人) 小于 v(三人) 的话，核是一块区域，成本分摊要让每一对的分摊不超过他们自己合买的成本。
