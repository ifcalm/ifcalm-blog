## 一、一手看不穿的牌

德州扑克打到最后一轮，桌上的底池里有 **100**（你和小周各投了 50）。现在轮到你说话，你面临这样的局面：

- 你的牌要么是**必赢的强牌**，要么是**必输的弱牌**，各占一半。你自己知道是哪一种，小周**不知道**。
- 小周手里是一张"中等牌"：能赢你的弱牌，输给你的强牌。
- 你可以**过牌**（直接摊牌，谁的牌大谁赢底池），或者**下注 100**。如果你下注，小周可以**跟注**（再投 100，摊牌），或者**弃牌**（认输，底池归你）。

先别往下读。请你想两个问题：

1. 你拿到**弱牌**的时候，要不要下注"诈唬"？
2. 小周面对你的下注，**跟还是弃**？

写好了吗？我们先把它写成一棵树。

## 二、把"看不到"写进博弈树

### 2.1 一棵带"信息集"的树

下面这棵树里，最上面是"自然"：它决定你拿到强牌还是弱牌，各一半的概率。你看得见，小周看不见。

![河牌上的虚张声势](/images/game-theory/16-bluff-tree.svg)

树上的数字是**你的净收益**（小周的就是相反数）：

- 你**过牌**：直接摊牌。强牌赢，你得 **+50**（赢走小周在底池里的 50）；弱牌输，你得 **−50**。
- 你**下注，小周弃牌**：你赢走底池，得 **+50**。
- 你**下注，小周跟注**：强牌，你多赢小周的 100，得 +50 + 100 = **+150**；弱牌，你输掉自己多投的 100，得 −50 − 100 = **−150**。

最关键的是中间那条**橙色虚线**。它把小周的**两个**决策节点连在了一起：小周在这两个位置上，**看到的东西一模一样**，就是"你下注了"，TA 分不清自己是在"你强"的那个节点，还是在"你弱"的那个节点。

> **信息集**：一个玩家做选择时，自己**无法区分**的所有节点，放在一起，叫一个信息集。同一个信息集里的节点，玩家看到的东西完全一样，所以 TA 在这些节点上**必须做同样的选择**。

在每个人都看得见之前发生了什么的博弈里，每个节点自己就是一个信息集。**信息集，就是"看不到"在博弈树上的样子。**

### 2.2 策略：在信息集上做选择

你自己的两个节点（强、弱）是**两个不同的信息集**，因为你知道自己的牌。小周只有**一个**信息集。所以：

- 你的策略：强牌时下注（显然，下注只赚不赔）；弱牌时，**以概率 b 下注**（诈唬），以概率 1 − b 过牌。
- 小周的策略：看到下注，**以概率 c 跟注**，以概率 1 − c 弃牌。

像这样，在每个信息集上各自按一定的概率选择，叫**行为策略**。

## 三、该诈唬多少

### 3.1 从不诈唬，行不行

假设你**从不诈唬**（b = 0）。小周听到下注，就知道你一定是强牌，**弃牌**。你的收益：强牌下注，小周弃牌，+50；弱牌过牌，−50。平均是 (+50 − 50) ÷ 2 = **0**。

### 3.2 总是诈唬，行不行

假设你**弱牌也一律下注**（b = 1）。小周听到下注，不知道你是强是弱，各一半。小周跟注的期望是：一半概率输 150，一半概率赢 150，平均 0；弃牌是 −50。小周会**跟注**（0 比 −50 好）。你的收益：强牌被跟注 +150，弱牌被跟注 −150，平均 **0**。

两个极端都是 0。**不诈唬，对手就知道你下注是真牌，不会给你付钱；总诈唬，对手就敢跟注，你的诈唬全部被抓。**

### 3.3 取多少最好

设你弱牌时以 b 的概率诈唬。对小周来说：

- 小周总是**弃牌**：你的期望是 50b（强牌 +50，弱牌下注 +50，弱牌过牌 −50，一合并就是 50b）。
- 小周总是**跟注**：你的期望是 50 − 50b。

小周会选对自己最好的，也就是**让你的期望更低**的那个。看几个 b：

| b | 小周总弃牌时你的期望 | 小周总跟注时你的期望 | 小周会选 | 你的期望 |
|---|---|---|---|---|
| 0 | 0 | 50 | 弃牌 | 0 |
| 1/4 | 12.5 | 37.5 | 弃牌 | 12.5 |
| **1/2** | **25** | **25** | 无差别 | **25** |
| 3/4 | 37.5 | 12.5 | 跟注 | 12.5 |
| 1 | 50 | 0 | 跟注 | 0 |

![诈唬多少最合适](/images/game-theory/16-bluff-tent.svg)

红线是"小周选对自己最有利的应对"之后你的期望收益，在 **b = 1/2** 处最高，是 **25**。**弱牌的时候，一半的概率诈唬。**

### 3.4 小周该跟多少

反过来站在小周的位置。你弱牌时，下注和过牌对你应该**一样好**，这样你才愿意随机：

- 你过牌（弱牌）：−50。
- 你下注（弱牌），小周以 c 的概率跟注：c × (−150) + (1 − c) × 50 = 50 − 200c。

让两者相等：50 − 200c = −50，得 **c = 1/2**。小周面对下注，**一半的概率跟注**。

### 3.5 一个简单的比例

在均衡里，你下注的牌有多少是诈唬？强牌（概率 1/2）全部下注，弱牌（概率 1/2）里有一半下注：

- 强牌下注：1/2；弱牌下注：1/2 × 1/2 = 1/4。
- 诈唬在所有下注里的占比：1/4 ÷ (1/2 + 1/4) = **1/3**。

**每下注三次，有一次是诈唬。** 这个 1/3 不是巧合。小周跟注，赢了净得 150，输了净亏 150；弃牌则固定亏 50。设小周跟注时赢的概率是 w，跟注不亏需要 150w − 150(1 − w) 至少等于 −50，解得 w = 1/3，也就是你下注的牌里，有 1/3 是小周能赢的（诈唬）。所以一般地：

> **诈唬占下注的比例 = 下注额 ÷（底池 + 2 × 下注额）。**

下注 100、底池 100，比例就是 100 ÷ 300 = 1/3。

⚠️ **这里最容易想错：诈唬的目的，不是骗，而是让对手"无差别"。** 你诈唬的比例，刚好让小周在跟注和弃牌之间**没有偏好**。多一点，TA 就会一直跟；少一点，TA 就会一直弃。你不是在猜 TA 会不会上当，而是在**让 TA 怎么做都占不到便宜**。

## 四、三张牌的小扑克

扑克的难点，是牌太多。有一个只有三张牌的版本，是 Kuhn 在 1950 年设计的"一个简化的两人扑克"，被反复研究，几乎成了信息集的标准教材例子。

### 4.1 规则

三张牌：**J、Q、K**（K 最大）。你和小周各先投 **1**（底注）。各发一张牌，各自看自己的，不给对方看。

1. 你先说话：**过牌**或**下注 1**。
2. 如果你**过牌**：小周可以**过牌**（直接摊牌，大的赢 1），或者**下注 1**。小周下注后，你可以**弃牌**（输 1）或**跟注 1**（摊牌，大的赢 2）。
3. 如果你**下注**：小周可以**弃牌**（你赢 1）或**跟注**（摊牌，大的赢 2）。

### 4.2 均衡

这个游戏的均衡有一整族。其中一个是（以下的"你"是先说话的人）：

| 谁、在什么局面 | 手里的牌 | 怎么做 |
|---|---|---|
| 你，先说话 | J | 以 1/3 的概率下注（诈唬），其余过牌 |
| | Q | 过牌 |
| | K | 下注 |
| 你，过牌后小周下注了 | J | 弃牌 |
| | Q | 以 2/3 的概率跟注 |
| | K | 跟注 |
| 小周，面对你的下注 | J | 弃牌 |
| | Q | 以 1/3 的概率跟注 |
| | K | 跟注 |
| 小周，面对你的过牌 | J | 以 1/3 的概率下注（诈唬） |
| | Q | 过牌 |
| | K | 下注 |

几个值得停下来想的地方：

- **最差的牌 J，有时会下注。** 这是诈唬：J 反正很难赢，偶尔下注，可以逼走手里是 Q 的对手。
- **中等的牌 Q，反而不一上来下注。** 下注的话，K 会跟（你输 2），J 会弃牌（你只赢 1）。过牌则可以保留"抓对手诈唬"的机会：对手的 J 有时会诈唬下注，这时你的 Q 能赢。
- **最强的牌 K，总是下注。** 强牌价值要赚足。

### 4.3 算一算，这是不是均衡

把 6 种发牌（你的牌、小周的牌）都算一遍，每种的概率是 1/6。表里是**你的期望净收益**：

| 你的牌 | 小周的牌 | 你的期望收益 |
|---|---|---|
| J | Q | −2/3 |
| J | K | −4/3 |
| Q | J | +1 |
| Q | K | −5/3 |
| K | J | +1 |
| K | Q | +4/3 |

平均是 (−2/3 − 4/3 + 1 − 5/3 + 1 + 4/3) ÷ 6 = (−1/3) ÷ 6 = **−1/18**。

我还检验过：不论小周怎么改变策略，你的期望都不会低于 −1/18；不论你怎么改变策略，小周也压不低 1/18。所以这是均衡，游戏的**值是 −1/18**。

**先说话的人，平均每局输 1/18 个底注**（约 5.6%）。后说话的小周占了一点便宜，因为 TA 先看到了你的动作。

## 五、证据：真有人这样玩吗

**理论预测什么？** 在这类游戏里，理性的玩家会按特定比例诈唬，让对方无差别；先说话的人在三张牌的游戏里略吃亏（−1/18）。

**证据怎么说？**

- Kuhn 的三张牌扑克，发表在 1950 年的《博弈论文集》第一卷（由 Kuhn 和 Tucker 主编）里。据多个二手介绍，这个游戏的均衡值是 −1/18，并且均衡不止一个，而是一族（由一个参数控制）。
- 近年的扑克人工智能给了一个有说服力的现实检验。据报道，名为 Libratus 的程序在 2017 年和四位顶尖职业选手打了 12 万手一对一无限注德州扑克，胜出；名为 Pluribus 的程序在 2019 年发表于《科学》杂志，据报道在六人桌上击败了顶尖的人类选手。据介绍，这类程序的思路是让程序自我对弈，逐步逼近一个"不可被针对"的策略，并在需要时随机选择。

**局限在哪？** 真实的扑克比这里的玩具大得多：牌多、轮次多、下注额可以变，没有人能精确算出均衡。人工智能用的是近似。真人对手也不是理想的均衡玩家。报道里的细节没有逐条核对原始论文。

**分歧是什么？** 对真人来说，**该一直按均衡打，还是该针对对手的习惯来调整**？按均衡打，对手无法占你的便宜，可是你也占不到便宜；针对习惯打，可能赢更多，可是你的偏离也会被对手利用。两种打法各有道理，要看你对对手的把握有多大。

## 六、常见的误用

- **"诈唬就是骗人。"** 不对。它的作用是让对手在"跟"和"弃"之间没有偏好，是一种按比例的随机，不是撒谎的本事。
- **"诈唬越多越好。"** 不对。过了 1/3，对手就会一直跟注，你的诈唬全被抓。
- **"按均衡打就能赢。"** 不对。均衡策略保证你**不会被针对**，不保证你赢。三张牌里，先说话的人长期是亏的（−1/18）。
- **"发现对手的规律，就一直针对 TA。"** 要小心。你一直针对，对手也会发现，并反过来利用你。
- **"信息集就是'知道得少'。"** 不对。信息集说的是**你没法区分哪些情形**，它决定你的策略必须在这些情形里一样。

## 七、小结

- **信息集**：一个玩家做选择时无法区分的所有节点。同一个信息集里，玩家必须做同样的选择。"看不到"，就用信息集来写。
- **行为策略**：在每个信息集上，按一定的概率选择。
- **河牌上的虚张声势**：弱牌时一半的概率诈唬，对手面对下注一半的概率跟注，你的期望是 25。诈唬占下注的 1/3，等于下注额 ÷（底池 + 2 × 下注额）。
- 诈唬的目的是让对手**无差别**，不是欺骗。
- **三张牌扑克**：最差的牌偶尔诈唬，中等的牌过牌，最强的牌下注；先说话的人平均输 1/18 个底注。
- 均衡保证你不会被针对，不保证你赢。

回到那手看不穿的牌：下次你听到"这个人一直在虚张声势"，请想一想：TA 诈唬的比例，是不是刚好让你不知道该跟还是该弃？

## 思考题

1. 河牌的例子里，底池 100，但这次**下注 50**（半个底池）。你弱牌时诈唬的概率 b 是多少？小周面对下注，跟注的概率 c 是多少？诈唬占下注的比例是多少？你的期望收益是多少？
2. 底池 100、下注 100，但强牌的概率变成 **2/3**（弱牌 1/3）。你弱牌时该诈唬多少？小周跟注的概率是多少？你的期望收益是多少？
3. 三张牌扑克里，你拿 Q，先说话。按上面的均衡，计算"下注"和"过牌"的期望收益，说明为什么 Q 一上来过牌。（提示：小周手里是 J 或 K，各 1/2；小周面对你下注时，J 弃牌，K 跟注。）
4. 河牌的例子里，如果你发现小周**总是跟注**，你该怎么做？期望是多少？小周发现之后会怎么办？
5. 举一个生活里需要"诈唬"的例子（谈判、竞标、比赛），说说如果你从不诈唬、或总是诈唬，会发生什么。
6. 石头剪刀布，你先出，小周后出但**看不到**你出什么。把它画成博弈树，小周有几个决策节点？它们是不是在同一个信息集里？如果小周**看得到**，又是怎样的？

## 思考题提示

1. 下注 50：诈唬被跟注输 100，弃牌赢 50。让小周无差别：P(强牌｜下注) = 3/4，对应 b = 1/3（弱牌里 1/3 的概率诈唬）；让你弱牌时无差别：50 − 150c = −50，c = 2/3。诈唬占下注的比例：(1/2 × 1/3) ÷ (1/2 + 1/2 × 1/3) = 1/4，等于 50 ÷ (100 + 100) = 1/4。你的期望是 50/3 ≈ 16.7。
2. 强牌 2/3：小周无差别需要 P(强牌｜下注) = 2/3。弱牌概率只有 1/3，即使你弱牌总是诈唬（b = 1），P(强牌｜下注) = (2/3) ÷ (2/3 + 1/3) = 2/3，刚好够。所以 b = 1，也就是弱牌一律下注；小周跟注的概率 c = 1/2；你的期望是 2/3 × 100 + 1/3 × (−50) = 50。
3. 下注：J 弃牌（赢 1），K 跟注（输 2），期望 1/2 × 1 + 1/2 × (−2) = −1/2。过牌：对 J：J 以 1/3 下注，你以 2/3 跟注（赢 2）或弃牌（−1）；J 以 2/3 过牌（摊牌赢 1）。期望 2/3 × 1 + 1/3 × (2/3 × 2 + 1/3 × (−1)) = 1。对 K：K 总是下注，你以 2/3 跟注（输 2）或弃牌（输 1），期望 2/3 × (−2) + 1/3 × (−1) = −5/3。平均 (1 − 5/3) ÷ 2 = −1/3。过牌（−1/3）比下注（−1/2）好。
4. 总是跟注，你就不该诈唬（b = 0），强牌下注，弱牌过牌。期望：强牌被跟注 +150，弱牌过牌 −50，平均 50。小周发现你不再诈唬，就会改成弃牌，你的期望降到 0；于是你会再开始诈唬。双方一轮一轮调整，最后停在均衡。
5. 开放题。例子：谈判桌上虚报底线。从不虚报，对手知道你的话总是真话；总是虚报，对手就不再信你。
6. 小周有 3 个决策节点（你出石头、剪刀、布之后各一个）。如果小周**看不到**，三个节点在**同一个信息集**里，小周只能出同一种应对，不论你出什么；如果**看得到**，三个节点各自是一个信息集，小周可以针对每种出法选能赢的。
