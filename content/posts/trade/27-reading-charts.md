[第七篇](/posts/trade/07-analysis-methods/)按证据强度评价了技术分析，[第十五篇](/posts/trade/15-orderflow-data/)讲了盘口和成交数据能测量什么。这一篇处理一个更基础、也更少被认真对待的问题：

> **屏幕上那张图，到底承载了多少信息？**

不是「怎么用图表预测」——那是[第七篇](/posts/trade/07-analysis-methods/)已经给过结论的事。而是**一张图里客观存在什么、客观丢失了什么、以及哪些看起来是新信息的东西其实不是**。

这一篇几乎全是可验证的构造性事实。看完之后，很多关于图表的说法会自动失效——不需要统计检验，因为它们在**信息论层面**就不成立。

> 本文仅用于记录和普及基础知识，不构成投资建议。文中不推荐任何指标或用法。

## 一、K 线是一次有损压缩

### 它保留了什么

一根 K 线把一段时间内的成千上万笔成交，压缩成四个数字：

```
开盘 O：该周期第一笔成交价
最高 H：期间最高成交价
最低 L：期间最低成交价
收盘 C：该周期最后一笔成交价
```

加上成交量，一共五个数。

### ⭐ 它丢掉了什么

**全部路径信息。** 而其中最关键的一项是：

> **你无法从一根 K 线知道，最高价和最低价谁先出现。**

这两根形态完全相同的 K 线，内部可以是完全相反的过程：

```
情况 A：开盘 → 先冲到最高 → 一路跌到最低 → 收在中间
情况 B：开盘 → 先砸到最低 → 一路涨到最高 → 收在中间

OHLC 四个数完全一样。图上是同一根 K 线。
```

### 这不是学术细节——它直接造成回测偏差

```
一根日线：最高价碰到了你的止盈，最低价碰到了你的止损

回测引擎必须二选一：
  假设先到止盈 → 系统性高估
  假设先到止损 → 系统性低估

而这根 K 线里根本没有这个信息。
```

**周期越大，一根 K 线内「双向触及」的情况越多，这个偏差越严重。**

这是[第七篇](/posts/trade/07-analysis-methods/)六种回测偏差里最隐蔽的一个，因为它不来自你的疏忽，来自**数据本身的信息缺失**。

唯一的解法是用更细的数据回测——**如果你的策略同时有止损和止盈，就必须用比信号周期至少细一个数量级的数据来验证**。

### 关于影线和收盘价

**影线**的机制含义是：那个价格**被触及过但没有被守住**。仅此而已。它不告诉你是谁在那里成交、成交了多少、为什么退回来。

⚠️ 一根长上影可以是「抛压很重」，也可以是「一笔大买单打空了薄簿子然后回落」——[第十五篇](/posts/trade/15-orderflow-data/)讲的，**在流动性薄的时段，制造一根长影线的成本非常低**。

**收盘价**在传统市场有明确含义（结算价、指数编制基准、期权行权判定）。但在 **7×24 的加密市场，「收盘」只是一个人为选定的时间切片**——UTC 0 点和你所在时区的 0 点，切出来是两组不同的 K 线，而底层成交完全一样。

> **绝大多数指标都建立在收盘价上，而收盘价在 24 小时市场里是一个约定，不是一个事件。**

## 二、周期：恒等，不是相关

### 高周期就是低周期加起来的

```
1 根 1 小时 K 线  ≡  它内部那 12 根 5 分钟 K 线
```

**这是恒等关系，不是相关关系。** 完全相同的成交记录，只是聚合粒度不同。高周期没有包含任何低周期没有的成交。

所以：

> **切换周期不会给你新数据，只会改变平滑程度。**

### ⚠️ 由此「多周期共振」失效

三个周期都看多，必然高度一致——**这是构造决定的，不是市场告诉你的**。

```
你以为的：p = 0.05³ ≈ 0.000125
实际接近：p = 0.05
```

判据在[第十五篇](/posts/trade/15-orderflow-data/)：**同一个量 ⇒ 重复采样；不同的量 ⇒ 补充信息。**

```
❌ 大周期判方向 + 小周期判方向     → 同一个量
✅ 大周期算 ATR 定仓位 + 小周期定入场 → 不同的量
✅ 大周期判断环境（做不做）+ 小周期触发 → 过滤器 vs 触发器
```

### 那周期选择在决定什么

既然不改变信息，周期实际决定的是三件**可以算出来的**事（[第二十六篇](/posts/trade/26-screening/)）：

| 决定的东西 | 关系 |
|---|---|
| **成本比值** | 波动按 √T 缩放，**成本按 1 缩放** ⇒ 周期越小越吃亏 |
| **样本积累速度** | 周期越小，攒够 256 笔越快 ⇒ 越早知道自己对不对 |
| **对手构成** | 15 分钟以下几乎全是机器 |

**这三件事和「哪个周期看得更清楚」毫无关系。** 周期选择是一个算术问题，不是审美问题。

## 三、⭐ 指标：它们实际在算什么

这是本篇信息量最大的一节。

### 一个分类

把图表上能画的东西，按**它是否引入了价格之外的数据**分类：

| 类别 | 例子 | 含新信息吗 |
|---|---|---|
| **① 价格的确定性变换** | MA、EMA、MACD、RSI、KDJ、动量 | ❌ **零新信息** |
| **② 波动率变换** | ATR、布林带宽、标准差通道 | ✅ 有（二阶矩） |
| **③ 成交量类** | 成交量、CVD、VWAP、OBV | ✅ 有（不同的数据） |
| **④ 订单簿/逐笔** | 深度、OBI、主动买卖 | ✅ 有（[第十五篇](/posts/trade/15-orderflow-data/)） |
| **⑤ 链上/基本面** | 活跃地址、资金费率、持仓量 | ✅ 有 |

### 第 ① 类为什么是零新信息

因为它们是价格的**确定性函数**：

```
MA(n)  = (P_t + P_{t-1} + ... + P_{t-n+1}) / n
MACD   = EMA(12) − EMA(26)，信号线 = 它的 EMA(9)
RSI    = 100 − 100/(1+RS)，RS = 平均涨幅 / 平均跌幅
KDJ    = (C − L_n) / (H_n − L_n) 的平滑
```

**给定价格序列，这些值唯一确定。** 它们不是新观测，是**同一份数据的重新表述**。

推论——而且这个推论很硬：

> **在图上加十个第 ① 类指标，你没有得到十个证据。你得到的是同一个价格序列的十种画法。**
>
> 它们必然高度相关，因为它们是同一个输入的不同变换。

这和多周期共振是**完全一样的错误**，只是换了一个维度：一个在时间尺度上重复采样，一个在变换方式上重复采样。

### ⚠️ 这不等于「指标没用」

必须说清楚边界，否则就成了另一种教条：

- 确定性变换**可以有用**——它把某些结构变得容易观察（比如 ATR 让你不必心算波动率）
- 它有用的方式是**降低认知负担**，不是**增加信息**
- 判断一个第 ① 类指标是否有效，**必须用[第七篇](/posts/trade/07-analysis-methods/)和[第二十篇](/posts/trade/20-performance-and-retirement/)的方法实测**，不能靠「它显示了什么」

真正要拒绝的是这句话：**「均线金叉 + MACD 金叉 + RSI 上穿，三重确认」**——那是一个观测被数了三遍。

### 第 ② 类的特殊地位

波动率类值得单独说，因为它是**第 ① 类里唯一逃出来的**：

```
MA 用的是价格的一阶矩（均值）
ATR / 标准差用的是二阶矩（离散度）
```

二阶矩确实包含一阶矩没有的信息。更重要的是——**波动率是这份手册里少数几个反复被用到的量**：

- 仓位大小（[第六篇](/posts/trade/06-risk-management/)）
- 止损距离（[第六篇](/posts/trade/06-risk-management/)、[第十八篇](/posts/trade/18-execution/)）
- 可交易比值（[第二十六篇](/posts/trade/26-screening/)）
- 杠杆 ETF 衰减（[第十二篇](/posts/trade/12-product-structures/)）

⭐ **而且波动率有一个方向性预测所没有的性质：它有可观察的自相关（波动率聚集）。** 这不是本手册要展开的策略内容，但它解释了为什么波动率类指标在实用性上和方向类指标不在一个层级。

### 第 ③ 类：图表上唯一的非价格数据

一张标准 K 线图上，**只有成交量不是价格的函数**。

这让它成为图表上最值得认真对待的一栏。但用它有一个前提，[第十五篇](/posts/trade/15-orderflow-data/)已经强调过，这里再说一次因为太多人做错：

> ⚠️ **成交量必须和「历史同一时段」比，不能和前面几根比。**

```
❌ 前几根是 100、120、110，这根 500 → 放量！
   （在美国开盘时段，500 可能是正常的）

✅ 把一天切成固定的桶（5min → 288 桶）
   对每个桶算过去 20–30 天的均值和标准差
   今天这一根的 Z 分数 = (当前量 − 该桶均值) ÷ 该桶标准差
```

和前几根比，会**系统性地在活跃时段误报放量、在冷清时段误报缩量**。

## 四、点位：它是流动性，不是转折点

### 机制上真实的部分

这部分可以论证，不需要信仰：

| 位置 | 那里堆着什么 |
|---|---|
| **前高上方** | 突破买单 + 空头止损（买方向） |
| **前低下方** | 突破卖单 + 多头止损（卖方向） |
| **整数关口** | 限价单显著聚集（价格聚集是微观结构文献中证据充分的现象） |

所以正确的表述是：

> **点位是「流动性可能在那里」的位置，不是「价格可能在那里反转」的位置。**

这两句话的差别是决定性的。

### ⭐ 由此得到一个反直觉的推论

[第十五篇](/posts/trade/15-orderflow-data/)那句话在这里落地：

> **止损单在关键位置上，从「保护」变成了「流动性供给」。**

大额资金需要成交对手时，会去有挂单的地方找——而那正是所有人止损堆积的地方。

**所以假突破不是异常，它是流动性机制的正常产物。** 期待它不发生，等于期待市场里没有人需要流动性。

实际含义：

```
❌ 把止损放在前低正下方 —— 人人都在那，你是燃料
✅ 止损放在「判断被证伪」的位置，然后检查它是否恰好在人堆里
⚠️ 如果因此被迫放宽止损 → 仓位必须相应缩小（第六篇）
```

最后一条是硬约束。[第六篇](/posts/trade/06-risk-management/)的公式没有商量余地：

```
数量 = (账户 × 风险%) ÷ (入场价 − 止损价)
```

**止损放宽，分母变大，仓位必须变小。** 「把止损挪远一点但仓位不变」等于偷偷加了杠杆。

### 证据不足的部分

```
❌ 趋势线的斜率、通道、形态命名 —— 主观性高，独立检验后无稳定超额
❌ 「测试三次必破」这类计数规则 —— 无可靠证据
❌ 斐波那契比例 —— 属于第七篇证据分级里最低一档
```

不是说用了必亏，是说**它们不构成可依赖的优势来源**。区别在于：前面那些「订单堆积」的说法可以从市场机制推导出来，这些不能。

## 五、⚠️ 六种会系统性骗过你的读图方式

这一节可能是本篇最实用的部分。

### 1. ⭐ 事后看图 vs 事中看图

**这是所有读图错误里影响最大的一个。**

你见过的每一张标注了「这里进场、这里出场」的教学图，都有两个性质：

```
① 它是从大量图里挑出来的（幸存者偏差）
② 标注是在知道结果之后做的（后见之明偏差）
```

在完成的图上，信号「显而易见」。在右侧还没长出来的时候，同样的形态有几十种可能的后续，而你不知道是哪一种。

**自检方法**（这个方法很有效，值得真的去做）：

```
拿历史数据，用纸盖住右侧
一根一根往右揭，每揭一根做一次决策并记录
揭完之后统计
```

⚠️ **几乎所有人第一次做这个练习时，结果都远差于他们看完整图时的预期。** 那个落差就是后见之明偏差的大小。

### 2. 未走完的 K 线

**当前这根还在变。** 它的收盘价、影线、乃至颜色，都可能在周期结束前完全改变。

```
回测用的是「已收盘」的 K 线
实盘你看到的是「正在形成」的 K 线

→ 你在实盘中看到的信号，可能在收盘时并不存在
→ 而你的回测从来没见过这种情况
```

这是一个具体、常见、且**能让实盘结果显著差于回测**的差异。规则应该明确写死：**信号在收盘确认后才成立，还是允许盘中触发？** 两种都可以，但必须选一个，并且**用同一个口径回测**（[第十八篇](/posts/trade/18-execution/)的状态机）。

### 3. 缩放欺骗

同一份数据，改变 Y 轴范围或时间跨度，主观印象可以完全相反：

```
把 Y 轴压扁 → 剧烈波动看起来像平稳趋势
把 Y 轴拉伸 → 微小噪声看起来像剧烈行情
```

**看图前先看坐标轴。** 而且注意：多数看盘软件默认自动缩放，也就是说**你每次切换标的，坐标尺度都在变**——跨标的的视觉比较几乎总是失真的。

想比较不同标的的波动，**用数字（ATR%）不要用眼睛**。

### 4. 对数坐标 vs 线性坐标

对加密尤其重要，因为价格常常跨数量级：

```
线性坐标：$1 → $2 和 $100 → $101 的视觉高度相同
          （前者是 +100%，后者是 +1%）
对数坐标：相同的百分比变化 = 相同的视觉高度
```

**看长期图（月线、年线）应该用对数坐标**，否则早期的翻倍行情会被压成一条直线，而近期的小幅波动看起来像剧变。

⚠️ 很多「历史上每次都这样」的说法，是线性坐标制造的错觉。

### 5. 幸存图表偏差

你在任何地方看到的历史图表，都属于**还在交易的标的**。

```
归零的、下架的、退市的项目，不会有人贴它们的图
```

所以「回调都是买入机会」这类印象，是从**幸存者的图**里得到的。那些没回来的，图早就没了（[第二十六篇](/posts/trade/26-screening/)的 point-in-time 问题）。

⚠️ 这在加密比在美股严重得多，因为**消失率高得多**。

### 6. 复权与拼接

- **美股**：拆股、分红会导致历史价格需要调整。用未复权数据算指标，会在除权日看到虚假跳空（[第十二篇](/posts/trade/12-product-structures/)）。
- **加密**：代币迁移、重命名、交易对更换计价货币，都会造成历史数据断裂。有些数据源会**静默拼接**，制造出不存在的价格跳跃。

**用之前先画一遍完整历史，肉眼找异常跳空。** 这一步能发现相当一部分数据问题。

## 六、所以图表能回答什么

收敛成一张表——**左边的可以直接读出来，右边的读不出来**：

| ✅ 图表能回答 | ❌ 图表不能回答 |
|---|---|
| 现在的波动率有多大（ATR%） | 接下来会涨还是会跌 |
| 现在的波动率相对自己的历史是高还是低 | 这个波动率会持续多久 |
| 哪里有订单堆积（前高前低、整数关口） | 价格到那里会不会反转 |
| 成交量相对**同时段**基准是否异常 | 这个异常是买方还是卖方主导（**需要逐笔数据**，[第十五篇](/posts/trade/15-orderflow-data/)） |
| 当前价相对某个均值的偏离程度 | 它会不会回归 |
| 这个标的的成本比值够不够（[第二十六篇](/posts/trade/26-screening/)） | 这一笔会不会赚钱 |

⭐ **左列全是「当前状态的测量」，右列全是「未来的推断」。**

这条分界线就是[第十五篇](/posts/trade/15-orderflow-data/)开篇那个原则的具体形态：**图表是一个测量仪器，不是一个预测装置。**

## 七、一个实际的读图顺序

如果要给一个可执行的流程，它和大多数人的习惯是**反的**：

```
① 先看坐标轴   —— 线性还是对数？Y 轴范围？时间跨度？
② 再看波动率   —— ATR%，以及它相对自身历史的位置
③ 算成本比值   —— 今天这个标的、这个周期，值不值得做（第二十六篇）
                  ⚠️ 不通过就到此为止，后面都不用看
④ 看成交量     —— 相对同时段基准，不是相对前几根
⑤ 标订单堆积区 —— 前高前低、整数关口
                  用途是「止损别放这儿」，不是「这儿会反转」
⑥ 最后才看方向 —— 而且要写成可证伪的假设（第十九篇）
```

**第 ⑥ 步排在最后，而且多数时候走不到那里**——因为第 ③ 步已经把大部分情况否掉了。

多数人的顺序是从 ⑥ 开始，然后用 ①–⑤ 去给已经形成的结论找支持。**那不是分析，那是确认偏误的实施过程**（[第九篇](/posts/trade/09-system-and-traps/)）。

## 八、这一篇的结论

- **K 线是有损压缩。** ⭐ 最关键的丢失：**无法知道最高价和最低价谁先出现**——这直接造成回测偏差，且周期越大越严重。同时有止损和止盈的策略，**必须用细一个数量级的数据验证**。
- **影线只说明「触及过但没守住」。** 在流动性薄的时段，制造一根长影线的成本很低。
- ⚠️ **24 小时市场里「收盘」是一个约定，不是一个事件**——而几乎所有指标都建立在收盘价上。
- ⭐ **周期之间是恒等关系，不是相关关系。** 1 根 1h ≡ 内部 12 根 5min。**切换周期不产生新数据，只改变平滑程度。**
- **周期选择决定的是三件可算的事**：成本比值（波动按 √T，成本按 1）、样本积累速度、对手构成。**和「看得清不清楚」无关。**
- ⭐ **MA / MACD / RSI / KDJ 是价格的确定性函数，零新信息。** 加十个这类指标 = 同一个价格序列的十种画法。「三重确认」是一个观测被数了三遍。
- **图表上唯一的非价格数据是成交量**——所以它最值得认真对待。⚠️ 但必须和**历史同一时段**比，和前几根比会系统性误报。
- **波动率类是确定性变换里唯一逃出来的**（二阶矩），而且它是本手册里被反复用到的量：仓位、止损、成本比值、杠杆衰减。
- ⭐ **点位是流动性所在，不是转折点所在。** 止损单在关键位置从保护变成了流动性供给——**假突破是机制的正常产物**。止损放宽则仓位必须缩小，否则等于偷偷加杠杆。
- ⭐ **六种系统性骗人的读图方式**：事后看图（**用纸盖住右侧一根根揭，做一次这个练习**）、未走完的 K 线（实盘看到的信号收盘时可能不存在）、缩放欺骗（跨标的的视觉比较几乎总是失真）、线性/对数坐标、幸存图表偏差、复权与静默拼接。
- ⭐ **图表能测量当前状态，不能推断未来。** 左列右列那张表就是全部边界。
- **读图顺序应该是反的**：坐标轴 → 波动率 → 成本比值（不过就停）→ 成交量 → 订单堆积区 → **最后才是方向**。从方向开始然后找支持，那是确认偏误的实施过程。
