你在链上看到一个大额转账：某个巨鲸把一万个 ETH 转了出去。

标题写着"巨鲸抛售"。

而这笔转账可能是：从冷钱包转到热钱包、交易所内部归集、给托管方、跨链桥的锁仓、或者他自己的两个地址之间倒一下。**链上看得见的是"币动了"，不是"有人卖了"。**

[第 34 篇]({{< ref "34-technical-analysis-map.md" >}})给了一张技术分析的完整地图。但它原本的十一类**全部是股票和中心化交易所的数据源**——加密独有的链上层不在里面。

这一篇把它补上，作为那张地图的**第 12 类**。

⚠️ 而[第 7 篇]({{< ref "07-analysis-methods.md" >}})第七节虽然列过链上分析的价值与局限，但那是一页清单：**没有算法、没有可算的判据、没有分层**。这一篇给这三样。

> 本系列仅用于记录与普及基础知识，不构成投资建议。本篇讲的是**测量**，不含任何方向性判断。

## 零、⭐ 它在地图上的位置

按[第 34 篇]({{< ref "34-technical-analysis-map.md" >}})第二节的判据（**用了什么数据**），链上层排得很高：

| 数据来源 | 有新信息 |
|---|---|
| 只有价格 | ❌ 零 |
| 成交量 | ✅ |
| 订单簿 / 逐笔 | ✅ 衰减快 |
| 衍生品持仓 | ✅ |
| 横截面 | ✅ |
| ⭐ **链上** | ✅ **有，而且是别处完全没有的那一份** |

### 打个比方

链上数据像**一座玻璃仓库**：每一件货什么时候进、什么时候出、搬到哪个货架，全都看得清清楚楚。

**但你看不到价签，也听不到谈价。** 一件货从 A 架搬到 B 架，可能是卖掉了，也可能只是换个位置放。

⚠️ 所以**必须先说清楚它不是什么**：它不是「看到大户在买」。**链上看得见的是转账，不是买卖。** 第五节会说明这个区别为什么是致命的——**几乎所有流行的链上"情绪指标"，都建立在把搬货当成卖货这一步上。**

## 一、⭐ 它唯一真正的优势：全样本 + 可独立复算

拿传统市场的持仓数据比一下：

| | 美股 13F | 链上 |
|---|---|---|
| 覆盖 | **抽样**（只有超过门槛的机构） | ⭐ **全部转账** |
| 频率 | 季度 | ⭐ **实时** |
| 滞后 | 季末后最多 45 天 | 无 |
| 能否独立复算 | ❌ 只能读它报的 | ✅ **自己跑节点就能算** |

> **这是整个加密领域里，数据质量明显优于传统市场的地方——大概也是唯一一处。**

这和[第 29 篇]({{< ref "29-onchain-trading.md" >}})第二节的结论是同一件事：**链上真正的优势不是「没有人占你便宜」，而是「能被测量」。**

## 二、⭐ 但地址不是人——这条决定了大部分指标的上限

⚠️ 这就是玻璃仓库里**看不到价签**那一半。货的进出你看得一清二楚，但"这一箱是卖了还是换个货架"、"这两个货架是不是同一个主人"——**仓库的玻璃墙回答不了**。下面大部分指标的上限，都卡在这里。

一个人可以有无数个地址；一个地址也可以是一整家交易所。交易所的冷热钱包互相调拨，在链上和「有人转走了十亿美元」长得一模一样。

于是有了本篇最重要的一条区分：

> ⭐ **「链上数据可复现」和「链上指标可复现」是两回事。**
>
> **原始数据（转账、余额、合约状态）任何人都能独立复算。**
>
> ⚠️ **但任何依赖「这个地址是谁」的指标，都继承了标注方的不可复现性——而标注是私有的、会变的、且通常不公开方法。**

⭐ 这正是[第 37 篇]({{< ref "37-chan-theory.md" >}})第五节那条判据的又一次应用：**一条链只要有一环不可复现，整条链的输出就不可复现。** 链上指标的那一环，就是地址标注。

## 三、⭐ 核心分层：按依赖多少假设排

这一节是全篇的骨架。类比[第 34 篇]({{< ref "34-technical-analysis-map.md" >}})第二节的重排——**传统的分类（按指标名字）没有信息量，按「依赖什么」分类才有**。

| 层 | 依赖地址标注 | 依赖成本假设 | 例子 |
|---|---|---|---|
| 🟢 **第 0 层：纯协议数据** | ❌ | ❌ | 区块间隔、Gas、算力/质押总量、总供应、销毁量 |
| 🟢 **第 1 层：单合约可读** | ❌ | ❌ | ⭐ DEX 池子储备、借贷协议抵押率与**清算线**、稳定币合约发行量 |
| 🟡 **第 2 层：需要聚合规则** | 🟡 部分 | ❌ | 活跃地址数、新增地址、转账笔数 |
| ⚠️ **第 3 层：需要地址标注** | ✅ **完全依赖** | ❌ | 交易所余额、巨鲸持仓、矿工流出 |
| ❌ **第 4 层：还需要成本假设** | ✅ | ✅ | MVRV、NUPL、已实现市值、长短期持有者划分 |

> ⭐ **这个排序同时是可复现性的排序、可信度的排序，和「被制造的难度」的排序。**
>
> ⚠️ **而流行度恰好是反过来的——最火的那几个在最底下。**

## 四、🟢 层：这里的东西是真的可以算的

### 1. ⭐ 借贷协议的清算线分布

这是本篇最值得单独指出的一项，因为它是[第 33 篇]({{< ref "33-price-levels.md" >}})那条统一判据——**「谁在这里必须交易」**——在链上的**完美实例**：

```
借贷协议的合约里，公开记录着：
  每个仓位的抵押品数量、借款数量、清算阈值
⇒ 每个仓位的清算价格可以被精确算出
⇒ 把它们按价格分桶，就得到一条「清算燃料」曲线
```

⭐ **这比 CEX 的清算数据强得多**：CEX 的清算量是**事后**由平台披露的汇总值，而链上的清算线是**事前**、**逐仓位**、**可独立复算**的。

⚠️ 三个限制（同[第 17 篇]({{< ref "17-defi-liquidation-bridges.md" >}})）：

- 清算价随利息累积**缓慢移动**，快照会过期
- 借款人可以随时补抵押——**它是一个可以被改变的位置，不是一个约定**
- 只覆盖**这一个协议**，⚠️ 而且**不能跨协议加总**（同[第 15 篇]({{< ref "15-orderflow-data.md" >}})深度不能跨平台加总的理由）

### 2. DEX 池子储备

**这才是「资金在不在池子里」的可靠版本**：储备量直接读合约，不需要任何标注。而它和[第 15 篇]({{< ref "15-orderflow-data.md" >}})第五节的订单簿深度是同一类东西——**当前状态的快照**，可以直接算冲击成本（[第 29 篇]({{< ref "29-onchain-trading.md" >}})）。

### 3. 供应侧的时间结构

```
质押量 / 解质押队列   → ⭐ 排队时间给出了供给变化的「时间表」
稳定币合约增发与销毁  → 事件可查，无需标注
代币解锁合约          → 第 21 篇：解锁时间表写在合约里
```

**这一类的价值在于它是「日历」而不是「信号」**——和[第 16 篇]({{< ref "16-calendar-events.md" >}})性质相同：**已知会发生、时间确定、不需要预测**。

## 五、⚠️ 第 3 层：交易所余额没有它看起来那么硬

「交易所余额下降 ⇒ 卖压减少」是流传最广的链上叙事之一。拆开看：

**三个标注层面的失真：**

- **内部调拨**：冷热钱包互转，在标注不全时表现为巨额流入或流出
- **新钱包未被标注**：交易所换地址，旧地址「流出」，新地址不在名单里
- **托管与机构钱包混入**：托管商的地址常被归到交易所名下

**⭐ 但还有一个更根本的，和标注无关：**

> ⭐ **转账不是成交。**

这和[第 33 篇]({{< ref "33-price-levels.md" >}})第五节那条「成交量不是资金流向」是**同一个错误的链上版本**——而链上版本更极端：

```
成交量：至少有买方和卖方，只是净额恒为零
链上转账：⭐ 连买卖双方都没有，它只是位置变了
```

⚠️ 所以「大额转入交易所」可以是准备卖、可以是做市商调仓、可以是换托管、可以是转入衍生品账户当保证金、也可以是走 OTC 的交割腿。**这几种在链上长得完全一样。**

## 六、❌ 第 4 层：MVRV / NUPL 这一类

必须公平地说：**它们的构造是精巧的**，而且在 BTC 的 UTXO 模型上确实可以算。

```
已实现市值 = Σ（每一份币「最后一次移动」时的价格 × 数量）
MVRV      = 市值 ÷ 已实现市值
NUPL      = (市值 − 已实现市值) ÷ 市值
```

⭐ 它想测的东西也是有意义的：**市场整体的账面盈亏状态**。但三个问题是结构性的：

**① ⚠️「最后一次移动」不等于「买入成本」**

自己转给自己、换钱包、交易所内部归集、找零输出——**全都会重置那个价格**，而它们和真实交易在链上无法区分。

**② ⚠️ 账户模型的链上根本没有这个东西**

UTXO 模型（BTC）里每一份币有明确的「上次移动」。**以太坊等账户模型的链没有 UTXO**，只能用启发式近似——⭐ **而近似方法是各家自己定的，这就回到了第二节的不可复现问题。**

**③ 最致命的一条：阈值的样本量**

「MVRV 高于某个值就是顶部」这类说法，那个数字是**在已经发生过的几个周期上挑出来的**。

> **BTC 到今天一共只有三到四个完整周期，而阈值是一个连续参数。**

按[第 38 篇]({{< ref "38-validation.md" >}})第七节：**在四个样本点上拟合一个连续阈值，纯运气就能做得很好。** 这不是「证据弱」，是**样本量根本不支持做这件事**。

而且这类指标**无法通过增加时间来解决**——[第 30 篇]({{< ref "30-trend-following.md" >}})第八节讲的样本量问题在这里是最极端的形态：**你要等下一个周期，那是好几年。**

## 七、⭐ 一个必须正面处理的自指问题

[第 7 篇]({{< ref "07-analysis-methods.md" >}})第七节提过一句「知道有人在看这些指标，就有人会去制造这些指标」。展开它，会得到一条和第三节完全吻合的结论。

⚠️ **在链上制造信号，成本极低而且完全合法：**

```
想制造「交易所大额流出」 → 转到自己的另一个钱包（只花 Gas）
想制造「巨鲸增持」       → 把币拆到多个地址，或归集到一个
想制造「活跃地址激增」   → 批量自转
```

⭐ **这和[第 28 篇]({{< ref "28-market-manipulation.md" >}})讲的市场操纵有一个关键区别**：

> **刷量至少还要真的成交、承担手续费和价格风险。**
>
> ⭐ **制造链上信号只需要转账——不需要成交，不承担任何价格风险。**

由此得到一条很干净的推论：

> **越依赖地址标注的指标，越容易被免费制造。**

⚠️ 而这条推论的排序，和第三节那张表**完全一致**——这不是巧合：**依赖标注，就意味着依赖「谁是谁」这个可以被随意重排的东西。**

> **另一个对位物是[第 45 篇]({{< ref "45-option-chain.md" >}})的期权链**：美股那边同样是横截面聚合的状态测量，同样按「依赖多少假设」分层，**而两边最流行的指标都在最底下。**

## 八、⭐ 它和第 39 篇是一对

| | [第 39 篇]({{< ref "39-market-breadth.md" >}}) 市场广度 | **本篇** 链上 |
|---|---|---|
| 市场 | 美股 | 加密 |
| 性质 | 横截面聚合的**状态测量** | 同 |
| 🟢 最扎实的用法 | 集中度 `1/Σwᵢ²`（纯算术） | **清算线分布、池子储备**（读合约） |
| ⚠️ 最常见的误用 | 广度差 ⇒ 要跌 | 交易所流出 ⇒ 要涨 |
| 数据口径问题 | 成分家数在变、口径不统一 | ⭐ **地址标注是私有的** |

⭐ **两篇的结论也是同一句**：**这一类数据最扎实的用法不需要预测任何东西**——它回答「现在是什么状态」，不回答「接下来会怎样」。

按[第 34 篇]({{< ref "34-technical-analysis-map.md" >}})第五节的三种用途：

| 用途 | 🟢 第 0–1 层 | ⚠️ 第 3 层 | ❌ 第 4 层 |
|---|---|---|---|
| **测量** | 🟢 **强** | 🟡 受标注限制 | ❌ 依赖成本假设 |
| **纪律** | 🟢 可以（如清算区回避） | 🟡 | ❌ |
| **预测** | ❌ | ❌ | ❌ **样本量不支持** |

## 九、拿到任何链上指标，先问五个问题

```
□ 它依赖地址标注吗？标注方是谁？方法公开吗？
□ 我能不能自己从节点或区块浏览器复算出来？
□ 它假设了「成本」吗？那个成本是怎么定的？
□ 它的阈值哪来的？在几个周期上拟合的？
□ ⭐ 制造这个信号要花多少钱？转账还是成交？
```

⭐ **第 ② 问是最快的一道筛**：复算不出来的，它就不是测量，是别人的产品。

⭐ **第 ⑤ 问是最狠的一道**：只要转账就能制造的信号，默认按噪声处理。

## 十、能回答和不能回答什么

| 问题 | |
|---|---|
| 这个借贷协议的清算线分布是什么样 | ✅ ⭐ **逐仓位可精确算，事前、可复算** |
| 这个池子现在多深、冲击成本多少 | ✅ 直接读合约 |
| 未来 90 天有多少代币解锁 | ✅ 合约里写着（[第 21 篇]({{< ref "21-tokenomics.md" >}})） |
| 质押/解质押队列有多长 | ✅ 供给变化的时间表 |
| 稳定币这个月增发了多少 | ✅ 事件可查，无需标注 |
| 交易所余额降了说明什么 | ⚠️ ⭐ **转账不是成交**——五种情况在链上长得一样 |
| 巨鲸在增持吗 | ⚠️ 地址不是人，且拆分归集免费 |
| 现在 MVRV 到了顶部区间吗 | ❌ **三四个周期拟合一个连续阈值，样本量不支持** |
| 链上数据是不是比传统市场可靠 | ✅ **原始数据是** **指标不一定是** |
| 大户在买还是在卖 | ❌ **链上看不见买卖，只看得见位置变化** |

## 十一、这一篇的结论

- ⭐ **链上层是[第 34 篇]({{< ref "34-technical-analysis-map.md" >}})地图上的第 12 类**，而按信息含量它排得很高——**它是别处完全没有的一份数据。**
- ⭐ **它唯一真正的优势是全样本 + 可独立复算**：美股 13F 是抽样、季度、最多滞后 45 天且只能读它报的；链上是全部转账、实时、自己跑节点就能算。**这大概是加密领域唯一一处数据质量优于传统市场的地方。**
- **但「链上数据可复现」和「链上指标可复现」是两回事。** 原始数据谁都能算；⚠️ **任何依赖「这个地址是谁」的指标，都继承了标注方的不可复现性**——而标注是私有的、会变的、方法通常不公开。
- **所以正确的分类不是按指标名字，是按依赖多少假设**：🟢 纯协议数据 → 🟢 单合约可读 → 🟡 需要聚合规则 → ⚠️ 需要地址标注 → ❌ 还需要成本假设。**这同时是可复现性、可信度和「被制造难度」的排序。** **而流行度恰好反过来。**
- **最值得用的一项是借贷协议的清算线分布**：它是[第 33 篇]({{< ref "33-price-levels.md" >}})「谁在这里必须交易」在链上的完美实例，而且**比 CEX 强**——CEX 的清算是事后汇总，链上是事前、逐仓位、可复算。但它会随利息移动、可以被补抵押改变，且**不能跨协议加总**。
- **「转账不是成交」是这一类里最重要的一句**，而它比[第 33 篇]({{< ref "33-price-levels.md" >}})的「成交量不是资金流向」更极端：**成交量至少有买卖双方，链上转账连买卖双方都没有——它只是位置变了。** 大额转入交易所可以是准备卖、做市商调仓、换托管、转保证金、OTC 交割腿，**在链上长得完全一样**。
- ❌ **MVRV / NUPL 这一层有三个结构性问题**：「最后一次移动」不等于买入成本、账户模型的链上只能靠各家自定的启发式近似、**而最致命的是阈值只有三四个周期的样本量**。在四个样本点上拟合一个连续阈值，**纯运气就能做得很好**——而且这个问题**无法靠等待解决**，下一个样本要等好几年。
- **自指问题必须正面处理**：在链上制造信号只需要转账，**不需要成交、不承担价格风险**——比刷量便宜得多。由此**越依赖地址标注的指标，越容易被免费制造**，而这条推论的排序和第三节那张表完全一致，**并非巧合**。
- **它和[第 39 篇]({{< ref "39-market-breadth.md" >}})是一对**：一个美股一个加密，都是横截面聚合的状态测量，最扎实的用法都**不需要预测任何东西**，最常见的误用都是**把状态量当方向信号**。
- **五个问题里最有用的两个**：「我能不能自己复算」——复算不出来的，**它不是测量，是别人的产品**；「制造这个信号要花多少钱」——**只要转账就能造的，默认按噪声处理**。
