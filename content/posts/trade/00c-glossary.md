## 一、仓位与风险

| 术语 | 定义 | 出处 |
|---|---|---|
| **期望值 E** | `(胜率 × 平均盈利) − (败率 × 平均亏损) − 每笔成本` | [1]({{< ref "01-before-you-trade.md" >}})§5 |
| **仓位数量** | `(账户 × 单笔风险%) ÷ (入场价 − 止损价)` | [6]({{< ref "06-risk-management.md" >}})§2 |
| **R 倍数** | 把每笔结果除以「初始风险」，统一成可比单位 | [6]({{< ref "06-risk-management.md" >}})§5 |
| **有效杠杆** | `总仓位价值 ÷ 账户净值` | [6]({{< ref "06-risk-management.md" >}})§6 |
| **强平价** | `入场价 × (1 − 1/L) ÷ (1 − 维持保证金率)` | [6]({{< ref "06-risk-management.md" >}})§6 |
| **回撤不对称** | 亏 50% 需要涨 100% 回本 | [6]({{< ref "06-risk-management.md" >}})§3 |
| **相关性趋向 1** | 危机中分散化失效，按「一起亏」估总风险 | [6]({{< ref "06-risk-management.md" >}})§8 |

## 二、成本与可交易性

| 术语 | 定义 / 判据 | 出处 |
|---|---|---|
| **往返成本** | `手续费×2 + 价差 + 滑点×2 + 资金费率×N` | [26]({{< ref "26-screening.md" >}})§2 |
| ⭐ **可交易比值** | `期间预期波动 ÷ 往返成本`　**< 5 ⇒ 出局** | [26]({{< ref "26-screening.md" >}})§2 |
| ⭐ **出场压力比** | `仓位 ÷ ±1% 买单深度`　**> 0.3 ⇒ 出局**（深度·现在，⚠️ 挂单可撤偏乐观） | [26]({{< ref "26-screening.md" >}})§3 |
| **出场流量比** | `仓位 ÷ 最差时段分钟成交量`（成交量·过去） | [44]({{< ref "44-data-pipeline.md" >}})§3 |
| **绝对 / 相对价差** | `卖一 − 买一` / `(卖一 − 买一) ÷ 中间价`；⭐ 只有后者可比 | [15]({{< ref "15-orderflow-data.md" >}})§1 |
| ⭐ **冲击成本** | `(成交均价 − 中间价) ÷ 中间价`，逐档吃穿算出 | [15]({{< ref "15-orderflow-data.md" >}})§5 |
| **持久冲击** | 约随参与率的 `√(Q/V)` 增长；⚠️ 拆单收益递减（量减半冲击只降到约 0.71 倍） | [15]({{< ref "15-orderflow-data.md" >}})§5 |
| **费用率分界点** | `N = (往返成本 ÷ 费用率) × 365`，短于它盯价差、长于它盯费用率 | [42]({{< ref "42-etf-basics.md" >}})§4 |

## 三、状态测量

| 术语 | 定义 | 出处 |
|---|---|---|
| **VWAP** | `成交额 ÷ 成交量`；⭐ 必然落在 [低, 高] 之间（可当数据校验） | [15]({{< ref "15-orderflow-data.md" >}})§1 |
| **RVOL / Z 分数** | `当前量 ÷ 同时段历史均值` / `(当前量 − 同时段均值) ÷ 同时段标准差` | [15]({{< ref "15-orderflow-data.md" >}})§3 |
| **成交速度** | 单位时间成交笔数；⭐ 唯一不受价格方向影响的纯状态量 | [15]({{< ref "15-orderflow-data.md" >}})§2 |
| **主动买占比 / CVD** | 成交打在卖一还是买一；累计即 CVD。⭐ 测**急迫性**不是方向 | [15]({{< ref "15-orderflow-data.md" >}})§2 |
| **OBI** | 订单簿失衡；⚠️ 有效期**亚秒级**，对分钟级无用 | [15]({{< ref "15-orderflow-data.md" >}})§6 |
| **Volume Profile / POC** | 成交量按**价格**分桶；⭐ 相对成交序列**零新信息** | [15]({{< ref "15-orderflow-data.md" >}})§4 |
| **波动率分位** | `100 × 过去 N 天中低于今天的天数 ÷ N`（⚠️ 用分位不用绝对值） | [35]({{< ref "35-market-regime.md" >}})§2 |
| ⭐ **效率比 ER** | `|期末 − 期初| ÷ Σ|每根变动|`　→1 趋势 / →0 震荡；**与波动率独立** | [35]({{< ref "35-market-regime.md" >}})§4 |
| ⭐ **半衰期** | `− ln2 ÷ b`（由 `Δp = a + b·p` 回归）；⚠️ 对单个价格通常**无解，而那是正确答案** | [35]({{< ref "35-market-regime.md" >}})§4 |
| **路程 R / 净位移 D** | ER 的分母 / 分子；⭐ 对网格分别是**燃料**和**敌人** | [41]({{< ref "41-grid-trading.md" >}})§2 |
| **持仓量 OI** | 还没平掉的合约；⭐ 三个量里唯一的**存量** | [33]({{< ref "33-price-levels.md" >}})§5 |
| **资金费率 F** | `溢价指数 P + clamp(利率 I − P, ±0.05%)`；⚠️ 封顶后不再反映拥挤度 | [4]({{< ref "04-crypto-mechanics.md" >}})§3 |

## 四、横截面与广度

| 术语 | 定义 | 出处 |
|---|---|---|
| ⭐ **有效成分数** | `1 ÷ Σwᵢ²`；前十占一半时 500 成分只值 **39 只** | [39]({{< ref "39-market-breadth.md" >}})§2 |
| ⭐ **有效独立策略数** | `N ÷ (1 + (N−1)ρ)`；ρ=0.5 时 10 个策略只值 **1.8 个** | [38]({{< ref "38-validation.md" >}})§8 |
| **广度比值** | `等权指数 ÷ 市值加权指数`；⭐ 最干净的广度度量 | [39]({{< ref "39-market-breadth.md" >}})§1 |
| **净涨家数 / 腾落线 / ADR** | `涨−跌` / 其累积 / `涨÷跌`；⚠️ 腾落线**绝对值无意义** | [39]({{< ref "39-market-breadth.md" >}})§1 |
| **TRIN** | `(涨家数÷跌家数) ÷ (涨量÷跌量)`；⭐ 这一类里唯一引入成交量的 | [39]({{< ref "39-market-breadth.md" >}})§1 |
| **VIX** | 标普 500 期权反推的 30 天隐含波动率；⚠️ **不是恐慌指数，且不可直接交易** | [39]({{< ref "39-market-breadth.md" >}})§4 |
| **偏斜 Skew** | `25-delta 看跌 IV − 25-delta 看涨 IV`；⭐ 测**保险价格**不是方向 | [45]({{< ref "45-option-chain.md" >}})§4 |
| **GEX** | Gamma 敞口；⭐ **数值可算，符号靠一个不可观测的假设** | [45]({{< ref "45-option-chain.md" >}})§5 |
| **Put/Call 比** | ⚠️ 三种互不兼容定义（成交量 / OI / 名义），跨来源不可比 | [45]({{< ref "45-option-chain.md" >}})§6 |
| **MVRV / NUPL** | `市值÷已实现市值` / `(市值−已实现市值)÷市值`；⚠️ 阈值只有 3–4 个周期样本 | [43]({{< ref "43-onchain-metrics.md" >}})§6 |

## 五、检验与统计

| 术语 | 定义 / 判据 | 出处 |
|---|---|---|
| ⭐ **样本量** | `t = (μ/σ)√N`；要 t=2 需 `N = 4σ²/μ²`。夏普 0.5 约需 **16 年** | [7]({{< ref "07-analysis-methods.md" >}})§9 |
| ⭐ **成本放大样本量** | 成本吃掉一半毛收益 ⇒ 所需样本量 **×4**（平方关系） | [38]({{< ref "38-validation.md" >}})§3 |
| ⭐ **过滤器判据** | 加过滤器后 `平均 R 需提升倍数 ≥ √(N原 ÷ N后)` | [32]({{< ref "32-trading-signals.md" >}})§6 |
| ⭐ **多重比较** | 试 N 次纯运气的最好夏普 ≈ `√(2 ln N) ÷ √T`。5 年试 1000 次 ⇒ **1.46** | [38]({{< ref "38-validation.md" >}})§7 |
| **分块 bootstrap** | 抽连续块保留自相关；⚠️ 块长本身是参数 | [38]({{< ref "38-validation.md" >}})§5 |
| **步进检验** | 滚动 / 锚定；⭐ 真正的产出是**各段最优参数的一致性** | [38]({{< ref "38-validation.md" >}})§6 |
| **参数平原** | 一片连续区间都还行，才不是拟合噪声 | [30]({{< ref "30-trend-following.md" >}})§9 |
| **point-in-time 池** | 「当时那天真实存在的可交易集合」；⭐ 是**必须从第一天积累的资产** | [26]({{< ref "26-screening.md" >}})§7、[44]({{< ref "44-data-pipeline.md" >}})§1 |
| ⭐ **引擎自检** | 跑随机进出策略，结果必须 ≈ `−成本×次数`。**唯一有已知答案的回测** | [38]({{< ref "38-validation.md" >}})§9 |
| ⭐ **聚合可加性** | `Σ(12 根 5min 量) ≡ 1 根 1h 量`；**不成立就是数据有问题** | [44]({{< ref "44-data-pipeline.md" >}})§2 |

## 六、结构性概念（非公式）

| 概念 | 一句话 | 出处 |
|---|---|---|
| ⭐ **凸 / 凹** | 亏损截断+盈利放任 ⇒ **凸**（趋势）；盈利截断+亏损放任 ⇒ **凹**（网格） | [30]({{< ref "30-trend-following.md" >}})§2、[41]({{< ref "41-grid-trading.md" >}})§1 |
| ⭐ **测量 / 纪律 / 预测** | 同一工具在三种用途下可靠性差**一个数量级**；⚠️ 必须先说是哪一种 | [34]({{< ref "34-technical-analysis-map.md" >}})§5 |
| ⭐ **零新信息** | 价格的确定性变换不含价格里没有的东西（MA/MACD/RSI/OBV/Volume Profile） | [27]({{< ref "27-reading-charts.md" >}})§4 |
| ⭐ **恒等 ≠ 相关** | 1 根 1h ≡ 12 根 5min，**多周期共振是同一份数据看两遍** | [27]({{< ref "27-reading-charts.md" >}})§3 |
| ⭐ **时态三分** | 成交量=过去·流量 / 深度=现在·快照 / OI=存量 | [33]({{< ref "33-price-levels.md" >}})§5 |
| ⭐ **谁必须交易** | 判断「位置」是否有效的统一判据：那里有没有**被迫**执行 | [33]({{< ref "33-price-levels.md" >}})§2 |
| **滞后 (n−1)/2** | MA(n) 与标准 EMA(n) 平均滞后**相同**；⚠️「EMA 更快」是错的 | [27]({{< ref "27-reading-charts.md" >}})§4 |
| **前视偏差** | 用了当时不可得的信息；⭐ 六种形态 | [32]({{< ref "32-trading-signals.md" >}})§2 |
| **幸存者偏差** | 消失的标的不在数据里 ⇒ 历史统计系统性偏乐观 | [7]({{< ref "07-analysis-methods.md" >}})§10 |
| ⭐ **公开衰减** | 公开的方向性规则写出来就开始衰减；连指数纳入都被套利掉 | [7]({{< ref "07-analysis-methods.md" >}})§6、[16]({{< ref "16-calendar-events.md" >}})§5 |
| ⭐ **可复现性是一条链** | 一环不可复现 ⇒ 整条链输出不可复现 | [37]({{< ref "37-chan-theory.md" >}})§5 |
| ⭐ **跨定义检验** | 换一种同样合理的固化方式，结论翻转 ⇒ 你测的是你的实现 | [37]({{< ref "37-chan-theory.md" >}})§6 |
| ⭐ **定义性的真** | 重言式事后总成立，从它推不出关于未来的任何结论 | [37]({{< ref "37-chan-theory.md" >}})§4 |
| ⭐ **选择偏差（确认才算成立）** | 失败的按定义不算，样本集**被结果定义**；⚠️ 回测里不会报错 | [40]({{< ref "40-chart-patterns.md" >}})§4 |
| ⭐ **静默错误** | 数据错误不报错，只给出看起来合理的结果 | [44]({{< ref "44-data-pipeline.md" >}})§0 |
| ⭐ **样本量被锁死** | 一年只有一个一月；BTC 只有 3–4 个周期。**无法靠提高频率解决** | [16]({{< ref "16-calendar-events.md" >}})§7、[43]({{< ref "43-onchain-metrics.md" >}})§6 |
| ⭐ **可交易性 ⟂ 可获利性** | 流动性与关注度正相关 ⇒ **没有「便宜又低效」那一格** | [26]({{< ref "26-screening.md" >}})§8 |
| ⭐ **空仓是免费的** | 环境不对就不做，是唯一不需要技能也不需要预测的正期望动作 | [35]({{< ref "35-market-regime.md" >}})§10 |
| **左侧 / 右侧** | 不是流派，是**确认窗口**这个旋钮的两端 | [36]({{< ref "36-left-right-side.md" >}})§1 |
| **进场位置自测** | `(进场价 − 波段极值) ÷ 波段幅度` 的**分布** | [36]({{< ref "36-left-right-side.md" >}})§9 |

## 七、加密特有

| 术语 | 定义 | 出处 |
|---|---|---|
| **FDV / 流通市值** | 全稀释估值 / 当前流通量估值；⚠️ 行情站显示的是后者 | [21]({{< ref "21-tokenomics.md" >}})§2 |
| **年通胀率** | `年新增供应量 ÷ 当前流通供应量` | [21]({{< ref "21-tokenomics.md" >}})§4 |
| **基差年化** | `(F − S) ÷ S × (365 ÷ 距到期天数)`；⭐ 开仓即锁定 | [10]({{< ref "10-market-neutral.md" >}})§2 |
| **标记价格** | 清算依据；⭐ **止损应当用它触发**，不是最新价 | [15]({{< ref "15-orderflow-data.md" >}})§1 |
| **已实现市值** | `Σ(每份币最后一次移动时的价格 × 数量)` | [43]({{< ref "43-onchain-metrics.md" >}})§6 |
| **链上五层** | 纯协议 → 单合约可读 → 需聚合规则 → **需地址标注** → **还需成本假设** | [43]({{< ref "43-onchain-metrics.md" >}})§3 |
| **链上四项成本** | `池子费率×2 + Gas×2 + 滑点×2 + MEV 损耗` | [29]({{< ref "29-onchain-trading.md" >}})§5 |
