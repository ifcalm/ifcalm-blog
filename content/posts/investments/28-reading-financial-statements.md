## 一、利润一样，公司不一样

这一讲要回答的问题是：**一家公司的财务报表里，哪些数字最重要？怎样看出一家公司是真的赚钱，还是只是"账面上"赚钱？**

先看一个场景。

五年过去了，阿杰的咖啡馆已经变成了一家有 20 家门店的连锁公司"阿杰咖啡"。它准备上市，你在研究要不要买它的股票。同时，另一家规模差不多的咖啡连锁"乙记咖啡"也在上市。

两家公司公布的去年净利润，一模一样：都是 **118.5 万美元**。

只看利润，它们没有区别。但你仔细翻了翻财报，发现：

- 阿杰咖啡去年从经营中实际收到了 **170 万美元**的现金。
- 乙记咖啡去年从经营中实际收到的现金，只有 **35 万美元**。

同样"赚了" 118.5 万美元，一家收到的现金比利润还多，另一家收到的现金还不到利润的三分之一。这中间发生了什么？哪家更值得信任？

这一讲就是要教你读懂这三张报表，回答这个问题。

## 二、家庭的三本账

打个比方。如果你想了解一个家庭的财务状况，会看三样东西：

- **工资单**：这个月挣了多少，花了多少，剩下多少。这是一段时间里的**收入和支出**。
- **家底清单**：在某一天拍一张照片，家里有多少存款、房子、车，欠了多少房贷、信用卡。这是某一个时间点上的**拥有和欠下**。
- **银行流水**：这个月实际有多少钱进了账户、多少钱出了账户。这是**真实的现金进出**。

前两本账可以有"估计"和"约定"的成分：比如工资单上写着这个月有一笔奖金，但公司说下个月才发。只有银行流水是最硬的：钱进来了就是进来了，没进来就是没进来。

公司的三张财务报表，正好对应这三本账：

- **利润表**对应工资单。
- **资产负债表**对应家底清单。
- **现金流量表**对应银行流水。

这个比方后面会回来好几次，尤其是那句话：**流水不会撒谎。**

## 三、利润表：这一年挣了多少

### 3.1 阿杰咖啡的利润表

下面是阿杰咖啡去年的利润表（单位：千美元）：

| 项目 | 金额 |
|---|---|
| 收入 | 10,000 |
| 减：销售成本（咖啡豆、牛奶、杯子等） | 3,500 |
| **毛利润** | **6,500** |
| 减：经营费用（房租、工资、管理费，含折旧 600） | 4,800 |
| **经营利润** | **1,700** |
| 减：利息 | 200 |
| **税前利润** | **1,500** |
| 减：所得税（21%） | 315 |
| **净利润** | **1,185** |

利润表从上往下读，就是一层一层地扣掉成本：

1. **收入**：卖了多少钱的咖啡和点心。
2. 扣掉直接和产品相关的**销售成本**，得到**毛利润**。
3. 再扣掉房租、员工工资、总部管理等**经营费用**，得到**经营利润**。这是公司主营业务本身赚的钱。
4. 再扣掉借款的**利息**和**所得税**，得到**净利润**。这是最终属于股东的部分。

### 3.2 折旧：没有花出去的"费用"

经营费用里有一项 600 千美元的**折旧**，需要单独说一下。

几年前，阿杰咖啡花钱买了咖啡机、装修了门店。这些东西能用好几年，会计上不会把买它们的钱一次全部算成当年的费用，而是在它们能用的那几年里，每年分摊一部分。这一年分摊到的部分，就是折旧。

所以折旧是一项"费用"，会减少利润，但**这一年并没有真的花出这笔钱**。钱在当初买设备的那一年就已经花出去了。这一点在后面看现金流量表时很重要。

### 3.3 几个比率

从利润表可以算出几个衡量盈利能力的比率：

- **毛利率** = 毛利润 ÷ 收入 = 6,500 ÷ 10,000 = **65%**。每卖 1 美元的咖啡，扣掉原料以后还剩 65 美分。
- **经营利润率** = 经营利润 ÷ 收入 = 1,700 ÷ 10,000 = **17%**。
- **净利润率** = 净利润 ÷ 收入 = 1,185 ÷ 10,000 ≈ **11.85%**。

这些比率本身不说明好坏，要和同行业的其他公司、和这家公司自己过去几年比较。毛利率很高、但经营利润率很低，说明房租和人工太贵；毛利率在逐年下降，说明原料成本上涨了，或者为了竞争在降价。

## 四、资产负债表：年底这一天的家底

### 4.1 阿杰咖啡的资产负债表

下面是阿杰咖啡去年年底的资产负债表（单位：千美元）：

| 资产 | 金额 | 负债和股东权益 | 金额 |
|---|---|---|---|
| 现金 | 800 | 应付账款（欠供应商的） | 500 |
| 应收账款（企业客户还没付的） | 200 | 应计费用（欠员工的工资等） | 300 |
| 存货 | 400 | 长期借款 | 3,200 |
| 店面和设备（扣除累计折旧后） | 6,600 | 股东权益 | 4,000 |
| **资产合计** | **8,000** | **负债和权益合计** | **8,000** |

### 4.2 两边永远相等

资产负债表最重要的一个性质是：**左边永远等于右边。**

> 资产 = 负债 + 股东权益

这不是巧合，而是定义。第一讲用咖啡馆讲过：公司拥有的每一样东西（资产），要么是借来的钱买的（负债），要么是股东的钱买的（股东权益）。换个说法：股东权益就是"公司拥有的东西扣掉欠别人的钱之后，剩下的部分"，也就是第一讲说的"剩余索取"。

回到家底清单：你家的房子、存款、车加起来，减去房贷和信用卡，剩下的就是你真正的身家。

### 4.3 几个比率

- **负债权益比** = 长期借款 ÷ 股东权益 = 3,200 ÷ 4,000 = **0.8**。借的钱是股东出的钱的 0.8 倍。第一讲和第二十七讲都说过，借得越多，股东承担的风险越大。
- **利息覆盖倍数** = 经营利润 ÷ 利息 = 1,700 ÷ 200 = **8.5 倍**。经营利润是利息的 8.5 倍，就算利润下降一大半，付利息也没问题。这个倍数越低，越危险。
- **流动比率** =（现金 + 应收账款 + 存货）÷（应付账款 + 应计费用）=（800 + 200 + 400）÷（500 + 300）= **1.75**。短期内能变现的资产，是短期内要付的钱的 1.75 倍。

⚠️ 资产负债表有一个容易被忽视的局限：上面的数字大多是按**历史成本**记录的。那些店面和设备，账上记的是当初花的钱减去折旧，不一定是它们今天值多少钱。很多最有价值的东西，比如品牌、客户的忠诚度、员工的经验，根本不在资产负债表上。所以第十七讲说的"账面价值"，只是一个粗略的会计数字，不是公司真正的价值。

## 五、现金流量表：钱真正的进出

### 5.1 阿杰咖啡的现金流量表

下面是阿杰咖啡去年的现金流量表（单位：千美元）：

| 项目 | 金额 |
|---|---|
| **经营活动** | |
| 净利润 | 1,185 |
| 加：折旧（是费用，但没有花现金） | +600 |
| 减：应收账款增加（卖出去了，钱还没收到） | −50 |
| 减：存货增加（买进来了，还没卖出去） | −100 |
| 加：应付账款增加（买进来了，钱还没付） | +65 |
| **经营现金流** | **1,700** |
| **投资活动** | |
| 开新店、买设备（资本支出） | −1,200 |
| **融资活动** | |
| 给股东分红 | −600 |
| 新增借款 | +200 |
| **现金增加** | **+100** |

### 5.2 从利润到现金

现金流量表最重要的部分，是第一段：它解释了**为什么利润不等于现金**。

利润是按"挣到了"来算的，不是按"收到钱"来算的。从利润到实际收到的现金，要做几项调整：

1. **加回折旧**：折旧减少了利润，但这一年没有花钱。
2. **减去应收账款的增加**：有些咖啡卖给了企业客户，记成了收入，但对方还没付钱。
3. **减去存货的增加**：买了更多的咖啡豆放在仓库里，花了钱，但还没卖出去，没变成销售成本。
4. **加上应付账款的增加**：从供应商那里进了货，记成了成本，但还没付钱。

调整以后，阿杰咖啡的**经营现金流**是 1,700 千美元，比净利润 1,185 还多。主要原因是那 600 的折旧：它是一个"没有花钱的费用"。

### 5.3 自由现金流

经营带来的现金，还不能全部算作股东能拿走的钱。阿杰咖啡去年还花了 1,200 开新店、买新设备，这叫**资本支出**。没有这笔投入，公司就没法维持和扩大经营。

> 自由现金流 = 经营现金流 − 资本支出 = 1,700 − 1,200 = **500**

自由现金流是在维持和扩大业务之后，**真正可以自由支配**的现金：可以用来分红、回购股票、还债，或者存起来。后面第三十讲会用它来给公司估值。

阿杰咖啡去年分红 600，比自由现金流 500 还多一点，差额用新借的 200 补上了，最后现金增加了 100。

### 5.4 三张表怎样连在一起

三张表不是互相独立的，而是严丝合缝地连在一起：

![三张报表怎样连在一起（阿杰咖啡，单位：千美元）](/images/investments/28-three-statements.svg)

- 利润表的**净利润**，是现金流量表的第一行。
- 净利润扣掉分红，让资产负债表上的**股东权益**增加了：年初的股东权益 3,415，加上净利润 1,185，减去分红 600，正好是年底的 4,000。
- 现金流量表的最后一行**现金增加 100**，正好等于资产负债表上现金的变化：年初 700，年底 800。

这种勾稽关系，也是审计师和分析师用来检查报表是否可信的方法之一。

## 六、净资产收益率和它的三段拆解

### 6.1 ROE

股东最关心的一个比率，是**净资产收益率**（ROE）：

> ROE = 净利润 ÷ 股东权益 = 1,185 ÷ 4,000 ≈ **29.6%**

股东投进公司的每 1 美元，这一年给股东赚了将近 30 美分。

（更严格的算法是用年初和年底股东权益的平均值做分母，这里为了简单用年底的数字。）

### 6.2 拆成三段

ROE 高，可能是因为几种完全不同的原因。美国杜邦公司在 20 世纪初就用过一种方法，把 ROE 拆成三个部分相乘，后来被叫做**杜邦分析**：

> ROE = 净利润率 × 资产周转率 × 权益乘数

- **净利润率** = 净利润 ÷ 收入 = 11.85%：每卖 1 美元，最后赚多少。
- **资产周转率** = 收入 ÷ 总资产 = 10,000 ÷ 8,000 = 1.25：每 1 美元的资产，一年能带来多少收入。
- **权益乘数** = 总资产 ÷ 股东权益 = 8,000 ÷ 4,000 = 2：每 1 美元的股东权益，撑起了多少资产。它衡量的是借钱的程度。

三者相乘：11.85% × 1.25 × 2 ≈ 29.6%，正好等于 ROE。

### 6.3 为什么要拆开

拆开以后，你就能看出 ROE 是从哪里来的：

- **高利润率**：靠品牌、技术或者定价能力赚钱，比如奢侈品公司。
- **高周转率**：利润率不高，但卖得非常快，比如大型超市。
- **高权益乘数**：靠借钱放大，比如银行。

⚠️ 这里最需要警惕的是第三种。两家公司 ROE 都是 30%，一家是因为利润率高，另一家是因为借了很多钱。后者的 ROE 更脆弱：第一讲和第二十七讲都说过，固定的那一块（利息）切得越大，剩下的那一块晃得越厉害。经济一变差，借钱多的公司 ROE 会掉得非常快，甚至变成负的。所以看到一个很高的 ROE，一定要看看它是怎么来的。

## 七、利润和现金为什么会对不上

### 7.1 回到乙记咖啡

现在可以回答开头的问题了。

乙记咖啡的净利润也是 1,185，折旧也是 600，应付账款也增加了 65。但它的现金流量表上，有两行和阿杰咖啡很不一样：

- **应收账款增加了 1,000**。
- **存货增加了 500**。

它的经营现金流是：1,185 + 600 − 1,000 − 500 + 65 = **350**。

利润 1,185，现金只有 350，中间差了 835。差在哪里？差在乙记咖啡"卖出去"了很多东西，却没有收到钱（应收账款大增）；买了很多原料，却没有卖出去（存货大增）。

### 7.2 这可能意味着什么

应收账款和存货大幅增加，不一定是坏事：一家快速扩张的公司，客户增多、库存增加，是正常的。但如果它们增长得比收入快得多，就是一个需要警惕的信号。可能的原因包括：

- 公司为了做大收入，给客户放宽了付款条件，甚至把东西"压"给经销商，提前确认了收入。
- 产品卖不出去，库存积压，可能将来要减值。
- 更坏的情况，是收入本身有虚构的成分。

回到家庭的三本账：工资单上写着这个月有一大笔收入，可银行流水里钱并没有进来。**流水不会撒谎。** 当利润和现金长期对不上，相信现金。

第十九讲提到的**应计异象**，说的正是这件事：1996 年 Richard Sloan 发现，利润里来自"应计项目"（比如应收账款增加）的部分越大、来自实际现金的部分越小，公司未来的股票收益平均越差。投资者似乎没有充分区分这两种利润。

## 八、哪些数字最容易被粉饰

财务报表是按照美国的**公认会计原则**（GAAP）编制的，上市公司的年报还要经过独立的会计师事务所审计。但会计规则里仍然有很多需要判断和估计的地方，也就有了粉饰的空间。下面是几个最常见的地方。

**收入确认。** 什么时候算"卖出去了"？是签了合同、发了货，还是收到了钱？提前确认收入，是最常见的粉饰手法之一。信号：应收账款增长远快于收入。

**把费用变成资产。** 一笔支出，如果算成当年的费用，会直接减少利润；如果算成一项"资产"（资本支出），就只是每年分摊一点折旧。2002 年，美国电信公司世通（WorldCom）被揭露把数十亿美元本该算作经营费用的支出记成了资本支出，虚增了利润，最终申请破产，是当时美国历史上最大的破产案。

**调整后的利润。** 很多公司除了公布按 GAAP 计算的利润，还会公布一个"调整后"的利润，把一些它认为"一次性"或者"非现金"的费用剔除掉。这本身不一定有问题，但如果一家公司每年都有"一次性"的费用，它们其实就不是一次性的。

**EBITDA。** 这是一个常见的"调整后"指标：息税折旧摊销前利润，也就是在扣除利息、税、折旧和摊销之前的利润。它有时有用，但它忽略了一个很真实的成本：设备会老化、需要更换。沃伦·巴菲特曾多次批评过度依赖 EBITDA 的做法，认为它假装资本支出不存在。回到阿杰咖啡：如果不扣折旧，它的利润看起来会大很多，但那些咖啡机过几年总是要换的。

**股票薪酬。** 很多科技公司用股票和期权给员工发薪酬。这是真实的成本：它稀释了老股东的权益。但在"调整后利润"里，它常常被剔除掉。

**表外负债。** 有些义务不出现在资产负债表上，或者被藏在很难看懂的附注里。2001 年安然（第十讲提到过）就是通过大量复杂的"特殊目的实体"，把巨额债务藏在了资产负债表之外。

## 九、去哪里看财报

美国上市公司必须向证券交易委员会（SEC）提交定期报告，所有人都可以在 SEC 的 **EDGAR** 系统里免费查阅：

- **10-K**：年度报告，经过审计，内容最完整，包括三张报表、附注、管理层讨论与分析，以及风险因素。
- **10-Q**：季度报告，未经全面审计。
- **8-K**：重大事件报告，比如高管变动、并购、重大诉讼。

读年报时，除了三张报表，**附注**和**管理层讨论与分析**也很重要：收入怎么确认、折旧怎么计算、有哪些或有负债，往往写在附注里。

## 十、几个容易混淆的地方

**"利润就是公司赚到的现金。"** 利润是按"挣到了"计算的，现金是按"收到了"计算的，两者可以差得很远。

**"ROE 越高越好。"** 要看 ROE 是靠利润率、周转率，还是靠借钱撑起来的。靠借钱的高 ROE 更脆弱。

**"账面价值就是公司值多少钱。"** 资产负债表大多按历史成本记账，很多最有价值的东西（品牌、技术、人才）根本不在表上。

**"EBITDA 比净利润更能反映公司的赚钱能力。"** EBITDA 忽略了设备更新等真实的成本。

**"经过审计的报表就一定没问题。"** 审计能发现很多问题，但会计规则里仍有很多判断空间。安然和世通的报表都经过了审计。

## 十一、小结

回到开头那两家利润都是 118.5 万美元的咖啡连锁：阿杰咖啡的经营现金流是 170 万美元，乙记咖啡只有 35 万美元。乙记的应收账款和存货大幅增加，利润里有很大一部分还没有变成现金。

- 三张报表就像**家庭的三本账**：**利润表**是工资单（一段时间的收支），**资产负债表**是家底清单（某一天的拥有和欠下），**现金流量表**是银行流水（真实的现金进出）。
- 利润表一层层扣掉成本：收入 → 毛利润 → 经营利润 → 净利润。**折旧**是一项不花现金的费用。
- 资产负债表：**资产 = 负债 + 股东权益**，永远相等。账上大多是历史成本。
- 现金流量表解释了**利润为什么不等于现金**。**自由现金流** = 经营现金流 − 资本支出，是真正可以自由支配的现金。
- 三张表严丝合缝地连在一起：净利润进入现金流量表，也改变股东权益；现金增加等于资产负债表上现金的变化。
- **ROE** = 净利润率 × 资产周转率 × 权益乘数。靠借钱撑起来的高 ROE 更脆弱。
- 利润和现金长期对不上，是一个警示信号。**流水不会撒谎。**
- 最容易被粉饰的地方：收入确认、费用资本化、调整后的利润、EBITDA、股票薪酬、表外负债。

## 思考题

1. 一家公司收入 5,000，销售成本 2,000，经营费用 1,800（含折旧 300），利息 100，税率 25%。它的毛利率、经营利润率和净利润是多少？
2. 用第 1 题的公司，如果这一年应收账款增加了 200，存货减少了 100，应付账款增加了 50，经营现金流是多少？如果资本支出是 400，自由现金流是多少？
3. 两家公司 ROE 都是 20%。甲公司净利润率 10%、资产周转率 1.0、权益乘数 2.0；乙公司净利润率 4%、资产周转率 1.25、权益乘数 4.0。如果经济衰退，两家的收入都下降，你认为哪家的 ROE 更脆弱？为什么？
4. 一家公司过去三年的收入每年增长 15%，但应收账款每年增长 50%，经营现金流连续三年低于净利润。你会怎样解读这些信号？
5. 一家公司公布的"调整后利润"比 GAAP 利润高 40%，差额主要来自"股票薪酬"和"重组费用"，而重组费用已经连续五年出现。你会怎么看待这个"调整后利润"？

## 思考题提示

1. 毛利润 3,000，毛利率 60%。经营利润 3,000 − 1,800 = 1,200，经营利润率 24%。税前利润 1,100，税 275，净利润 825。
2. 经营现金流 = 825 + 300 − 200 + 100 + 50 = 1,075。自由现金流 = 1,075 − 400 = 675。
3. 乙公司更脆弱。它的权益乘数是 4.0，借的钱是股东出的钱的 3 倍；利润率又只有 4%，收入稍微下降，加上固定的利息，利润就可能大幅下降甚至变成亏损，ROE 会掉得很快。甲公司主要靠较高的利润率，借钱较少，抗风险能力更强。
4. 应收账款增长远快于收入，经营现金流持续低于利润，说明很多"收入"没有变成现金。可能是放宽了收款条件、提前确认收入，甚至虚构收入。这是一个需要深入调查的警示信号，在没有合理解释之前，应该对它的利润打一个折扣。
5. 股票薪酬是真实的成本，它稀释了股东的权益，不应该被剔除。连续五年出现的"重组费用"也不是一次性的，而是经营的一部分。这个"调整后利润"很可能高估了公司真实的盈利能力，GAAP 利润可能是更可靠的参考。
